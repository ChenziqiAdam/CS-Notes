# Recurrent Neural Networks (RNN)

- A family of neural architectures
	- word2vec
	- feedforward network
	- RNN
	- transformer
- Core Idea: Apply the same weights $W$ *repeatedly*
	![[Pasted image 20251017171113.png]]
	- The hidden states store the info up until the current state.
	- The final prediction is based on the final hidden state.
- Summary
	- RNN Advantages:
		- Can process any length input
		- Computation for step $t$ can (in theory) use information from many steps back
		- Model size doesn't increase for longer input context
		- Same weights applied on every timestep, so there is symmetry in how inputs are processed.
	- RNN Disadvantages:
		- Recurrent computation is slow
		- In practice, difficult to access information from many steps back, i.e. forget too quickly
- To train a RNN model:
	- Get a big corpus of text which is a sequence of words $x^{(1)}, \ldots, x^{(T)}$.
	- Feed into RNN-LM; compute output distribution $\hat{y}^{(t)}$ for every step $t$:
		- i.e., predict probability distribution of every word, given words so far.
	- **Loss function** on step $t$ is **cross-entropy** between predicted probability distribution $\hat{y}^{(t)}$, and the true next word $y^{(t)}$ (one-hot for $x^{(t+1)}$):
		$J^{(t)}(\theta) = CE(y^{(t)}, \hat{y}^{(t)}) = -\sum_{w \in V} y_w^{(t)} \log \hat{y}_w^{(t)} = -\log \hat{y}_{x^{(t+1)}}^{(t)}$
	- Average this to get **overall loss** for entire training set:
		$J(\theta) = \frac{1}{T} \sum_{t=1}^T J^{(t)}(\theta) = \frac{1}{T} \sum_{t=1}^T -\log \hat{y}_{x^{(t+1)}}^{(t)}$
- Example:
	1. Give a prediction on the next word, and calculate the loss compared to the actual word
	![[Pasted image 20251017171922.png]]
	2. Continue to the next word and pull it back to the actual word, i.e. "teacher forcing"
	![[Pasted image 20251017172003.png]]
	- However: Computing loss and gradients across entire corpus $x^{(1)}, \ldots, x^{(T)}$ at once is too expensive (memory-wise)!
		$J(\theta) = \frac{1}{T} \sum_{t=1}^T J^{(t)}(\theta)$
		- In practice, consider $x^{(1)}, \ldots, x^{(T)}$ as a segment (say 100 words)
	- Compute loss $J(\theta)$ for a sentence (actually, a batch of sentences), compute gradients and update weights. Repeat on a new batch of sentences.
- Backpropagation for RNNs
	- Q. What’s the derivative of $J^{(t)}(\theta)$ with respect to the repeated weight matrix $W_h$?
		$\frac{\partial J^{(t)}}{\partial W_h} = \sum_{i=1}^t \frac{\partial J^{(t)}}{\partial W_h}\bigg|_{(i)}$
		- The gradient w.r.t. a repeated weight is the sum of the gradient w.r.t. each time it appears
	- Multivariable Chain Rule
		![[Pasted image 20251017185649.png]]
	- "Backpropagation through time": sum up gradients over timesteps
		![[Pasted image 20251017185743.png]]
- Evaluation of Language Models
	- The standard evaluation metric for Language Models is **perplexity**:
		$\text{perplexity} = \prod_{t=1}^T \left( \frac{1}{P_{\text{LM}}(x^{(t+1)} \mid x^{(t)}, \ldots, x^{(1)})} \right)^{1/T}$
		- $1/T$: Normalized by number of words
		- $\prod_{t=1}^T (...)$: Inverse probability of corpus, according to Language Model
		- *Perplexity* lower is better.
			- *Perplexity* is # of uniform choices you are choosing from in some say.
	- This is equal to the exponential of the cross-entropy loss $J(\theta)$:
		$= \prod_{t=1}^T \left(\frac{1}{\hat{y}_{x^{(t+1)}}^{(t)}} \right)^{1/T} = \exp \left( \frac{1}{T} \sum_{t=1}^T -\log \hat{y}_{x^{(t+1)}}^{(t)} \right) = \exp(J(\theta))$
- Problems with RNN: Vanishing Gradient & Exploding Gradient
	- Q. Why is Vanishing Gradient a problem?
		![[Pasted image 20251017200118.png]]
		- Gradient signal *from far away* is lost because it’s much smaller than gradient signal *from close-by*.
		- Thus model weights are basically updated only with respect to *near effects*, not *long-term effects*.
	- Q. Why is Exploding Gradient a problem?
		- If the gradient becomes too big, then the SGD update step becomes too big.
		- This can cause bad updates: we take too large a step and reach a weird and bad parameter configuration (with large loss).
		- Solution: Gradient Clipping
			- If the norm of the gradient is greater than some threshold, scale it down before applying SGD update

# LSTM: Long Short-Term Memory RNN

- The main problem is that it’s too difficult for the RNN to learn to preserve information over many timesteps.
	- In a vanilla RNN, the hidden state is constantly being rewritten.
	- Could we design an RNN with separate memory which is added to?
- LSTM
	![[Pasted image 20251017201943.png]]
	- On step t, there is a **hidden state** $h^{(t)}$ and a **cell state** $c^{(t)}$
		- Both are vectors length $n$
		- The cell stores long-term information
		- The LSTM can *read, erase, and write* information from the cell
	- The selection of which information is erased/written/read is controlled by three corresponding gates (gates are calculated things whose values are probabilities)
		- The gates are also vectors of length $n$
		- On each timestep, each element of the gates can be open(1), closed (0), or somewhere in-between
		- The gates are dynamic: their value is computed based on the current context
		![[Pasted image 20251017202801.png]]
	- It is the + sign that makes the memory addictive, much easier to preserve information over timesteps.
- Q. Is vanishing/exploding gradient just an RNN problem?
	- No! It can be a problem for all neural architectures (including feed-forward and convolutional neural networks), especially very deep ones.
	- Another solution: Add more direct connections (thus allowing the gradient to flow)
	- Residual connections, a.k.a. "ResNet" or skip-connections
		- The identity connection preserves information by default.
		- This makes deep networks much easier to train.
		![[Pasted image 20251017203939.png]]

## Machine Translation

- Early: Statistical Machine Translation
- Traditional: Neural Machine Translation (NMT)
	- NMT is a way to do Machine Translation with a *single end-to-end neural network*.
	- The neural network architecture is called a **sequence-to-sequence model** (aka **seq2seq**) and it involves *two* RNNs (encoder and decoder)
	![[Pasted image 20251017210223.png]]
- Sequence-to-sequence is versatile.
	- The general notion here is an **encoder-decoder model**.
		- One neural network takes input and produces a neural representation.
		- Another network produces output based on that neural representation.
		- If the input and output are sequences, we call it a seq2seq model.
	- Many NLP tasks can be phrased as sequence-to-sequence
- The sequence-to-sequence model is an example of a **Conditional Language Model**
	- Language Model because the decoder is predicting the next word of the target sentence $y$
	- Conditional because its predictions are also conditioned on the source sentence $x$
	![[Pasted image 20251017210742.png]]
- Evaluation: BLEU (Bilingual Evaluation Understudy)
	- BLEU compares the machine-written translation to one or several human-written translation(s), and computes a similarity score based on:
		- Geometric mean of n-gram precision (usually for 1, 2, 3 and 4-grams)
		- Plus a penalty for too-short system translations
	- BLEU is useful but imperfect
		- There are many valid ways to translate a sentence.
		- Therefore, a good translation can get a poor BLEU score because it has low n-gram overlap with the human translation.
