- Floating Points: FP32 (4 bytes in memory)
	- Exponent: 8 bits
	- Digits: 23 bits
	![[Pasted image 20260206114702.png]]
- Possible solution to save memory: use FP16
	- FP16
		- Exponent: 5 bits
		- Digits: 10 bits
	- Issues:
		- Less range: Roughly 2e-14 to 2e15 on both sides
		- Smaller precision leads to rounding errors: 1.0001 is 1 in half precision
		- For Neural Net training:
			- Gradients can underflow
			- Weight updates are imprecise
- Solution: **Mixed Precision Training**
	![[Pasted image 20260206115227.png|1000]]
	- Still use FP16, but use FP32 for neural network updates
	- But upcasting cannot solve gradient underflow!
	- Solution: Scale a little
	![[Pasted image 20260206115431.png]]
- Q. Can we get rid of gradient scaling?
	- BFP16!
