## LM Agent Training - BAGEL

- Q. The standard practice is to do in-context learning with few-shot demonstrations of humans performing following similar instructions, which is still not scalable/reliable.
- **BAGEL** (**Bootstrapping Agents by Guiding Exploration with Language**)
	![[Pasted image 20260228174650.png]]
	- Idea: Use Exploration + Model Generated Data
		- Similar to use LM to generate rationales and train models with that.
	- Exploration:
		1. Let one LM to explore and generate some trajectories.
		2. Let another LM to generate a description based on the trajectory. One trajectory is meaningful if it can be described by some natural language.
		3. Add these meaningful trajectories to the dataset.
		![[Pasted image 20260228174109.png]]
	- Iterative Relabeling: The model is given an instruction and asked to map it to a sequence of actions.
		- If correct, add it to the dataset.
		- If not correct, take that trajectory, ask another LM to generate a description based on it, and add to the dataset.
			- The cost of generating one trajectory is high, and the generated trajectory maybe meaningful.
- Application: In-context exemplars / Fine-tuning
