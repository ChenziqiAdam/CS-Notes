- `if`, `elif`, `else`
- `match`, `case`
- Example:
	```Python
	answer = input("Do you agree? ").strip().lower()
	if answer.startswith("y"):
		print("Agreed")
	else:
		print("Not agreed")

	name = input("What's your name? ")
	if name == "Harry" or name == "Hermione" or name == "Ron":
		print("Gryffindor")
	elif name == "Draco":
		print("Slytherin")
	else:
		print("Who?")

	name = input("What's your name? ")
	match name:
		case "Harry":
			print("Gryffindor")
		case "Hermione":
			print("Gryffindor")
		case "Ron":
			print("Gryffindor")
		case "Draco":
			print("Slytherin")
		case _: # Similar to default
			print("Who?")
```
