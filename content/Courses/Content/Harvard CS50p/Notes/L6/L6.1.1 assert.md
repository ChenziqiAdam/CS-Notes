 - `assert`: <u>claim something should be true</u>, if not Python will warn `AssertionError`
	- Example: 
		```Python
		from calculator import square

		def main():
			test_calculator()
			
		def test_calculator():
			try:
				assert square(0) == 0
			except AssertionError:
				print("0 squared was not 0")
			try:
				assert square(-2) == 4
			except AssertionError:
				print("-2 squared was not 4")

		if __name__ == "__main__":
			main()
```
