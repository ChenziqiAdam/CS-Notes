- Beside instance variables/methods, there are also **class variables/methods**.
- `@classmethod` and `cls`: means the method can be called without initializing an instance first, and such methods takes in a argument `cls` instead of `self`.
	- Example: sorting hat (分院帽)
		```Python
		import random
		
		class Hat:
		
			houses = ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"] # class variables, making the data more clear and managable
			
			@classmethod
			def sort(cls, name): # class method
				print(name, "is in", random.choice(cls.houses))
			
		name = input("Name: ")
		Hat.sort(name)
```
- Q. when to use classes? 
	To represent real world entities, i.e. a mold or template.
	- For a **singleton**(单例), there is no need or consistency to use classes, e.g. sort hat.
- Q. then why just use functions instead of a class?
	- Better organize code, making related data more manageable and convenient to use
- Example: better `student.py` with `cls()`
	```Python
	class Student:
		def __init__(self, name, house, patronus=None):
```
