- Example: `tuple`
	```Python
		def main():
			name, house = get_student() # unpack sequences of value
			print(f"{name} from {house}")
	
		def get_student():
			name = input("Name: ")
			house = input("House: ")
			return name, house # actually return a tuple
			
		if __name__ == "__main__":
			main()
```
- `tuple`(元组): <u>a set or collection of data</u>
	- similar to `list`, both use `[]` to access the content.
	- unlike `list`, `tuple` is immutable.
		- But if there is a `list` inside a `tuple`, the content of the list is still mutable.
	- Q. when `tuple` and when `list`
		use `tuple` for defensive coding, i.e. the programmer do not want others to change the value in the collection.
	- Example: better `tuple`:
		```Python
		def main():
			student = get_student()
			print(f"{student[0]} from {student[1]}")
	
		def get_student():
			name = input("Name: ")
			house = input("House: ")
			return (name, house) # treat as a tuple
	```
