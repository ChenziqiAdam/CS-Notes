- Classes can overwrite Python built-in methods.
	- Example: `__str__()`
		- If directly `print(student)`, there will be the location of the `student` object in RAM due to Python will automatically trigger the default method `__str__()`.
		```Python
		class Student:
			def __init__(self, name, house):
				if not name: # if name == ""
					raise ValueError("Missing name!")
				if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
					raise ValueError("Invalid house!")
				self.name = name
				self.house = house
				
			def __str__(self):
				return (f"{self.name} from {self.house}")
```
