- Q. how to make the data inside the class immutable?
	use ***properties*** and ***decorators***
	- `@property`
		- `@`: ***decorators***, which are functions that modify other functions
	- Example: **getter** and **setter**
		```Python
		class Student:
			def __init__(self, name, house, patronus=None):
				if not name:
					raise ValueError("Missing name!")
				self.name = name
				self.house = house # trigger Python to call the setter
				self.patronus = patronus
				
			# getter
			@property
			def house(self):
				return self._house
				
			# setter
			@house.setter
			def house(self, house):
				if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
					raise ValueError("Invalid house!")
				self._house = house
```
		- Now even if write code `student.house = "Number Four, Privet Drive"`, Python will automatically call the function `house` preventing accessing the `.house` attribute.
		- **Python does not allow instance variable and instance methods have the same name, which will cause name conflicts.**
	- `getter` usually takes in one argument `self`, while `setter` usually takes in two or more arguments.
	- Example: better code
		```Python
		class Student:
			def __init__(self, name, house, patronus=None):
				self.name = name
				self.house = house
			
			@property
			def name(self):
				return self._name
				
			@name.setter
			def name(self, name):
				if not name:
					raise ValueError("Missing name!")
				self._name = name
				
			@property
			def house(self):
				return self._house
				
			@house.setter
			def house(self, house):
				if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
					raise ValueError("Invalid house!")
				self._house = house
```
		- Now the instance variable is called `_name` and `_house`, while the property is called `name` and `property`.
	- Python does not support `public` or `private` in Java. **So it is an honor system that every programmer should obey not to touch the variables starting with `_` "the underscore".**
		- `__` two underscores is also a warning "DO NOT TOUCH THIS!"
