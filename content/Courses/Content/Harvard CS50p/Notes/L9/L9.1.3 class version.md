- `classes`: a class is blueprint or mold for objects, i.e. custom own data type
	- Example: `class`
		```Python
		class Student: # class
			...
			
		def main():
			student = get_student()
			print(f"{student.name} from {student.house}")

		def get_student():
			student = Student() # instantiation
			student.name = input("Name: ") # attribute of the Student class
			student.house = input("House: ") # attribute
			return student
```
- Classes can have methods, i.e. **instance method**.
	- Example: better class
		```Python
		class Student: # class
			def __init__(self, name, house): # instance method
				self.name = name
				self.house = house
		
		def get_student(): # instance method
			name = input("Name: ")
			house = input("House: ")
			student = Student(name, house) # object
			return student
			# return Student(name, house)
```
		- `__init__(self)`: instance method, also **initialization method** here (similar to *constructor* in Java) 
			- `__init__`: is called "dunder init"
			- `self`: necessary argument for all methods inside a class
	- Example: more defensive: `raise` and `try`
		```Python
		class Student:
			def __init__(self, name, house):
				if not name: # if name == ""
					raise ValueError("Missing name!")
				if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
					raise ValueError("Invalid house!")
				self.name = name
				self.house = house
		
		def get_student():
			name = input("Name: ")
			house = input("House: ")
			try:
				return Student(name, house)
			except Value:
				...
```
		- `raise`: enable programmers to create their own errors or raise exceptions mannually.
			- This can avoid exiting the system without saving data.
