- **float**: numbers that have decimal point
	- `round()`: 
		- `round(number[, ndigits])`
		- **For square brackets in documentations, this means something optional.**
		- can add the number of digits programmers want
		- by default round up to the nearest integer
	- Q. what if programmers want to see something like "1, 000"
		```Python
		x = 3000.000
		y = 2000.00
		z = round(x + y, 2)
		w = x / y

		print(f"{z:,}")
		print(f"{w:.2f}") # Similar to round()
```
		```YAML
		1,000.00
		0.67
```
