- **str**: string
	More about str:
	- `name = name.strip()`: remove all whitespace from str
	- `name = name.capitalize`: capitalize the first letter
	- `name = name.title()`: capitalize the first letter in each word
	- `name = name.strip().title()`
		can combine as many functions as programmers want
		**Although more space-saving, less readability.**
	**Always learn to read the official document**
	Other about str:
	- `first, last = name.split(" ")`: split the input with whitespace
