- **`def`**
- Example:
	```Python
	def main():
		hello()
		name = input("What's your name? ")
		hello(name)
		return 0
		
	def hello(to="world"):
		print("Hello,", to)

	main()
```
	```YAML
	Hello, world
	Hello, Adam
```
	- `to`: parameter to the function
	- `to="world"`: parameter by default if no parameter is passed
