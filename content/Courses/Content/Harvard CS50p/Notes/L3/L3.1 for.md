- `for`
	- Example:
		```Python
		# Simple for loops
		for i in [0, 1, 2]: # for loop using a list
			print("meow")
			
		for i in range(3): # for loop using range
			print("meow")
			
		for _ in range(3): # for loop with _ as a variable
			print("meow")
			
		print("meow\n" * 3, end="") # str multiplication
	
		# Nested for loop
		for i in range(3):
			for i in range(3):
				print("#", end="")
			print()
	
		for _ in range(3):
			print("#" * 3)
```
