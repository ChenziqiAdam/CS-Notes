- **CLA: command-line argument**
	- for productivity and speed: avoid typing the same thing again and again
	- `sys.argv`: <u>argument vector</u>: `list`
	- Example: `sys`
		```Python
		import sys
	
		try: 
			print("Hello, my name is", sys.argv[1])
		except IndexError:
			print("Enter your name: ")
```
		```csharp
		python hello.py David
		Hello, my name is David
	
		python hello.py David Malan
		Hello, my name is David
	
		python hello.py "David Malan" // Use quotes s.t. the full name is regarded as a whole
		Hello, my name is David Malan
```
		```Python
		import sys
	
		# Check for the potential errors
		if len(sys.argv) < 2:
			sys.exit("Too few arguments")
		elif len(sys.argv) > 2:
			sys.exit("Too many arguments")
	
		# if no error, execute the following code
		print("Hello, my name is", sys.argv[1])
```
		- `sys.exit()`: end the program and pop out the warning
		- this is necessary s.t. there will not happen `IndexError` when `print()`
	- Example:
		```Python
		import sys
	
		if len(sys.argv) < 2:
			sys.exit("Too few arguments")
	
		for arg in sys.argv[1:]:
			print("Hello, my name is", arg)
```
		- `sys.argv[1:]`: ***slices***
			- a way to extract a subset from a sequence like `list`, `tuple`, `str`
			- `sequence[start:end:step]`
			- also support **slice** from the end, i.e. `sys.argv[1,-1]` ignore the last item
