- Example:
	```Python
	# sayings.py
	def hello(name):
		print(f"hello, {name}")

	def main():
		hello("world")

	if __name__ == "__main__":
		main()
```
	```Python
	# say.py
	import sys
	from sayings import hello

	if len(sys.argv) == 2:
		hello(sys.argv[1])
```
	- `if __name__ == "__main__"`: is necessary s.t. the `main()` function won't be called everytime the module is called.
	- i.e.
		- if remove `if __name__ == "__main__"`:
			```csharp
			python say.py David
			hello, world
			hello, David
```
		- add `if __name__ == "__main__"`:
			```csharp
			python say.py David
			hello, David
```
	- `from sayings import hello`: Python will san the `sayings.py` and find the `hello()` function
		- however, if `main()` is in the end without `if __name__ == "__main__"`, it will be executed
	- `__name__`: the special variable is set by default `__main__` when run a file from command line
