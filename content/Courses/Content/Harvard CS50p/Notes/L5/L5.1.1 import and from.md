- `import`&`from`
	1. Example `random.choice(seq)`:
		```Python
		import random
	
		coin = random.choice(["head", "tail"])
		print(coin)
	
		# Below is another way to implement
		from random import choice()
	
		coin = choice(["head", "tail"])
		print(coin)
```
	- Compared to the first version, the second is more concise and clean.
	- However, it is confusing to have one's own `choice()` function (or variable) in the second version, i.e. name conflicts.
