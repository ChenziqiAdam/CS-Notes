- Q. In real world, users always do not follow the format, how do programmers format those input and store the correct version?
	- Example: name
		```Python
		import re
		
		name = input("What's your name? ").strip()
		matches = re.search(r"(^.)+, *(.+)$")
		if matches:
			last, first = matches.groups()
			# last = matches.group(1)
			# first = matches.group(2)
			name = f"{first} {last}"
		print(f"hello, {name}")
```
	- `re.search(r"(^.)+, (.+)$")`: recall `()` in *regexes* is a capturing group, which means later the programmer can access the content
	- Q. what is `group(0)`: the original string
- Example: tighter version
	```Python
	if matches := re.search(r"(^.)+, *(.+)$"):
		name = matches.group(2) + " " + matches.group(1)
```
	- `:=`: <u>walrus operator</u>
		supports assigning a boolean value while asking a boolean condtional question
