- Q. how to extract the username by the URL `https://twitter.com/davidjmalan`
	- Example: assuming formatted input
		```Python
		url = input("URL: ").strip()
		
		username = url.replace("https://twitter.com/", "")
		print(f"Username: {username}")
```
- But in real world, this is too good to be true. That is where *regexes* comes in.
- `re.sub(pattern, repl, string, count=0, flags=0)`
	- Example:
		```Python
		import re
		
		url = input("URL: ").strip()
		
		username = re.sub(r"^(https?://)?(www\.)?twitter\.com/.+$", "", url)
		print(f"{username}")
```
		- `\.com`: the `\` here is a must! 
			**Pay attention to special symbols!**
		- `https?`: there may be `https` or `http`
- **It is always difficult to write out the *regexes* all at once!**
	**Step by step!**
- Q. what if the user even did not type his username?
	`re.search()`
	- Example:
		```Python
	re.search(r"^(https?://)?(www\.)?twitter\.com/(.+)$", "", url, re.IGNORECASE)
	if matches:
		print(f"Username:", matches.group(2))
```
		- `group(2)`: `group(1)` is `(www\.?)`
	- Example: tighter version
		```Python
		if matches := re.search(r"^(https?://)?(?:www\.)?twitter\.com/(.+)$", "", url, re.IGNORECASE):
			print(f"Username:", matches.group(1))
```
		- `(?:www\.)`: recall `(?:...)` is non-captruing group
	- Example: more close to real world
		handle domain name and limited username
		```Python
		if matches := re.search(r"^(https?://)?(?:www\.)?twitter\.(.*)/\w$", "", url, re.IGNORECASE):
			if matches.group(1) == "com":
				print(f"Username:", matches.group(1))
```
