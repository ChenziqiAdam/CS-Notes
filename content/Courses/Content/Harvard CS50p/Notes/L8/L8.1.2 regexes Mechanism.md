- Underneath Mechanism of *regexes*
	***pattern matching machine***
	- Two primary types:
	1. **DFA (Deterministic Finite Automaton)**
		- fast, no backtracking (single path), less flexible
		```Rust
		States:
		[Start] --> a --> [State 1] --> b --> [State 2] --> c --> [State 3] --> f --> [End]
		                    |          \--> d --> [State 4] --> e --> [State 5] --> f --> [End]
```
	2. **NFA (Nondeterministic Finite Automaton)**
		- flexible, uses backtracking (multiple paths with choices), can be slower
		- This is how `re` module implements.
		```Rust
		States:
		[Start] --> a --> [State 1] --> b --> [State 2] --> c --> [State 3] --> f --> [End]
		                    |          \--> d --> [State 4] --> e --> [State 5] --> f --> [End]
```
