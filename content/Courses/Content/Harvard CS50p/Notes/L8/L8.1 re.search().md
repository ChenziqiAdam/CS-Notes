- [[L8.1.1 regexes Symbols]]
- Example: email
	```Python
	import re
		
	email = input("What's your email? ").strip()

	if re.search(r"^.+@.+\.edu$", email):
		print("Valid")
	else:
		print("Invalid")
```
	- `\.`: similar to `\n`, want to contain literally one `.`
	- `r"..."`: <u>raw string</u>, i.e. Python will treat the whole string to the function as it literally is
- [[L8.1.2 regexes Mechanism]]
- Q. so for is not good enough, `malan@@@harvard.edu` is still valid even if it is invalid in fact.
	- `[]`: <u>set of characters</u>
	- `[^]`: <u>complementing the set (补集)</u>
	- Example
	```Python
	if re.search(r"^[a-zA-Z0-9_]+@[a-zA-Z0-9_]+\.edu$", email):
		print("Valid")
	else:
		print("Invalid")
```
	- `a-z`: <u>means the range from 'a' to 'z'</u>
- Example: better version
	```Python
	if re.search(r"^\w+@\w+\.edu$", email):
		print("Valid")
	else:
		print("Invalid")
```
	- `\w`: <u>alphanumeric symbol or the underscore</u>, i.e. the same effect as `a-zA-Z0-9_`

	[[L8.1.4 regexes Syntax]]
- Q. what if the user types in upper case?
	- `re.search()` can take in more arguments, i.e. `flags`.
	- Common built-in variables (constants) in `re` library
		- `re.IGNORECASE`: <u>ignore the case of input</u>
		- `re.MULTILINE`: <u>handle paragraph input</u>
		- `re.DOTALL`
	- Example:
		```Python
		if re.search(r"^\w+@\w+\.edu$", email, re.IGNORECASE):
			print("Valid")
		else:
			print("Invalid")
```
- Q. what if the email has sub domain?
	- Example: `?`
		```Python
		if re.search(r"^(\w^\.)+@(\w+\.)?\w+\.edu$", email, re.IGNORECASE):
			print("Valid")
		else:
			print("Invalid")
```
- It is always too demanding for programmers to type in *regexes*. There must be libraries that exist for this purpose!
	- `re.match(pattern, string, flags=0)`
	- `re.fullmatch(pattern, string, flags=0)`
