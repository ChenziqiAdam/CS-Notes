- Python is a dynamically typed language, i.e. Python will automatically recognize the type of the variable.
	But there maybe bugs.
- `mypy`: a program help Python programmers check variable types with type hints
	`pip install mypy`
	- Example: `input()` return a `str`
		```Python
		# meows.py
		def meow(n: int) -> None: # hint the return value of the function
			for _ in range(n):
				print("meow")
				
		n: int = input("Number: ")
		# correct code:
		# n: int = int(input("Number: "))
		meow(n)
```
	- <u>run</u>: `mypy meows.py`
	- Example: another meow
		```Python
		def meow(n: int) -> str:
			return "meow\n" * n
			
		n: int = int(input("Number: ")) # convert str to int by the int() function
		meows: str = meow(n)
		print(meows, end="")
```
