- `map(function, variable)`: <u>map the function to every element in the collection of variables</u>
	- Example: naive yell
		```Python
		def main():
			yell("This", "is", "CS50")
			
		def yell(*words)
			uppercased = []
			for word in words:
				uppercased.append(word.upper())
			print(*uppercased)
			
		if __name__ == "__main__":
			main()
```
	- Example: better yell
		```Python
		def yell(*words):
			uppercased = map(str.upper, words)
			print(*uppercased)
```
		- `str.upper`: no `()` as no need to call the function here but to pass it to the `map()` function
