- ***PEP*: Python Enhancement Proposal**
	standalize how to document the code
	- Example: `meow()`
		```Python
		def meow(n: int) -> str:
			"""
			Meow n times.
			
			:param n: Number of times to meow
			:type n: int
			:raise TypeError: If n is not an int
			:return: A string of n meows, one per line
			:rtype: str
			"""
			return "meow\n" * n
			
		n: int = int(input("Number: "))
		meows: str = meow(n)
		print(meows, end="")
```
		- ***reStructuredText***: one language similar to Markdown used for documents
			one convential way for Python to document code
