- Example: wizard bank
	```Python
	def total(galleons, sickles, knuts):
		return (galleons * 17 + sickles) * 29 + knuts
		
	galleons = input("Galleons: ")
	sickles = input("Sickles: ")
	knuts = input("Knuts: ")
	coins = [galleons, sickles, knuts]
	
	print(total(*coins), "Knuts")
```
	- `*`:  <u>unpacking operator for list</u>
		automatically split the `coins` list and pass three arguments to the function
		- order preserving for lists, dictionaries, but not sets
	- For individual data, only can access by positional argument
		- If only three arguments are required but after unpacking passes four arguments, there will be an error.
