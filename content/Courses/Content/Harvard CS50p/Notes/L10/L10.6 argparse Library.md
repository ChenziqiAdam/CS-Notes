- `argparse`: a library that can handle CLA s.t. the programmers do not to worry about that part and focus on the really juicy part of the code
- CLA: `-` + one letter, `--` + one word
	- `python meows.py -h` or `python meows.py --help`: ask for help
	- Example: meow with CLA: `argparse` instead of `sys`
		```Python
		# meows.py
		import argparse
		
		parser = argparse.ArgumentParser(description="Meow like a cat")
		parser.add_argument("-n", default=1, help="number of times to meow", type=int) # interpreter
		args = parser.parse_args()
		
		for _ in range(int(args.n)):
			print("meow")
```
		- **==Always Turn to the Official Documents for Help!==**
		- `args.n` is the value of the `-n` argument provided by the user
			- if the user did not provide the `-n` argument, it will be `1` by default, making the code more robust
			- even if the user does not coorperate and types in a string, the `argparse` library will automatically generate a error message.
		- <u>run</u>: `python meows.py -h` or `python meows.py --help`
			```bash
			usage: meows.py [-h] [-n N]
			
			Meow like a cat
			
			optional arguments:
			  -h, --help  show this help message and exit
			  -n N        number of times to meow (default: 1)
```
			- `[]`: means optional in documents
