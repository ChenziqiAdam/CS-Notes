- Constants: a way to code more defensively
- However, Python does not support `constant` like Java. It is a convention to capitalize the variables and warn others not to touch them
	- Example: meow
		```Python
		class Cat:
			MEOWS = 3 # mean a constant
			
			def meow(self):
				for _ in range(Cat.MEOWS):
					print("meow")
					
		cat = Cat()
		cat.meow()
```
