- Q. if one function that takes in too much data, the computer's memory may run out quickly.
	***Generators***
- `yield`: <u>allow functions to return one value at a time</u>
	- Example: sheep
		```Python
		def main():
			n = int(input("What's n?"))
			for s in sheep(n):
				print(s)
				
		def sheep(n): # generator function
			for i in range(n):
				yield "#" * i
				
		if __name__ == "__main__":
			main()
	```
	- Underneath `yield` returns a ***iterator***.
