- `*args` and `**kwargs`: enable functions to take in uncertain number of arguments, such functions are called ***variadic functions***
	- `*args`: **positional arguments**
	- `**kwargs`: **keyword arguments (named arguments)**
	- Example:
		```Python
		def f(*args, **kwargs)
			print("Positional:", args)
			print("Named:", kwargs)
			
		f(galleons=100, sickles=50, knuts=25)
		f(100, 50, 25)
```
		- Output
			```yaml
			Positional: ()
			Named: {'galleons': 100, 'sickles': 50, 'knuts': 25} # a dictionary
			Positional: (100, 50, 25) # a sequence
			Named: {}
```
