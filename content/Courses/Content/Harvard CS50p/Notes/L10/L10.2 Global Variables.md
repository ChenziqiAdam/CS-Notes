- For global variables, they are only readable but <u>immutable</u>.
- Q. how to allow the global variables mutable?
	`global`
	- Example: balance(余额)
		```Python
		balance = 0
		
		def main()
			print("Balance:", balance)
			d = input("Deposit: ")
			deposit(d)
			w = input("Withdraw: ")
			withdraw(w)
			print("Balance:", balance)
			
		def deposit(n):
			global balance
			balance += n
			
		def withdraw(n):
			global balance
			balance -= n
```
	- If the programmer create another local variable with the same name as the global variable, it will shatter the global one tempararily.
	- If the programmer change an argument passed to a function, it will just change the copy of that variable instead of the variable itself.
	- Example: better ***encuplsulation***: *OOP*
		```Python
		class Account:
			def __init__(self):
				self._balance = 0
				
			@property
			def balance(self):
				return self._balance
				
			def deposit(self, n):
				self.balance += n
				
			def withdraw(self, n):
				self.balance -= n
				
		def main():
			account = Account()
			print("Balance:", account.balance)
			account.deposit(100)
			account.withdraw(50)
```
- Global variables are not encouraged to use in many cases, as it makes the code messier, harder to see where the variable stores.
