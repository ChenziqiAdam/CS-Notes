- Example：
	```Python
	names = []

	with open("names.txt", "r") as file:
		for line in file:
			names.append(line.rstrip())

	for name in sorted(names):
		print(f"hello, {name}")

	# Another version with the original file changed
	with open("names.txt", "r") as file:
		for line in sorted(file):
			names.append(line.rstrip())
```
	- `line.rstrip()`: remove the whitespaces at the end of each line
	- `sorted()`: sort alphabetically here
		- for more ways to sort, **Learn to Read the Official Document**
		- `sorted(iterble, /, *, key=None, reverse=False)`
