- File: store the information s.t. it won't disappear when the program ends
- Example:
	```Python
	name = input("What's your name? ")

	file = open("names.txt", "w")
	file.write(name)
	file.close()
```
	- `open("names.txt", "w")`: <u>open the file named "names.txt"</u>, if the file doesn't exit then create one
		- `"w"`: everytime remove the old file and create a new file
	- Q. what if the programmer wants to add at the end without writing the file?
		- `open("names.txt", "a")
- Example: better version
	```Python
	with open("names.txt", "a") as file:
		file.write(f"{name}\n")
```
	- `with open("names.txt", "a") as file`: <u>this will automatically close the file, i.e. guarantee that the file is closed after the operations</u>.
