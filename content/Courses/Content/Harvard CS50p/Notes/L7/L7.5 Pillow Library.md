- Python almost supports operation on every kind of data or file, e.g. `pillow` library.
- Example: `.gif`
	```Python
	import sys
	
	from PIL import Image
	
	images = []

	for arg in sys.argv[1:]:
		image = Image.open(arg)
		images.append(image)

	images[0].save{
		"costumes.gif", save_all=True, append_images=[images[1]], duration=200, loop=0
	}
```
	- `cuostumes.gif`: saved file name
	- `duration=200`: pause every 200 milliseconds
	- `loop=0`: loop infinite times
