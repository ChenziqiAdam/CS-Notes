	- Q. is quick sort stable?
		Depends on your partitioning strategy.
		- Three array partitioning is stable, but Hoare partitioning is not.
- Additional tricks to optimize sorts:
	- Switch to insertion sort:
		- When a subproblem reaches size 15 or lower, use insertion sort.
	- Make sort adaptive: Exploit existing order in array (Insertion Sort, SmoothSort, TimSort (the sort in Python and Java)).
	- Exploit restrictions on set of keys. 
		- If number of keys is some constant, e.g. \[3, 4, 1, 2, 4, 3, …, 2, 2, 2, 1, 4, 3, 2, 3], can sort faster (3-way quicksort).
	- For Quicksort: Make the algorithm introspective, switching to a different sorting method if recursion goes too deep.
