- Search for key.
	- If found, do nothing.
	- If not found:
		- Create new node.
		- Set appropriate link.
	```Java
	static BST insert(BST T, Key ik) {
		if (T == null) {
		    return new BST(ik);
		}
		if (ik < T.key) {
			T.left = insert(T.left, ik);
		}
		else if (ik > T.key) {
			T.right = insert(T.right, ik);
		}
		return T;
	}
```

	if (T.left == null) {
