- Q. how to search in an ordered linked list set?
	`A -> B -> C -> D -> E -> F -> G`
	- Naive Approach: iterate through the whole list
		- Slow search! Even though it's in order.
	- Optional idea: Optimization: extra links
		- Add (random) express lanes.
		- *Skip List*
		`A -> B -> C -> D -> E -> F -> G`
		` \_______/      \____________/`
	- Better Approach: change the entry point (from A to D)
		- Move pointer to middle and flip left links. 
		- Halved search time!
					  `|`
		`A <- B <- C <- D -> E -> F -> G`
	- Q. what can we do even better?
		- Dream bigger!
			```Shell
				D
		      /   \
		     B     F
		    / \   / \
		   A   C E   G
		```
