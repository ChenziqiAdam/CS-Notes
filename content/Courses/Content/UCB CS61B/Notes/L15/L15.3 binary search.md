- To find a key in a sorted array, compare the key with the **middle** entry
	- Small, go left
	- Big, go right
	- Equal, found
- Q. Binary Search is trivial to implement?
	- Idea published in 1946.
	- First correct implementation in 1962.
		- Bug in Java’s binary search discovered in 2006.
```Java
static int binarySearch(String[] sorted, String x, int lo, int hi) {
    if (lo > hi) {
	    return -1;
	}
    int m = (lo + hi) / 2;
    int cmp = x.compareTo(sorted[m]);
    if (cmp < 0) {
	    return binarySearch(sorted, x, lo, m - 1);
	} else if (cmp > 0) {
	    return binarySearch(sorted, x, m + 1, hi);
	} else {
		return m;
	}
}
```
