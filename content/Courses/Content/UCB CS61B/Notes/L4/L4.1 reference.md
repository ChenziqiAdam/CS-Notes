- While declaring a variable of a certain type,
	- Java does NOT write anything into the reserved boxes. Also, Java will not let access a variable that is uninitialized.
- ***Golden Rule of Equal (GRoE)***
	- Given variables `b` and `a`:
		`b = a` copies all the bits form a into b
	- Passing parameters obeys the same rule:
		simply copy the bits to the new scope (Pass by Value)
- **Primitive Types** vs. **Reference Types**
	- 8 * Primitive Types: `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`
	- Reference Types: all else
- **Parameter Passing**: *parameter passing* also follows the *GRoE*, i.e. <u>copy</u> the bits from the variables into the parameter variables.
