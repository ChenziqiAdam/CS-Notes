### 1. Spanning Trees
- Given an **undirected** graph, a ***spanning tree*** T is a subgraph of G, where T:
	- Is connected
	- Is acyclic(无环的) 
	- Includes all the vertices
	The first two properties make it a tree, and the last one makes it spanning.
	![[Pasted image 20240911105108.png]]
- A ***minimum spanning tree (MST)*** is a spanning tree of minimum total weight.
### 2. MST vs. SPT
- Q. is the MST also an SPT (shortest paths tree) ?
	![[Pasted image 20240911105435.png]]
	In this case, SPT with node B as the starting node is also the MST for the graph.
	- A shortest paths tree depends on the start vertex:
		- Because it tells you how to get from a source to EVERYTHING.
	- There is no source for a MST.
		- The MST sometimes happens to be an SPT for a specific vertex.
	![[Pasted image 20240911105844.png]]
	In this case, there is no node whose SPT is also the MST. 
	Minimum spanning tree must include only 2 of the 2 weight edges, but the SPT always includes at least 3 of the 2 weight edges.
### 3. Cut Property: a useful tool for finding the MST
- A ***cut*** is an assignment of a graph’s nodes to two non-empty sets.
- A ***crossing edge*** is an edge which connects a node from one set to a node from the other set.
	![[Pasted image 20240911110217.png]]
- ***Cut Property***: Given any cut, minimum weight crossing edge is in the MST.
- Cut Property Proof
	Suppose that the minimum crossing edge e were not in the MST.
	- Adding e to the MST creates a cycle.
	- Some other edge f must also be a crossing edge.
	- Removing f and adding e is a lower weight spanning tree.
	- Contradiction!
	![[Pasted image 20240911110527.png]]
- Generic MST Finding Algorithm
	Start with no edges in the MST.
	- Find a cut that has no crossing edges in the MST. 
	- Add the smallest crossing edge to the MST.
	- Repeat until V-1 edges.
	But we need some way of finding a cut with no crossing edges!
