- There is a **1-1 correspondence** between an LLRB and an equivalent 2-3 tree. Implementation of an LLRB is based on maintaining this 1-1 correspondence.
	- When performing LLRB operations, pretend like you’re a 2-3 tree.
	- Preservation of the correspondence will involve **tree rotations**.
- Design Process
	- Task #1: Insertion color
		- Q. Should we use a red or black link when inserting?
		- Use red! In 2-3 trees new values are **ALWAYS** added to a leaf node (at first).
		![[Pasted image 20240906101615.png|800]]
	- Task #2: Insertion on the Right
		- Q. Suppose we have a leaf E, and insert S with a red link. Since right links aren’t allowed, what do we do?
		- Use trees rotation! `rotateLeft(E)`
		![[Pasted image 20240906101849.png]]
	- Task #3: Double Insertion on the Left
		- Q. Suppose we have the LLRB below and insert E. 
			- We end up with the wrong representation for our temporary 4-node. 
			- What should we do?
		- New Rule: Representation of temporary 4-nodes
			- We will represent temporary 4-nodes as BST nodes with two red links.
			- This state is only temporary (more soon), so temporary violation of “left leaning” is OK.
			![[Pasted image 20240906102132.png]]
		- Then use trees rotation! `rotateRight(Z)`
		![[Pasted image 20240906102436.png]]
	- Task #4: Splitting Temporary 4-Nodes
		- Q. Suppose we have the LLRB below which includes a temporary 4-node. What should we do next?
		- **Hint**: see what happens in 2-3 trees world?
		- Flip the colors of all edges touching B! `flip(B)`
			- Note: This doesn’t change the BST structure/shape.
		![[Pasted image 20240906103253.png]]
	- That's it!
		That is all for the red-black BST.
		- When inserting: Use a red link.
		- If there is a right leaning “3-node”, we have a **Left Leaning Violation**.
			- <u>Rotate left</u> the appropriate node to fix.
		- If there are two consecutive left links, we have an **Incorrect 4 Node Violation**.
			- <u>Rotate right</u> the appropriate node to fix.
		- If there are any nodes with two red children, we have a **Temporary 4-Node**.
			- <u>Color flip</u> the node to emulate the split operation.
		One last detail: Cascading operations.
		- It is possible that a rotation or flip operation will cause an additional violation that needs fixing.
	- Additional Task: Cascading Operation
		- Q. Color flip may yield an invalid tree, i.e. **right leaning red black tree**.
			- Below is an example that we get a right leaning 3-node (B-S)
			![[Pasted image 20240906103817.png]]
		- Fix with `rotateLeft(B)`!
		![[Pasted image 20240906103933.png]]
- In short, all the rules are:
	- **Right red link**: rotate left (the upper one)
	- **Two consecutive left links**: rotate right (the upper one)
	- **Red left and red right**: color flip
