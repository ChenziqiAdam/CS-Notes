- Q. why ALists instead of SLists?
	Random Access in Arrays
	- For Arrays, retrieval from any position of an array is very fast, which is indenpendent of the size of the array.
	- But for Slists, random access may be slow.
- AList **Invariants**:
	- The position of the next item to be inserted is always `size`
	- `size` is always the number of items inthe AList.
	- The last item in the list is always in position `size - 1`.
	- `removeLast()`:
		```Java
		public int removeLast() {
			int returnItem = items[size - 1];
			size -= 1;
			return returnItem;
		}
```
		- `items[size - 1] = 0`: not necessary for correctness, as the invariants are preserved.
		- **Abstraction**: programmers can do whatever they want as soon as give users what they want.
