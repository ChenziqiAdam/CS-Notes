```Java
public class AList<Glorp> {
	private Glorp[] items;
	private int size;

	public AList() {
		items = (Glorp []) new Objext[8]; // cast
		size = 0;
	}
	
	private void resize(int capacity) {
			Glorp[] a = (Glorp []) new Object[size + 1];
			System.arraycopy(items, 0, a, 0, size);
			items = a;
		}
		
	public Glorp get(int i) {
		return items[i];
	}
}
```
- Nulling out deleted items
	unlike integer based AList, actually need to null out deleted items
	- Java only destorys unwanted objects when the last reference has been lost.
	- Keeping references to unneeded objects is sometimes called **loitering**.
	- To save memory, avoid loitering.
	```Java
	public int deleteBack() {
			Glorp returnItem = getBack();
			items[size - 1] = null; // avoid wasting memory
			size -= 1;
			return returnItem;
		}
```
