- Given a dictionary, sort it by its keys.
- Idea: exploiting space instead of time
- Case #1: Keys are unique integers from 0 to N-1
	- Create a new array
	- Copy item with key i into ith entry of new array
- We just sorted N items in Θ(N) worst case time. Avoiding yes/no questions lets us dodge our lower bound based on puppy, cat, dog!
- Case #2: Non-unique keys
	- Count number of occurrences of each item
	- Iterate through list, using count array to decide where to put everything
	- See [CS61B counting sort demo](https://docs.google.com/presentation/d/1vmVKHRSwb5WN1rHvktplbPGecHChxOwWa7ovRuiLzbA/edit?usp=sharing).
- Bottom line, we can use counting sort to sort N objects in Θ(N) time. But in practice there is more to think.
