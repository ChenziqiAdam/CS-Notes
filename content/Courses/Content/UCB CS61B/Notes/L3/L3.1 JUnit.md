- Writing temporary tests for each program is tedious
	- **JUnit** is ad-hoc (for this particular purpose)
- JUnit is a library for making testing easier
- Example: **Selection Sort**
	- Selection Sort: 
		1. find the smallest item
		2. move it to the front
		3. Selection Sort the remaining N-1 items (without touching front item)
	- **Improvement #1: Simple JUnit**
		- `org.junit.Assert.assertEquals(expected, actual)`
			- test that `expected` equals `actual`
			- if not, program terminates with verbose message
		- JUnit does much more
			- other methods like `assertEquals` include `assertFlase`, `assertNotNull`, etc (**Read the Official Documentation**)
			- other more complex behavior to support more sophisticated testing (lab2)
	- **Improvement #2: Better JUnit**
		- Q. The messages output by JUnit are kind of ugly, and invoking each test manually is annoying.
			- Annotate each test with `@org.junit.Test`
			- Change all test methods to non-static (JUnit runners does instantiate TestSort.java)
			- Use a JUnit runner to run all tests and tabulate results
				- IntelliJ provides a default runner/renderer. OK to delete `main` (Black Magic). There are ways to run JUnit tests from command line.
				- Rendered output is easier to read, no need to manually invoke tests.
	- **Improvement #3: Even Better JUnit**
		- `import org.junit.Test`
		- `import static org.junit.Assert.*`
			- avoid typing out the name of the library repeatedly, e.g. `org.junit.` and `org.junit.Assert.`
	```Java
	import org.junit.Test;
	import static org.junit.Assert.*
	
	public class TestSort {
		/** Tests the sort method of the Sort class. */
		public static void testSort() {
			String[] input = {"cows", "dwell", "above", "clouds"};
			String[] expected = {"above", "clouds", "cows", "dwell"};
			Sort.sort(input);

			assertArrayEquals(expected, input);
		}
	}
```

		- Q. how to use recursion without changing the signature, i.e. `public tatic void sort(String[] x)`
			- Bad but tempting solution: 
				```Java
				public static void sort(String[] x) {
					int smallest = findSmallest(x);
					swap(inputs, 0, smallest);
					sort(x[1:]); // Would be nice, but not possible!
				}
```
				- Some languages support *sub-indexing* into arrays. Java does not. That is there is no way to get address of the middle of an array (Bottom Line).
			- Good solution
				```Java
				public static void sort(String[] x) {
					sort(x, 0);
				}

				/** Destructively sorts x starting at index k */
				public static void sort(String[] x, int k) {
					...
					sort(x, k + 1);
				}
```
