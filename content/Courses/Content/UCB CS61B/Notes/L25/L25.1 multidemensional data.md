- Suppose we want to perform operations on a set of Body objects in 2D space, like **2D Range Finding** and **Nearest Neighbors**.
	- Ideally, we’d like to store our data in a format (like a BST) that allows more efficient approaches than just iterating over all objects. But it doesn't work!
		![[Pasted image 20240912110903.png]]
	- Suppose we want to know “What are all the points with x-coordinate less than -1.5?
		- Equivalent to “What’s in the green rectangle?”
		- As for humans, this is easy to visually identify.
		- If we have the points stored in a list, then we’d have to iterate over the entire list.
			- Slow! Requires looking at every single point.
		- What about storing them in a BST ordered by X, then Y coordinate?
		![[Pasted image 20240912111045.png]]
- Building Trees of Two Dimensional Data
	- Suppose we put points into a BST map ordered by x-coordinate
		- put((-1, -1), A)
		- put(( 2,  2), B)
		- put(( 0,  1), C)
		- put(( 1,  0), D)
		- put((-2, -2), E)
		- put((-3, 2.5), F)
		![[Pasted image 20240912111408.png]]
	- Q. Given the BST, how to identify all the points with x-coordinate less than -1.5?
		- We can simply work our way down the tree, ignoring pursuing any options that are impossible.
		- For example, no need to go down the right child of A because no point over there could possibly have x coordinate < -1.5.
		- This process of cutting off a tree search early is called **“Pruning”**.
		![[Pasted image 20240912111550.png]]
	- If we’d used y coordinate for comparisons, we’d get a slightly different BST.
		- put((-1,  -1), A)  
		- put(( 2,   2), B)
		- put(( 0,   1), C)
		- put(( 1,   0), D)
		- put((-2,  -2), E)
		- put((-3, 2.5), F)
		![[Pasted image 20240912111750.png]]
	- Q. Given the BST below, identify all the points with x-coordinate less than -1.5.
		- Pruning is impossible!
		- E and F are not on the same side.
- Spatial Partitioning / Rectangle Intersection Interpretation
	In the X-oriented tree, the “A” node partitioned the universe into a left and right side.
	- Left: All points with X < -1.
	- Right: All points with X > -1.
	- Right side doesn’t intersect query rectangle.
	![[Pasted image 20240912112225.png]]
	![[Pasted image 20240912112249.png]]
	In the Y-oriented tree, the “A” node partitioned the universe into a top and bottom side.
	- Bottom (left): All points with Y < -1.
	- Top (right): All points with Y > -1.
	- Both sides intersect query rectangle.
	![[Pasted image 20240912112312.png]]
	![[Pasted image 20240912112329.png]]
