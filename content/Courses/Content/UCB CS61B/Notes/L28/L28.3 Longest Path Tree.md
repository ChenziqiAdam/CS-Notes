- Q. Consider the problem of finding the longest path tree (LPT) from s to every other vertex. Can you come up with an algorithm?
	- The path mush be simple, i.e. no cycles.
	**DAG LPT** solution for graph G:
	- Form a new copy of the graph G’ with signs of all edge weights **flipped**.
	- Run **DAGSPT** on G’ yielding result X.
	- Flip signs of all values in X.distTo. X.edgeTo is already correct.
	Too plain to prove or demo.
	- Actually the longest path problem is really hard to solve.
