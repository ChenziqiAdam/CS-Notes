- Q. Imaging a graph of courses, i.e. you have to take course CS61A before taking CS61B.
	- What algorithm do we use to find a valid ordering for these courses?
	- Valid orderings include: \[0, 2, 1, 3, 5, 4, 7, 6], \[2, 0, 3, 5, 1, 4, 6, 7], …
	![[Pasted image 20240926105050.png]]
	-  Possible Algorithm #1: Run DFS from `0` and `2` i.e. all vertices of in-degree 0
		- Works for this graph, but fails for others i.e. add a `8` pointing to `7`
- Solution: ***Topological Sort***
	- Perform a DFS traversal from every vertex with indegree 0, NOT clearing markings in between traversals.
		- Record DFS postorder in a list.
		- Topological ordering is given by the reverse of that list (reverse postorder).
	- Record DFS postorder in a list: \[7, 4, 1, 3, 0, 6, 5, 2]
	- Topological ordering is given by the reverse of that list (reverse postorder): \[2, 5, 6, 0, 3, 1, 4, 7]
- The reason it’s called topological sort: Can think of this process as sorting our nodes so they appear in an order consistent with edges.
	- When nodes are sorted in diagram, arrows all point rightwards.
		![[Pasted image 20240926105758.png]]
	- **Note**: For Topological Sort, we restarted DFS from every vertex with in-degree 0. However, when we did DFS for reachability, we did not restart.
- In fact, you don't have to run DFS from all vertices of in-degree 0. Another better topological sort algorithm:
	- Run DFS from an arbitrary vertex.
	- If not all marked, pick an unmarked vertex and do it again.
	- Repeat until done.
- ***Directed Acyclic Graphs (DAG)***
	- A topological sort only exists if the graph is a *directed acyclic graph (DAG)*.
	- Many graph algorithms only work on DAGs.
- Topological Sort Performance
	- O(V+E) time
	- Θ(V) space
