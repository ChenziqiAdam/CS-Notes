- Q. when we compare things, we want to compare in different ways. how can we achieve that in Java?
- Subtype Polymorphism vs. Explicit Higher Order Functions (HoFs)
	Suppose we want to write a program that prints a string representation of the large of two objects according to some specific comparison function
	- Explicit HoF Approach: can simply pass a different `compare` function
		```Python
		def print_larger(x, y, compare, stringify):
			if compare(x, y):
				return stringify(x)
			return stringify(y)
	```
	- Subtype Polymorphism Approach: requires an extra *comparator* `c`
		```Python
		def print_larger(T x, T y, comparator<T> c):
			if c.compare(x, y):
				return x.str()
			return y.str()
```
- Additional orders in Java
	- In some languages, we'd write two comparision functions and simply pass the one we want
		- `sizeCompare()`
		- `nameCompare()`
	- The standard Java approach: Create `sizeComparator` and `nameComparator` classes that implement the `Comparator` interface.
		- Requires method that also take `Comparater` arguments
		```Yaml
				  Comparator<T>
				        |
				      /   \
		 NameComparator    SizeComprator
```
	- Example: `NameComparator`
		```Java
		public class Dog implements Comparable<Dog> { 
			private String name;
```
