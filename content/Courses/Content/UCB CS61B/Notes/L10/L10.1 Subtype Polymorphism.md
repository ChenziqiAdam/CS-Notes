- *Polymorphism*: "providing a single interface to entities of different types"
- Consider a variable `deque` of static type `Deque`:
	- When you call `deque.addFirst()`, the actual behavior is based on the dynamic type.
	- Java automatically selects the right behavior using what is sometimes called "dynamic method selection".
- Subtype Polymorphism vs. Explicit Higher Order Functions (HoFs)
	Suppose we want to write a program that prints a string representation of the large of two objects
	- Explicit HoF Approach (sometimes called a "callback")
		```Python
		def print_larger(x, y, compare, stringify):
			if compare(x, y):
				return stringify(x)
			return stringify(y)
	```
	- Subtype Polymorphism Approach
		```Python
		def print_larger(x, y):
			if x.largerThan(y):
				return x.str()
			return y.str()
```
