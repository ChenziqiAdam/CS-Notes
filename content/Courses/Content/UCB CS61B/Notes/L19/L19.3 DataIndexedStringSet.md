- The corresponding integer conversion function is actually even simpler than `englishToInt()`! 
	- Using the raw character value means we avoid the need for a helper method.
	```Java
	public static int asciiToInt(String s) {
		int intRep = 0;
		for (int i = 0; i < s.length(); i += 1) {       	
	        intRep = intRep * 126;
	        intRep = intRep + s.charAt(i);
		}
		return intRep;
	}
```
