### 2. Exception
- There is an exception in `add()` and `contains()`.
	What if the user `add(null)` or the `ArraySet` is all `null` (`.equals` cannot compare `null`) ? Our current `ArraySet` will crash!
- Fixes
	- Ignore `null`s
	- Fix contains s.t. it doesn't crash if `items[i]` is `null`
