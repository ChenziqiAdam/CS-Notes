- The `toString()` method provides a string representation of an object.
	- `System.out.println(Object x)` calls `x.toString()`
	- The implementation of `toString()` in `Object` is the name of the class, then an `@` sign, then the memory location of the object.
	- Unfortunately, the `toString()` method doesn't work for our classes like `ArraySet`
- To make `toString()` work for `ArraySet`, we should **override** our own `toString()`
	```Java
	@Override
	public String toString() {
		StringBuilder returnSB = new StringBuilder("{");
		for (int i = 0; i < size; i += 1) {
			returnSB.append(items[i]);
			returnSB.append(", ");
		}
		returnSB.append("}");
		return returnSB.toString();
	}
	```
	- **Using string and `+` underneath makes a copy of the original string. This is due to that string is immutable.**
	- `StringBuilder` is faster with **append operation** as `StringBuilder` is linear underneath.
