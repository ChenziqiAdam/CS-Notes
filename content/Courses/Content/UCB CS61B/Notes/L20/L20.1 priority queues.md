- The Priority Queue Interface
	```Java
	/** (Min) Priority Queue: Allowing tracking and removal of the
	  * smallest item in a priority queue. */
	public interface MinPQ<Item> {
		/** Adds the item to the priority queue. */
		public void add(Item x);
		/** Returns the smallest item in the priority queue. */
		public Item getSmallest();
		/** Removes the smallest item from the priority queue. */
		public Item removeSmallest();
		/** Returns the size of the priority queue. */
		public int size();
	}
```
- Useful if you want to keep track of the “smallest”, “largest”, “best” etc.
- How to implement a MinPQ?
	Some possibilities:
	- Ordered Array
	- Bushy BST: Maintaining bushiness is annoying. Handling duplicate priorities is awkward.
	- HashTable: No good! Items go into random places.
