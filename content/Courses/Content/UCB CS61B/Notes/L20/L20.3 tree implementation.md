		- A deep look at approach 3
			```Java
			public int parent(int k) {
				return (k - 1) / 2;
			}
			
			public void swim(int k) {
			    if (keys[parent(k)] ≻ keys[k]) {
			       swap(k, parent(k));
			       swim(parent(k));              
			    }
			}
```
