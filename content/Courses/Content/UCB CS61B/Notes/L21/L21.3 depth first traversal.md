- **s-t Connectivity**: Given source vertex s and a target vertex t, is there a path between s and t?
	![[Pasted image 20240908170437.png]]
	- Q. how to fix it? Mark nodes!
	- One possible recursive algorithm for connected(s, t). 
		- Mark s.
		- Does s == t? If so, return true.
		- Otherwise, if `connected(v, t)` for any unmarked neighbor v of s, return true.
		- Return false.
	- Basic idea is same as before, but visit each vertex at most once.
		- Marking nodes prevents multiple visits.
- This idea of exploring a neighbor’s entire subgraph before moving on to the next neighbor is known as ***Depth First Traversal (Search)***.
	![[Pasted image 20240908170802.png]]
	- Let's call this algorithm ***DepthFirstPaths***.
- DepthFirstPaths Demo
	Goal: Find a path from s to every other reachable vertex, visiting each vertex at most once dfs(v) is as follows:
	- Mark v.
	- For each unmarked adjacent vertex w:
		- set edgeTo\[w] = v. 
		- dfs(w)
