- Q. how to improve the speed of the methods (`addLast()`, `getLast()`, `removeLast()`) about `last`?
	- One possible solution: given the precedent of `size`, add a `last` variable
	- But `removeLast()` will not be improved with `last`
		- Require setting the node's `.next` before `last` to `null`
- **Improvement #1: add backwards links from every node.**
	- This yield a "doubly linked list" or DLList, as opposed to the earlier Slist.
	- Reverse pointers allow all operations (add, get, remove) to be fast.
		- But for some operations on the nodes in the middle may not perform well.
	```Java
	public class DLList {
	    private Node sentinel;
	    private int size;
	
	    private static class Node {
	        private int value;
	        private Node prev;
	        private Node next;
	
	        public Node(int value, Node prev, Node next) {
	            this.value = value;
	            this.prev = prev;
	            this.next = next;
	        }
	    }
	
	    public DLList() {
	        sentinel = new Node(47, null, null);
	        sentinel.next = sentinel;
	        sentinel.prev = sentinel;
	        size = 0;
	    }
	
	    public void addLast(int value) {
	        Node newNode = new Node(value, sentinel.prev, sentinel);
	        sentinel.prev.next = newNode;
	        sentinel.prev = newNode;
	        size++;
	    }
```
- **Improvement #2: have two sentinels**
	```Java
	public class DLListWithDoubleSentinels {
	    private Node sentinelFront;
	    private Node sentinelBack;
	    private int size;
	
	    private static class Node {

	    public DLListWithDoubleSentinels() {

	        sentinelBack = new Node(-47, null, null);
	        sentinelFront.next = sentinelBack;
	        sentinelBack.prev = sentinelFront;

	    }

	    }
	}
```
- **Improvement #3: even better, circular sentinel (*circular linked list*)**
	```Java
	public class DLListWithCircularSentinel {
    private Node sentinel;
    private int size;

    private static class Node {
        private int value;
        private Node prev;
        private Node next;

        public Node(int value, Node prev, Node next) {
            this.value = value;
            this.prev = prev;
            this.next = next;
        }
    }

    public DLListWithCircularSentinel() {
        sentinel = new Node(47, null, null);
        sentinel.next = sentinel;
        sentinel.prev = sentinel;
        size = 0;
    }

    }
}
```
- **Summary**: Improve the DLList class step by step
	1. Rebranding: `IntList` -> `IntNode`
	2. Bureaucracy: `Slist`
	3. Access Control: `public` -> `private`
	4. Nested Class: bring `IntNode` into `Slist`
	5. Caching: Saving `size` as an int
	6. Generalizing: Adding a sentinel node to allow representation of the empty list
	7. Looking back: `.last` and `.prev` allow fast `removeLast()`
	8. Sentinel upgrade: Avoid special cases (come with `.last` and `.prev`) with  circular list
