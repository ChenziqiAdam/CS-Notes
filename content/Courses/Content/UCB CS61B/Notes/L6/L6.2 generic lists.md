- Q. so far is only-integer list, what about other lists, e.g. string list?
	- Java allows programmers to defer type selection until declaration.
	- Example:
		```Java
		public class Slist<Item> {
			private Node sentinel;
			private int size;
			...

			public class Node {
				public Item item;
				public Node next;
			}
		}

		...
		Slist<Integer> s1 = new Slist<>(5);
		Slist<String> s1 = new Slist<>("Apple");
```
- **Generics(范式)**
	- In the `.java` file implementing the data structure, specify the "generic type" only once at the very top of the file.
	- In `.java` files that use the data structure, specify desired type once:
		- write out desired type during declaration
		- use the empty diamond operator `< >` during instantiation.
	- **When declaring or instantiating the data structure, use the reference type.**
		- `int`: Integer
		- `double`: Double
		- `char`: Character
		- `boolean`: Boolean
		- `long`: Long
