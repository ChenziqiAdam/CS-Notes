- ***Interface Inheritance***: specifying the capabilities of a subclass using the `implements` keyword is known as *interface Inheritance*.
	- *Interface*: the list of all method signatures
	- *Inheritance*: the subclass "inherits" the interface from a superclass
	- Specifies what the subclass can do, but not how
	- Subclasses <u>must</u> override all of these methods. 
		- Otherwise will fail to compile.
	- Such relationships can be multi-generational.
		```yaml
		Collection61B
		      |
		      |
		   List61B
		   /     \
		AList   Slist
```
- ***Interface inheritance* is a powerful tool for generalizing code.**
