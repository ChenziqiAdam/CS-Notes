- *Interface Inheritance*: subclass inherits signatures, but NOT implementation
	- But Java also allows ***implementation inheritance***, i.e. subclasses can inherit signatures AND implementation.
- `default` keyword
	- Example: print
		```Java
		public interface List61B<Item> {
			default public void print() {
				for (int i = 0; i < size(); i += 1) {
					System.out.print(get(i) + " ");
				}
				System.out.println;
			}
		}
```
		- Default methods can be overrode (`@Override` is prefered).
