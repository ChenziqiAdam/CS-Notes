- *Hyperyms(上位词)*
	e.g. Dog is a "*hyperym*" of poodle, malamute, yorkie, etc.
- Simple Hyponymic Relationships in Java
	- List is a "*hypernym*" of Slist and AList.
	- Expressing this relationship in Java is a two-step process
		1. Define a *reference type* for the *hypernym*: `List61B.java`
		2. Specify that Slists and ALists are *hypernyms* of that type
- `interface` and `implements` keywords
	- Example: define List using `interface` but not `class`
		```Java
		public interface List61B<Item> {
			public void addFirst(Item x);
			public void addLast(Item x);
			public Item getFirst();
			public Item getLast();
			public Item removeLast();
			public Item get(int i);
			public void insert(Ite x, int position);
			public int size();
		}
```
		- a specification of what a List is able to do, not how to do
	- Example: use `implements` to tell the Java compiler that Slist and AList are hyponyms of List61B
		```Java
		public class AList<Item> implements List61B<Item> {
			public void addFirst(Item x) {
				...
			}
			...
		}
```
