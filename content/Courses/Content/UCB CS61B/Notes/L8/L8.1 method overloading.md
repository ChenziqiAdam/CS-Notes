- ***Overloading***: Java allows multiple methods with the same name, but different parameters.
	- Example:
		```Java
		public static String longest(AList<String> list) {
			...
		}
		
		public static String longest(Slist<String> list) {
			...
		}
```
	- Downsides:
		- The source code files are unnecessarily long.
		- Repeating tends to be aesthetically gross.
		- **More code to maintain.**
			- Ant change made to one, must be made to another, including bug fixes!
