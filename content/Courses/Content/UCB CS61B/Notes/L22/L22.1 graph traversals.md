- Q. Given the graph above, find the shortest path from s to all other vertices.
	- ***Breadth First Search*** (BFS)
	- Initialize a queue with a starting vertex s and mark that vertex.
		- A queue is a list that has two operations: enqueue (a.k.a. `addLast()`) and dequeue (a.k.a. `removeFirst()`).
			- A queue is the opposite of a stack. Stack has push (`addFirst()`) and pop (`removeFirst()`).
		- Let’s call this the queue our ***fringe***.
	- Repeat until queue is empty:
		- Remove vertex v from the front of the queue.
		- For each unmarked neighbor n of v: 
			- Mark n.
			- Set edgeTo\[n] = v (and/or distTo\[n] = distTo\[v] + 1).
				- This enables you to track distance value.
			- Add n to end of queue.
	![[Pasted image 20240909104920.png]]
	- See [CS61B BFS demo](https://docs.google.com/presentation/d/1JoYCelH4YE6IkSMq_LfTJMzJ00WxDj7rEa49gYmAtc4/edit?usp=sharing).
- Q. would BFS be a good algorithm for a navigation tool?
	- Bad! Roads have distance. (We will come back to this later)
