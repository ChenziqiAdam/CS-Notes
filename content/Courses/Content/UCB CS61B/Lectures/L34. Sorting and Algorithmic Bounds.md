### 0. Recap: Sort

|                | Memory   | # Compares          | Notes                             | Stable? |
| -------------- | -------- | ------------------- | --------------------------------- | ------- |
| Heapsort       | Θ(1)     | Θ(N log N)          | Bad caching                       | No      |
| Insertion      | Θ(1)     | Θ(N2)               | Best for almost sorted and N < 15 | Yes     |
| Mergesort      | Θ(N)     | Θ(N log N)          | Fastest stable sort               | Yes     |
| Quicksort LTHS | Θ(log N) | Θ(N log N) expected | Fastest sort                      | No      |

### 1. Math
- N! ∈ Ω ((N/2)<sup>N/2</sup>) (Recall that ∈ Ω can be informally be interpreted to mean ≥)
- log (N!) ∈ Ω (N log N)
- N log N ∈ Ω (log (N!))
- Thus the growing speed of the both is almost equal!
