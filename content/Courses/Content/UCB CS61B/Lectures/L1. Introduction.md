**1. Java is an *Object Oriented Language*.**
- Every Java file must contains a class declaration, which is declared using the keywords `public class`.
- All codes exist inside classes.
- To run a Java program, typically define a `main` method (a.k.a. functions): `public static void main(String[] args)`
**2.** Run a Java Program
```Shell
$ javac HelloWorld.java
$ java HelloWorld
Hello World! 
```
**3. Java is *Statically Typed*.**
- All variables, parameters, and methods must have a declared type, which can never change after declared.
- The compiler checks tall types in the program before the program even runs.
	- Unlike dynamically typed languages like Python, where users can run into type errors during execution!
**4.** Reflections on Static Typing
- The Good:
	- catch certain types of errors, making it easier on the programmer to debug their code
	- type errors can (almost) never occur on end user's computer
	- make it easier to read and reason about code
	- code can run more efficiently, e.g. no need to do expensive runtime type checks.
- The Bad:
	- code is more verbose(冗长的)
	- code is less general
- Other Key Syntax Features
	- Curly braces are used to denote the beginning and end of a section of code, e.g. a class or method declaration.
	- Statements end with semicolons.
	- Variables must be declared before use.
	- Functions must have a return type. If a function does not return anything, use `void`.
	- The compiler ensures type consistency. If types are inconsistent, the program will not compile.
**5.** Java Comments and Javadoc
- Line comments in Java use the `//` delimiter. Block (a.k.a. multi-line comments) comments use `/*` and `*/`.
- One special note is that all of your methods and almost all of your classes should be described in a comment using the so-called [Javadoc](https://en.wikipedia.org/wiki/Javadoc) format. 
	- In a Javadoc comment, the block comment starts with an extra asterisk, e.g. `/**`, and the comment often (but not always) contains descriptive tags.
	- As an example without tags:
	```Java
	public class LargerDemo {
	    /** Returns the larger of x and y. */           
	    public static int larger(int x, int y) {
	        if (x > y) {
	            return x;
	        }
	        return y;
	    }
	
	    public static void main(String[] args) {
	        System.out.println(larger(8, 10));
	    }
	}
	```
- The widely used [javadoc tool](http://docs.oracle.com/javase/8/docs/technotes/tools/windows/javadoc.html) can be used to generate HTML descriptions of your code.
