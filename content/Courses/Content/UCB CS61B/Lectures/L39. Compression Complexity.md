### 0. Recap
- The goal of a compression algorithm is to find short sequences of bits that generate desired longer sequences of bits.
- Compression Model #1 
	- Only consider the size of the compressed result
	- While the source code for the decompression algorithm might be complex.
- Compression Model #2 
	- Given a sequence of bits B, find a shorter sequence DA+C(B) that produces B when fed into an interpreter.
- Q. does there exist some optimal compression?
	Possible!
	- Retrieve the source code that generates the data.
	- Some complex data is generated by short codes.
