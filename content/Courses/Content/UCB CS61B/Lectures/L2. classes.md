### 1. Classes
- Standard process for executing Java programs
	`hello.java` -> javac (*compiler*) -> `hello.class` -> java (interpreter) -> ...
	- Q. why make a `.class` file?
		- `.class` file has been typed checked. Distributed code is safer.
		- `.class` file is simpler and easier for machines to execute.
	- A Java program without a `main` method cannot be run directly using the `java` command. However, its methods can still be invoked using the `main` method of another class.
- Example: `launcher`
	```Java
	public class Dog { // Cannot run directly since there is no main method
		public static void makeNoise() {
			System.out.println("Bark!");
		}
	}

	public class DogLauncher {
		public static void main(String[] args) { // Call a method from another class
			Dog.makeNoise();
		}
	}
```
	- Every method is inside a certain class.
	- To run a class, there must be a `main` method. But not all classes have a `main` method.
	- **Always call a method form another class**
		- s.t. make the code more readable and maintainable
- Example: define a typical class
	```Java
	public class Dog {
		public int weight; // Instance variables

		public Dog(int weight) { // Constructor
			this.weight = weight;
		}

		public void makeNoise() { // Non-static method, a.k.a. Instance Method
			if (weight < 10) {
				System.out.println("yipyipyip!");
			} else if (weight < 30) {
				System.out.println("bark!bark!");
			} else {
				System.out.println("woof!");
			}
		}
	}
```
	- ***Constructor***: determine how to instantiate the class
	- ***Non-static methods***: the idea is that if the method is going to be invoked by an instance of the class, then it should be non-static.
- Example: instantiate a class
	```Java
	public class DogLauncher {
		public static void main(String[] args) {
			Dog samll; // Declaration of a Dog variable
			new Dog(20); // Instantiation of the Dog class as a Dog Object
			small = new Dog(5); // Instantiation and Assignment
			Dog huge = new Dog(150); // Declaration, Instantiation and Assignment
			small.makeNoise();
			huge.makeNoise(); // Invocation of the huge Dog's makeNoise method
		}
```
	- `huge.makeNoise`: the ***dot notation*** means that the programmer wants to use a method or variable belonging to `Dog huge`, or more  succinctly, a member of `Dog huge`
- A class that uses another class is sometimes called a "client" of that class, i.e. `DogLauncher` is a client of `Dog`. 
- Neither of the two techniques is better: Adding a main method to `Dog` may be better in some situations, and creating a client class like `DogLauncher` may be better in others.
### 2. *Static* vs. *Non-static*
- Key differences between *static* (a.k.a. **class**) and *non-static* (a.k.a. **instance**) methods:
	1. *Static methods* are invoked using the class name, e.g. `Dog.makeNoise()`
	2. *Non-static methods* are invoked using an instance name, e.g. `maya.makeNoise()`
	3. *Static methods* cannot access "my" instance variables, because there is no "me".
- Q. why *static methods*?
	- some classes are never instantiated, e.g. Math
		- `x = Math.round(5.6)`
	- sometimes, classes may have a mix of *static* and *non-static methods*
		```Java
		public static Dog biggerDog(Dog d1, Dog d2) {
			if (d1.weight > d2.weight) {
				return d1;
			}
			return d2;
		}

		// The non-static method below practically has the same effect as the static method above 
		public Dog biggerDog(Dog d) {
			if (this.weight > d.weight) {
				return this;
			}
			return d;
		}

		Dog bigger = Dog.biggerDog(d, d2);
		// Dog bigger = d.biggerDog(d2);
		bigger.makeNoise();
```
- Summary: 
	A class may have a mix of static and non-static members
	- Static methods are actions that are taken by the class itself. Both are useful in different circumstances.
	- Non-static methods are actions that can be taken only by a specific instance of a class. 
	- A variable or method defined in a class is also called a member of the class.
	- Static members are accessed using the class name, e.g. `Dog.makeNoise()`.
	- Non-static members cannot be invoked using class name, e.g. ~~`Dog.makeNoise()`~~
	- Static methods **must** access instance variables via a specific instance, e.g. `d1`.
- Static and non-static variables are similar to functions.
	- Static variables should be accessed using the name of the class rather than a specific instance, e.g. you should use `Dog.binomen`, not `d.binomen`.
- `this` keyword: Inside a method, we can use the `this` keyword to refer to the current instance. 
	This is equivalent to `self` in Python.
### 3. *Helper Methods*
- Using helper method lets programmers formalize the decomposition of large problems into small ones
	- easier to read, debug, maintain and reuse
