### 1. Exponential Family
- Idea: If $P$ has special form, some inference come for free.
	- $P(y, \eta) = b(y) \exp[{\eta^TT(y) - a(\eta)}]$ PDF
		- $y$: data, $\eta$: natural parameters
		- $T(y)$ is called sufficient stats(statistics)
			- We use $T(y) = y$.
			- $T(y)$ has the same dimension as $\eta$.
		- $b(y)$ is called base measure.
			- Independent of $\eta$
		- $a(\eta)$ is called log partition function
			- Independent of $y$
- Examples:
	- Bernoulli
		1. $P(y, \phi) = \phi^y (1 - \phi)^{1-y}$
		2. $P(y, \phi) = \exp[{y}\log(\phi) + (1-y)\log(1-\phi)]$
		3. $P(y, \phi) = \exp[{y}\log(\frac{\phi}{1-\phi}) + \log(1-\phi)]$
			- $\eta = \log(\frac{\phi}{1-\phi}) \Rightarrow \phi = \frac{1}{1+\exp({-\eta})}$
			- $T(y) = y$
			- $a(\eta) = -\log(1-\phi) = -\log(\frac{\exp({-\eta})}{1+\exp({-\eta})})$
	- Gaussian (with $\sigma^2 = 1$)
		1. $P(y, \mu) = \frac{1}{\sqrt{2 \pi}} \exp\left( -\frac{(y - \mu)^2}{2} \right)$
		2. $P(y, \mu) = \frac{1}{\sqrt{2 \pi}} e^{-\frac{y^2}{2}} \exp\left(\mu y - \frac{1}{2}\mu^2\right)$
			- $\eta = \mu$
			- $T(y) = y$
			- $a(\eta) = \frac{1}{2}\eta^2$
- Q. Why do we care about this form?
	- Independence is easy.
		- $E[y:\eta] = \frac{\partial a(\eta)}{\partial \eta}$
		- $Var[y:\eta] = \frac{\partial^2 a(\eta)}{\partial^2 \eta}$
	- Learning is "well defined".
		- MLE (maximum likelihood estimater) w.r.t to $\eta$ is concave.

### 2. Generalized Linear Models
- Q. Where is our $x$ in the formulation?
	- Design Choices $\Rightarrow$ Assumptions (data type mapping)
		1. $y|x,\theta \sim$ Exponential Family (error mode)
			- Binary $\Rightarrow$ Bernoulli
			- Real $\Rightarrow$ Gaussian
			- Counts $\Rightarrow$ Poisson
		2. $\eta = \theta^Tx, \theta \in \mathbb{R}^{d+1}, x \in \mathbb{R}^{d+1}$
		3. Inference (test): $h_\theta(x) = E[y|x,\theta]$
			- Probability that $y$ is a certain value
	```mermaid
	flowchart LR
	    A[Data: $$x$$] -->B["Linear model: $$\theta^Tx$$"]
	    B -->|$$\eta$$| C["Exponential model: $$T(y), b(y)$$"]
	    C -->|learning| D["$$\max_\theta [log P(y,x,\theta)]$$"]
	    C -->|inference| E["$$E(y,x,\theta)$$"]
	
	    style B fill:#f9f9f9,stroke:#333,stroke-width:2px
	    style C fill:#f9f9f9,stroke:#333,stroke-width:2px	
	```
	- Learning $\theta_j = \theta_j + \alpha(y_i - h_\theta(x_i))x_{ij}$
- Terminology
	```mermaid
	flowchart LR
	    A[Model Parameter: $$\theta$$] -->|$$\theta^Tx$$| B["Natural Parameter: $$\eta$$"]
	    B -->|$$g$$| C["Canonical parameter: $$\phi, (\mu, \sigma^2)$$"]	
	```
	- $g$: canonical response
	- Function $g$ relates the mean $\mu = E[y]$ to $\eta = g(\mu) = \theta^T X$
	- Example: Gaussian $h_\theta(x) = E[y|x,\theta] = \mu = \theta^Tx$

### 3. Multiclass Classification via Softmax
- Discrete values up to k
	![[Pasted image 20250228115559.png]]
	- e.g. `k=4`: `{cat, dog, car, house}`
	- Encode: **one-hot vector**
		- $y \in \{0, 1\}^k$ s.t. $\sum_{i=1}^{n} y_i = 1$
		- e.g. `cat` $= [1, 0, 0, 0]$, `dog` $= [0, 1, 0, 0]$
		- To classify `cat`: $\theta_1x$; `dog`: $\theta_2x$
			- $x$: features of the data
		 - $P(y = k | x, \theta) = \frac{\exp\left(\theta_kx\right)}{\sum_{j=1}^{n}\exp\left(\theta_jx\right)}$ **Softmax**
			- Consistent with logistic regression
		- $\min CrossEntropy(p, \hat{p}) = -\sum_{i=1}^{k} P(y = k) \log{\hat{p}(y)}$
			- $= -\log{\hat{p}(y_i)}$
			- $= -\log{\frac{\exp\left(\theta_ix\right)}{\sum_{j=1}^{n}\exp\left(\theta_jx\right)}} \Rightarrow$ Gradient Descent
				- $y_i$ & $i$: ground truth label
				- $-\log$: **logit** (log probability)
				- The negative sign is to turn it into the minimization problem.
