### 1. Supervised Learning
- Schema
	- Prediction Function $h: X \rightarrow y$
		- e.g. Images $\rightarrow$ Cat
	- Given 
		- Training Set: $\{(X_1, y_1)...(X_n, y_n)\}$
	- Do
		- Find good $h: X \rightarrow y$ (hypothesis function)
		- BUT we care about new $X$ values that are not in the training set.
- Note
	- $y$ is Discrete: Classification Problem
	- $y$ is Continuous: Regression Problem
- When you first get the data, what you need to do is to look at it and draw it out!
- Q. How do we represent $h$?
	- Linear Regression: $h(X) = \theta_0 + \theta_1X$ (affine映射)
	- $h(X) = (\theta_0, \theta_1) \cdot (1, X)$
		- This is equivalent to $h(X) = \theta X$ where $X_0$ is $1$.
	```
	⎡ x₀ ⎤ -> 1
	⎢ x₁ ⎥ -> [ x₁₁ ... x₁ₘ ]
	⎢ .  ⎥
	⎢ .  ⎥ 
	⎢ .  ⎥
	⎣ xₙ ⎦ -> Size z = n
	```
	- $h(X) = \sum \theta_jX_j$ i.e. once $\theta$ is determined, $h(X)$ is determined.

### 2. Least Mean Square (LMS)
- Q. How do we estimate how "good" a $h(X)$ is?
	- Loss Function: $J(\theta) = \frac{1}{2} \sum ( h_\theta(x) - y )^2$
		- Least Squares
	- Goal: Find $\theta$ that minimize $J(\theta)$ (optimization)  
		- $\frac{\partial J(\theta)}{\partial \theta_j} = \sum ( h_\theta(x) - y ) \frac{\partial h_\theta(x)}{\partial \theta_j}$
		- $\frac{\partial h_\theta(x)}{\partial \theta_j} = X$
		- $\theta_j = \theta_j - \alpha \left( \frac{\partial J(\theta)}{\partial \theta_j} \right) = \theta_j - \alpha \sum ( h_\theta(x) - y ) X$ （Gradient Descent)
	- $J(\theta)$ is a function of $\theta$.

- Batch v.s. Stochastic Mini-batch: trade-off between speed and accuracy
	- Pick a subset $B$ from $X$ to compute the gradient.
	- Faster but requires careful selecting.
