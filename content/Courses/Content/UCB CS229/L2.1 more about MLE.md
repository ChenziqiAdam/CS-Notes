### MLE: Maximum Likelihood Estimator
1. Core Idea:
	- Goal: Estimate parameters of a statistical model that best explain observed data.
	- **"Best Explains" = Most Likely:** Find parameters that make the observed data the _most probable_ outcome.
2. Likelihood:
	- Definition: Measure of how plausible parameter values are given the observed data.
	- **Not Probability:** Likelihood of parameters _given data_, not probability of data _given parameters_.
	- Calculation (IID Data): Product of probabilities (or probability densities) of each data point, given parameters. `L(θ) = P(data | θ)` (or `f(data | θ)` for continuous data).
3. Maximum Likelihood Estimator (MLE):
	- **Definition:** The parameter value (or set of values) that _maximizes_ the Likelihood function.
	- **Find MLE:** Typically involves:
	    - **Choose a Model:** Select a probability distribution (e.g., Gaussian, Bernoulli).
	    - **Likelihood Function:** Write down the likelihood function.
	    - **Log-Likelihood (Optional but Easier):** Maximize the log-likelihood instead of the likelihood.
	    - **Differentiate & Solve:** Take derivatives of log-likelihood wrt parameters, set to zero, and solve.
4. Summary: MLE is like finding the "settings" (parameters) of a probability distribution that, if you were to "run" that distribution, would have the highest chance of generating the data you've actually observed.
