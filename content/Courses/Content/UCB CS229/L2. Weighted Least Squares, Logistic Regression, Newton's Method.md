### 1. More about Least Square and MLE
- Q. Why Least Squares?
	- Assume $y_j = \theta^TX_j + \epsilon_j$
		- $\epsilon$ is the error or noise (unmodeled information)
		- In the house price case, for example, house appearance, house location...
	- Q. How to represent $\epsilon$?
		1. $E(\epsilon)$ = 0 (unbiased)
		2. The errors are independent: $E(\epsilon_i \epsilon_j) = E(\epsilon_i) E(\epsilon_j)$ for $i \ne j$
	- Q. How "noisy"?
		- $E[(\epsilon_i)^2] = \sigma^2$
	- With these  assumptions, error $\epsilon$ is **Gaussian Distribution**.
- **Gaussian Distribution (or Normal Distribution)**
	- $x \sim N(\mu, \sigma^2)$
	- $f(x|\mu, \sigma) = \frac{1}{\sigma \sqrt{2 \pi}} \exp\left( -\frac{(x - \mu)^2}{2 \sigma^2} \right)$
- With previous assumptions
	- $y_j|x_j, \theta \sim N(\theta^Tx_j, \sigma^2)$
	- i.e. $P(y_i|x_i, \theta) = \frac{1}{\sigma \sqrt{2 \pi}} \exp\left( -\frac{(y_i - \theta^Tx_i)^2}{2 \sigma^2} \right)$, where $y_i - \theta^Tx_i = \epsilon_i$
- **Likelihood**: "most likely distribution"
	- $L(\theta) = P(y|x, \theta) = \prod_{i=1}^n P(y_i|x_i, \theta)$ (iid assumption: independent and identically distributed)
	- $L(\theta) = \prod_{i=1}^n{\frac{1}{\sigma \sqrt{2 \pi}} \exp\left( -\frac{(y_i - \theta^Tx_i)^2}{2 \sigma^2} \right)}$
- **Log Likelihood**: more friendly version
	- $l(\theta) = log(L(\theta) = \sum_{i=1}^n(\log(\frac{1}{\sigma \sqrt{2 \pi}}) - \frac{(y_i - \theta^Tx_i)^2}{2 \sigma^2})$
	- $J(\theta) = \max(l(\theta)) = \min\frac{1}{2}\sum_{i=1}^n(y_i - \theta^Tx_i)^2$

### 2. Classification and Logistic Regression
- Given $(x_i, y_i)$ for $i = 1 ... n$, $y_i \in \{0, 1\}$
- **Logistic Regression**
	- $h_\theta(x) \in [0, 1]$, $h_\theta(x) = g(\theta^Tx) = (1 + \exp\left( -\theta^Tx \right))^{-1}$
	- $g(z) = \frac{1}{1 + \exp\left(-z\right)}$ "*(inverse) link function*"
	- **Sigmoid Function**
- Q. How to utilize the formulation?
	- $P(y = 1 | x, \theta) = h_\theta(x)$, $P(y = 0 | x, \theta) = 1 - h_\theta(x)$
	- $L(\theta) = P(y|x, \theta) = \prod_{i=1}^n P(y_i|x_i, \theta) = \prod_{i=1}^n h_\theta(x_i)^{y_i} (1 - h_\theta(x_i))^{1-y_i}$
	- $l(\theta) = \sum_{i=1}^n [y_i \log(h_\theta(x_i)) + (1 - y_i)\log(1 - h_\theta(x_i))]$
	- **Same Recipe**: $\theta_{i+1} = \theta_i + \alpha\frac{\partial J(\theta)}{\partial \theta_i}$ (GD: Gradient Descent)
		- $\frac{\partial J(\theta)}{\partial \theta_j} = \sum_{i=1}^n(y_i - h_\theta(x_i))x_{ij}$
	- **Rule is General.**
### 3. Newton's Method
- Given $f: \mathbb{R}^d \Rightarrow \mathbb{R}$, do find $f(x) = 0$
	- i.e. $\min l(\theta) \Rightarrow l'(\theta) = 0$
- $\theta_{i+1} = \theta_i - \frac{f(\theta_i)}{f'(\theta_i)}$
	- Quadratic Fast!
	- Works well for 1-dimension.
	- Without $\alpha$
- Q. What happens when generalize to n-dimensions?
	- $\theta_{i+1} = \theta_i - (H)^{-1}\nabla l(\theta)$

### 4. Comparison of Optimization Methods

| Method        | Cost (Data Points) / Iteration | Compute / Iteration | Steps to Error $\epsilon^2$ |
| ------------- | ------------------------------ | ------------------- | --------------------------- |
| SGD           | 1                              | $\theta(d)$         | $\epsilon^{-2}$             |
| Batch GD      | N                              | $\theta(nd)$        | $\epsilon^{-1}$             |
| Newton Method | N                              | $\Omega(nd^2)$      | $log(\frac{1}{\epsilon})$   |
