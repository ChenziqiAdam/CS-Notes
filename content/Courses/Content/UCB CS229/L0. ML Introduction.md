### 0. History of ML
- Arthur Samuel (1959): Machine Learning is the field of study that gives the computer the ability to learn without being explicitly programmed.
- Tom Mitchell (1998): a computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.
- ML Taxonomy(分类):
	- Supervised Learning
	- Unsupervised Learning
	- Reinforce Learning

### 1. Supervised Learning
- Task: Find a function that maps: Features/Input -> Label/Output
- Dataset: $(x_1, y_1),...,(x_n, y_n)$ where $x_i = (x_{i1},...,x_{im})$
- Regression v.s. Classification: the label $y$ is continuous/discrete variable.
- Applications:
	- Computer Vision
		- Classification
		- Object detection
	- Natural Language Processing
		- Machine translation (classification)

### 2. Unsupervised Learning
- Task: find patterns in the data
- Dataset contains no labels: $x_1,...,x_n$
- Applications:
	- Clustering
	- Word Embeddings: represent words by vectors
		- word      --encode-> vector
		- relation -- encode-> direction
	- Large Language Models (LLMs): machine learning models for language learnt on large-scale language datasets
