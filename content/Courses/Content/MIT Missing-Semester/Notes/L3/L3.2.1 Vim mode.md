- Vim has multiple operating modes.
	- **Normal**: for moving around a file and making edits
	- **Insert**: for inserting text
	- **Replace**: for replacing text
	- **Visual** (plain, line, or block): for selecting blocks of text
	- **Command-line**: for running a command
- Switch between modals
	- `<ESC>`: other mode -> Normal mode
	- `i`: Normal mode -> Insert mode
	- `R`: Replace mode
	- `v`: Visual mode
	- `V`: Visual Line mode
	- `<C-v>` as well as `^V`: Block mode
	- `:`: Command-line mode
- Keystrokes have different meanings in different operating modes. 
	- For example, the letter `x` in Insert mode will just insert a literal character ‘x’, but in Normal mode, it will delete the character under the cursor, and in Visual mode, it will delete the selection.
