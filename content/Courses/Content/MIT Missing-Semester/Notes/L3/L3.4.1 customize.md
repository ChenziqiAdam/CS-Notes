- Customize Vim
	- Vim is customized through a plain-text configuration file in `~/.vimrc` (containing Vimscript commands).
	- Recommended basic config: **download our config [here](https://missing.csail.mit.edu/2020/files/vimrc) and save it to `~/.vimrc`.**
	- Vim is heavily customizable, and it’s worth spending time exploring customization options. You can look at people’s dotfiles on GitHub and other blog posts for inspiration.
