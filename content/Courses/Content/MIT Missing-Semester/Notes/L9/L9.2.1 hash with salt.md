- In cryptography, "salt" is a random value added to data, particularly passwords, before hashing. This helps protect against attacks like rainbow table attacks by ensuring that identical plaintext inputs (e.g., the same password) result in different hashed values.
	`password + randomSaltValue -> hash`
- By adding a unique salt to each password, even if two users have the same password, their hashed values will differ, enhancing security.
