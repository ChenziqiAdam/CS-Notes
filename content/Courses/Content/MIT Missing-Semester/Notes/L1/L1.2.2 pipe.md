- The essence of redirecting: **_pipes_**. 
- The `|` operator lets you “chain” programs such that the output of one is the input of another:
	```bash
	missing:~$ ls -l / | tail -n1
	drwxr-xr-x 1 root  root  4096 Jun 20  2019 var
	```
	- **`ls -l /`**: lists the contents of the root directory in long format, showing details like permissions, number of links, owner, group, size, and modification time for each item in the directory.
	- **`|`**: the pipe operator takes the output of the command on its left (in this case, `ls -l /`) and passes it as input to the command on its right.
	- **`tail -n1`**: this command reads from its input (the output of `ls -l /`) and displays the last line.
