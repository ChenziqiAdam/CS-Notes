- A Variety of Interfaces for giving them commands:
	graphical user interfaces, voice interfaces, AR/VR
- Textual Interface: ***The Shell*** (命令行界面 *CLI*: *command-line interface*)
- *Bourne Again SHell* (*"bash"*): one of the most widely used shells
- To open a shell prompt (where you can type commands), you first need a terminal.
- `missing:~$`
	- `missing`: on the machine `missing`
	- `~`: ***cwd***: **current working directory** (`~` is short for "home")
	- `$`: means you are not the ***root user***
	- Example: execute the `date` program
		```bash
		missing:~$ date
		Fri 10 Jan 2020 11:49:31 AM EST
		```
	- Example: execute the `echo` program
		```bash
		missing:~$ echo "hello, world!"
		hello, world!
		```
- Q. how does the shell know how to find the `date` or `echo` program?
	- The Shell is a **programming environment** (just like Python or Ruby).
	- When you run commands in the shell, you are really writing a small bit of code that the shell interprets. 
	- If the shell is asked to execute a command that doesn’t match one of its programming keywords, it consults an _environment variable_ called `$PATH` that lists which directories the shell should search for programs when it is given a command.
