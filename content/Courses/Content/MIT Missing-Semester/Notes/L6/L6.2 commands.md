### Basic
- `git init`: create a new git repo, with data stored in the `.git` directory
- `git status`: tell you what’s going on
- `git add <filename>`: add files to staging area
- `git commit`: create a new commit (and open the editor, e.g. VIM)
	**write good commit messages!**
- `git commit -m <commit-content>`: create a new commit (without opening the editor)
- `echo "content" > <filename>`: create a file with `content` (or overwrite a file if it exists)
- `echo "content" >> <filename>`: append `content` to a file
- `cat <filename>`: print out the content in the file
- `git log`: show a flattened log of history (including the hash)
- `git log --all --graph --decorate`: visualize history as a DAG
- `git log --all --graph --decorate --oneline`: more concise and clear than above
### Branching and Merging
- `git branch`: show all branches
- `git branch <branch-name>`: create a branch
- `git checkout <branch-name>`: switch to a branch
- `git checkout -b <new-branch-name>`: create a branch and switches to it
- `git checkout <revision>`: update `HEAD` and current branch
- `git checkout <commit-hash>`: switch to a commit with its hash
- `git merge <revision>`: merge into current branch
### Remotes(远程仓库)
- `git remote`: list remotes
- `git remote add <name> <url>`: add a remote
- `git push <remote> <local branch>:<remote branch>`: update remote reference
- `git fetch`: retrieve objects/references from a remote
- `git pull`: same as `git fetch; git merge`
- `git clone`: download repository from remote
### Undo
- `git commit --amend`: edit a commit’s contents/message
- `git reset HEAD <file>`: unstage a file
- `git checkout -- <file>`: discard changes
### Advanced Git
- `git config`: Git is [highly customizable](https://git-scm.com/docs/git-config)
- `git clone --depth=1`: shallow clone, without entire version history
- `git add -p`: interactive staging
- `git rebase -i`: interactive rebasing
- `git blame`: show who last edited which line
- `git stash`: temporarily remove modifications to working directory
- `git bisect`: binary search history (e.g. for regressions)
- `.gitignore`: [specify](https://git-scm.com/docs/gitignore) intentionally untracked files to ignore
