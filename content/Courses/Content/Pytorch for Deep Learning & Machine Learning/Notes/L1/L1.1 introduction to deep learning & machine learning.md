- *Deep learning (DL)* is a subset of *machine learning*.
- *Machine learning (ML)*: turn things (data) into numbers and find patterns in those numbers
- Machine Learning Algorithms v.s. Traditional Programming
	- former: x + f(x) -> y
	- later: x + y -> f(x)
- Q. why use ML (DL)?
	- Why not?
	- "If you can build a **simple rule-based** system that doesn't require machine learning, do that." -- Rule 1 of Google's Machine Learning Handbook
	- Q. what deep learning is good for?
		- Problems with long lists of rules
		- Continually changing environments
		- Discovering insights within large collections of data
	- Q. what deep learning is not good for?
		- When you need explainability
		- When the traditional approach is a better option
		- When errors are unacceptable
		- When you don't have much data
- *Machine Learning* v.s. *Deep Learning*
	- Former: structured data e.g. tables (gradient boosted machine: XGBoost)
		- Random forest
		- Gradient boosted models
		- Naive Bayes
		- Nearest neighbor
		- Support vector machine
		- ...
	- Later: unstructured data e.g. natural language, images and audio (neural network)
		- **Neural networks**
		- **Fully connected neural network**
		- **Convolutional neural network (CNN)**
		- Recurrent neural network
		- **Transformer**
		- ...
	- But it is common to combine both in reality.
- Neural networks
	- Process: inputs -> numerical encoding(编码) (tensor) -> learn representation (patterns/features/weights) -> representation outputs (tensor) -> output
	- Architecture: input layer (data goes in) -> hidden layer (learns patterns in data) -> output layer (outputs learned representation or prediction probabilities)
		- There can be multiple layers more than 3.
		- Each layer is usually a combination of linear (straight line) and /or non-linear (not-straight line) functions
- Types of Learning
	- Supervised Learning
	- Unsupervised & Self-supervised Learning
	- Transfer Learning
	- Reinforcement Learning
		- Different from the three above
		- Agent + Environment
- Q. what is deep learning used for?
	- Recommendation
	- Translation (sequence to sequence)
	- Speech recognition (seq2seq)
	- Computer vision (classification/regression)
	- NLP: natural language processing (classification/regression)
