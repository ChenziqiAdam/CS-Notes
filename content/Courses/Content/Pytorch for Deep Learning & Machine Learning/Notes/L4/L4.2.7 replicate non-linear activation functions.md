- Neural networks, rather than us telling the model what to learn, we give it the tools to discover the hidden patterns in data and learn them on its own.
	- And these tools are linear & non-linear functions.
- Q. what does a non-linear activation look like? How about we replicate some and what they do?
```Python
# Create a toy tensor (similar to the data going into our model(s))
A = torch.arange(-10, 10, 1, dtype=torch.float32)
# Visualize the toy tensor
plt.plot(A);
```
![[Pasted image 20240702105747.png]]
- Now let's see how `ReLU()` influence `A` (the inside implement see [Wikipedia page for ReLU](https://en.wikipedia.org/wiki/Rectifier_(neural_networks)).
```Python
# Create ReLU function by hand 
def relu(x):
  return torch.maximum(torch.tensor(0), x) # inputs must be tensors

# Pass toy tensor through ReLU function
relu(A)

# Plot ReLU activated toy tensor
plt.plot(relu(A));
```
![[Pasted image 20240702110126.png]]
- How about the [sigmoid() function](https://en.wikipedia.org/wiki/Sigmoid_function)?
```Python
# Create a custom sigmoid function
def sigmoid(x):
  return 1 / (1 + torch.exp(-x))

# Test custom sigmoid on toy tensor
sigmoid(A)

# Plot sigmoid activated toy tensor
plt.plot(sigmoid(A));
```
![[Pasted image 20240702110335.png]]
- These two are two of the most common in PyTorch. And there are plenty more.
- With linear and non-linear lines, we can almost draw anything.
	- That's exactly what our model is doing when we combine linear and non-linear functions.
	- Instead of telling our model what to do, we give it tools to figure out how to best discover patterns in the data.
	- And those tools are linear and non-linear functions.
