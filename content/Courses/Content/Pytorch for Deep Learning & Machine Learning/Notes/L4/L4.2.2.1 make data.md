- For teaching purpose, let's begin by making some data. We'll use the [`make_circles()`](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.make_circles.html) method from Scikit-Learn to generate two circles with different colored dots.
	```Python
	import sklearn
	from sklearn.datasets import make_circles
	
	# Make 1000 sampels
	n_samples = 1000
	# Create circles
	X, y = make_circles(n_samples,
	                    noise=0.03,
	                    random_state=42)
```
	- `sklearn`: a popular and helpful machine learning library
	- `noise=0.03`: add a little bit of noise to the dots
	- `random_state=42`: set random state manully
- Visualize the data and put them into pandas DataFrame
	```Python
	# Make DataFrame of circle data
	import pandas as pd
	circles = pd.DataFrame({"X1": X[:, 0],
	    "X2": X[:, 1],
	    "label": y
	})
	# circles.head(10)
	
	# Visualize with a plot
	import matplotlib.pyplot as plt
	plt.scatter(x=X[:, 0], 
	            y=X[:, 1], 
	            c=y, 
	            cmap=plt.cm.RdYlBu);
```
