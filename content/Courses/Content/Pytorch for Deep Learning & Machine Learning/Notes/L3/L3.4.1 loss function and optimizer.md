- ***Loss function***: a function to measure how wrong the predictions are to the ideal outputs, lower is better.
- ***Optimizer***: takes into account the loss of a model and adjusts the model's parameters (e.g. `weight`&`bias`)
- For PyTorch, what else is needed is a *training loop* and a *testing loop*.

| Function          | What does it do?                                                                                                                | Where does it live in PyTorch?                                                                                             | Common values                                                                                                                                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Loss function** | Measures how wrong your models predictions (e.g. `y_preds`) are compared to the truth labels (e.g. `y_test`). Lower the better. | PyTorch has plenty of built-in loss functions in [`torch.nn`](https://pytorch.org/docs/stable/nn.html#loss-functions).     | Mean absolute error (MAE) for regression problems ([`torch.nn.L1Loss()`](https://pytorch.org/docs/stable/generated/torch.nn.L1Loss.html)). Binary cross entropy for binary classification problems ([`torch.nn.BCELoss()`](https://pytorch.org/docs/stable/generated/torch.nn.BCELoss.html)). |
| **Optimizer**     | Tells your model how to update its internal parameters to best lower the loss.                                                  | You can find various optimization function implementations in [`torch.optim`](https://pytorch.org/docs/stable/optim.html). | Stochastic gradient descent ([`torch.optim.SGD()`](https://pytorch.org/docs/stable/generated/torch.optim.SGD.html#torch.optim.SGD)). Adam optimizer ([`torch.optim.Adam()`](https://pytorch.org/docs/stable/generated/torch.optim.Adam.html#torch.optim.Adam)).                               |

- *Loss function* may also be called *cost function* or *criterion* in different areas.
- Depending on what kind of problem you're working on will depend on what loss function and what optimizer you use.
	- Common loss function
		- MAE (mean absolute error) (for linear regression)
		- Binary cross entropy (for classification)
	- Common optimizer
		- SGD (stochastic gradient descent)
		- Adam
- For now, let's use MAE (in PyTorch: `torch.nn.L1Loss`) and SGD (in PyTorch: `torch.optim.SGD(params, lr)`)
	```Python
	# Create the loss function
	loss_fn = nn.L1Loss() # MAE
	
	# Create the optimizer
	optimizer = torch.optim.SGD(params=model_0.parameters(), # parameters of target model to optimize
								lr=0.01) # learning rate (how much the optimizer should change parameters at each step, higher=more (less stable), lower=less (might take a long time))
```
	- `nn.L1Loss`: i.e. MAE, measures the absolute difference between two points (predictions and labels) and then takes the mean across all examples.
		- mapping between loss functions and PyTorch functions see [torch.nn official document](https://pytorch.org/docs/stable/nn.html#loss-functions).
	- `torch.optim.SGD(params, lr)`
		- `params` is the target model parameters 
			- e.g. the `weights` and `bias` (values we want to optimize)
		- `lr` is the **learning rate**, i.e. how much the optimizer should change parameters at each step
			- higher(more) means the optimizer will try larger updates (these can sometimes be too large and the optimizer will fail to work)
			- lower(less) means the optimizer will try smaller updates (these can sometimes be too small and the optimizer will take too long to find the ideal values)
		- The learning rate is considered a **hyperparameter** (because it's set by a machine learning engineer). Common starting values for the learning rate are `0.01`, `0.001`, `0.0001`, however, these can also be adjusted over time (this is called [learning rate scheduling](https://pytorch.org/docs/stable/optim.html#how-to-adjust-learning-rate)).
