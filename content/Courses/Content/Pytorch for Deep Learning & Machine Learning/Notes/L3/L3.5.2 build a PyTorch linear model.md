- This time, we use `nn.Linear(in_features, out_features)` instead of defining the weight and bias parameters of our model manually using `nn.parameter`
	- `in_features` is the number of dimensions of your input data
	- `out_features` is the number of dimensions of your desired output
	- In our case, both of these are `1` since our data has `1` input feature (`X`) per label (`y`).
- Example code:
	```Python
	# Subclass nn.Module to make our model
	class LinearRegressionMode(nn.Module):
	    def __init__(self):
	        super().__init__()
	        # Use nn.Linear() for creating the model parameters
	        self.linear_layer = nn.Linear(in_features=1, 
	                                      out_features=1)
	    
	    # Define the forward computation (input data x flows through nn.Linear())
	    def forward(self, x: torch.Tensor) -> torch.Tensor:
	        return self.linear_layer(x)
```
