- **The 3 big errors with PyTorch & deep learning.**
	1. Tensors not right datatype: `tensor.dtype`
		- two tensors do not have the same datatype, i.e. one is `torch.float32` and the other is `torch.float16`
	2. Tensors not right shape: `tensor.shape`
		- two tensors' shapes don't match up
	3. Tensors not on the right device: `tensor.device`
		- two tensors do not have the same device, i.e. one is on the CPU and the other is on the GPU
- There are many different [tensor datatypes available in PyTorch](https://pytorch.org/docs/stable/tensors.html#data-types). Some are specific for CPU and some are better for GPU. Generally, if you see `torch.cuda` anywhere, the tensor is being used for GPU (since Nvidia GPUs use a computing toolkit called *CUDA*).
- The most common type (and generally the default) is `torch.float32` or `torch.float`.
	- This is referred to as "32-bit floating point".
	- But there's also 16-bit floating point (`torch.float16` or `torch.half`) and 64-bit floating point (`torch.float64` or `torch.double`).
	- The difference between those are computing speed (memory space) v.s. computing precision (precision in computing).
- Three important parameters of one tensor:
	```Python
	# Default datatype for tensors is float32
	float_32_tensor = torch.tensor([3.0, 6.0, 9.0],
								   dtype=None,
								   device=None,
								   requires_grad=False)
	float_32_tensor.shape
	print(float_32_tensor.dtype)
	float_32_tensor.device
```
	```Shell
	torch.Size([3])
	torch.float32
	device(type='cpu')
```
	- `dtype=None`: default to `None`, which is `torch.float32` or whatever datatype is passed
		- Datatype can change later: 
			`float_16_tensor = float_32_tensor.type(torch.float16)`
	- `device=None`: default to `None`, which uses the default tensor type, i.e. `cpu`, `cuda`(i.e. gpu)
	- `requires_grad=False`: if `True`, operations performed on the tensor are recorded 
- Get information from tensors: "what? what? where?"
	- `shape` - what shape is the tensor? (some operations require specific shape rules)
	- `dtype` - what datatype are the elements within the tensor stored in?
	- `device` - what device is the tensor stored on? (usually GPU or CPU)
	```Python
	# Create a tensor
	some_tensor = torch.rand(3, 4)
	
	# Find out details about it
	print(some_tensor)
	print(f"Shape of tensor: {some_tensor.shape}")
	print(f"Datatype of tensor: {some_tensor.dtype}")
	print(f"Device tensor is stored on: {some_tensor.device}") # will default to CPU
```
	```Shell
	tensor([[0.4688, 0.0055, 0.8551, 0.0646],
	        [0.6538, 0.5157, 0.4071, 0.2109],
	        [0.9960, 0.3061, 0.9369, 0.7008]])
	Shape of tensor: torch.Size([3, 4])
	Datatype of tensor: torch.float32
	Device tensor is stored on: cpu
```
- When run into issues in PyTorch, it's very often one to do with one of the three attributes above, i.e. "what? what? where?".
