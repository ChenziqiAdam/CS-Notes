- You can put tensors/models on a specific device by `to(device)`
- Q. why?
	GPUs offer far faster numerical computing than CPUs do and if a GPU isn't available, because of our **device agnostic code** (see above), it'll run on the CPU.
	```Python
	# Create tensor (default on CPU)
	tensor = torch.tensor([1, 2, 3])
	
	# Tensor not on GPU
	print(tensor, tensor.device)
	
	# Move tensor to GPU (if available)
	tensor_on_gpu = tensor.to(device)
	tensor_on_gpu
```
	```Shell
	tensor([1, 2, 3]) cpu
	tensor([1, 2, 3], device='cuda:0') # stored on the 0th device
```
- But for NumPy, it only works on CPUs.
	- If tensor is on GPU, can't transform it to NumPy.
	- To get a tensor back to CPU and usable with NumPy we can use [`Tensor.cpu()`](https://pytorch.org/docs/stable/generated/torch.Tensor.cpu.html).
		```Python
		# Instead, copy the tensor back to cpu
		tensor_back_on_cpu = tensor_on_gpu.cpu().numpy()
		tensor_back_on_cpu
```

		- The above returns a copy of the GPU tensor in CPU memory so the original tensor is still on GPU.
