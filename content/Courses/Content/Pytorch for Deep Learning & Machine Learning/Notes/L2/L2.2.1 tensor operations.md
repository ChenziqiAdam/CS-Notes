- Tensor operations
	- Addition
	- Subtraction
	- Multiplication (element-wise)
	- Division
	- **Matrix multiplication**
	```Python
	tensor = torch.tensor([1, 2, 3])
	tensor + 10
	tensor * 10
```
- PyTorch also has built-in operation functions.
	```Python
	tensor = torch.tensor([1, 2, 3])
	torch.add(tensor, 10)
	torch.mul(tensor, 10)
```
	- Use PyTorch in-built functions more as they tend to be faster and more readable.
	-  [More built-in functions available in PyTorch](https://pytorch.org/docs/stable/torch.html#math-operations)
- Matrix multiplication
	- Element-wise multiplication
	- Matrix multiplication
	```Python
	tensor = torch.tensor([1, 2, 3])
	print(tensor * tensor)
	print(tensor @ tensor) 
	# equal to tensor.matmul(tensor)
	# also equal to tenrch.matmul(tensor, tensor)
```
	```Shell
	tensor([1, 4, 9])
	tensor(14)
```

| Operation                   | Calculation                     | Code                    |
| --------------------------- | ------------------------------- | ----------------------- |
| Element-wise multiplication | `[1*1, 2*2, 3*3]` = `[1, 4, 9]` | `tensor * tensor`       |
| Matrix multiplication       | `[1*1 + 2*2 + 3*3]` = `[14]`    | `tensor.matmul(tensor)` |
- One of the most common errors in deep learning: shape errors.
	- Two main rules for matrix multiplication:
		1. The **inner dimensions** must match
		2. The resulting matrix has the shape of the **outer dimensions**
	- **Visualize** matrix multiplication at [http://matrixmultiplication.xyz/](http://matrixmultiplication.xyz/)
	- p.s. `torch.mm()` is a short version for `torch.matmul()`, but only works for matrices.
- Transpose
	- `tensor.T`: transpose `tensor`, i.e. switch the dimensions
	- Also `torch.transpose(input, dim0, dim1)` - where `input` is the desired tensor to transpose and `dim0` and `dim1` are the dimensions to be swapped.
	```Python
		tensor = torch.tensor([[ 7., 10.],
								[ 8., 11.],
						        [ 9., 12.]])
		tensor.T
```
	```Shell
		tensor([[ 7.,  8.,  9.],
		        [10., 11., 12.]])
```
