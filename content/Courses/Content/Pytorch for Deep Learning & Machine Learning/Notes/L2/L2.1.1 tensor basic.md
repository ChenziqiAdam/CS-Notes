- `torch.tensor()`: <u>create a tensor</u>
	```Python
	import torch
	torch.__version__
	```
	```Shell
	2.3.0+cu121 # the cu121 here is the code for CUDA later
```
	- Scalar
		```Python
		# Scalar
		scalar = torch.tensor(7)
		scalar # print self out
		scalar.ndim
		scalar.item()
	```
		```Shell
		tensor(7)
		0
		7
```
		- `.ndim`: <u>print out the dimension of the tensor</u>
		- `.item()`: retrive the number from the tensor
	- Vector
		```Python
		# Vector
		vector = torch.tensor([7, 7])
		vector
		vector.ndim
		vector.shape
```
		```Shell
		tensor([7, 7])
		1
		torch.Size([2])
```
		- Dimension is equal to the number of square brackets on the outside.
		- `.shape`: <u>tell how the elements inside are arranged</u>
	- Matrix
		```Python
		# Matrix
		MATRIX = torch.tensor([[7, 8], 
		                       [9, 10]])
		MATRIX
		MATRIX.ndim
		MATRIX.shape
```
		```Shell
		tensor([[ 7,  8],
		        [ 9, 10]])
		2
		torch.Size([2, 2])
```
	- Tensor
		```Python
		# Tensor
		TENSOR = torch.tensor([[[1, 2, 3],
		                        [3, 6, 9],
		                        [2, 4, 5]]])
		TENSOR
		TENSOR.ndim
		TENSOR.shape
```
		```Shell
		tensor([[[1, 2, 3],
		         [3, 6, 9],
		         [2, 4, 5]]])
		3
		torch.Size([1, 3, 3])
```
