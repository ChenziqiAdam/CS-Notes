- Reproducibility(复现性): try to take random out of random
	- Although neural networks start with randomness, there are ways to reduce the randomness.
	- PyTorch comes the concept of a ***random seed***.
	```Python
	import torch
	
	# Set the random seed
	RANDOM_SEED=42
	torch.manual_seed(seed=RANDOM_SEED)
	random_tensor_A = torch.rand(3, 4)
	
	# Have to reset the seed every time a new rand() is called 
	# Without this, tensor_B would be different to tensor_A 
	torch.random.manual_seed(seed=RANDOM_SEED) # try commenting this line out and seeing what happens
	random_tensor_B = torch.rand(3, 4)
```
- Reproducibility is one important part in PyTorch. More on [The PyTorch reproducibility documentation](https://pytorch.org/docs/stable/notes/randomness.html)and [The Wikipedia random seed page](https://en.wikipedia.org/wiki/Random_seed).
