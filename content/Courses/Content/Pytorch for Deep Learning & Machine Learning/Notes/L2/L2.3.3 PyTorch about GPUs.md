- GPUs are faster on computing numerical numbers.
- GPUs here refer to [Nvidia GPU with CUDA](https://developer.nvidia.com/cuda-gpus) enabled (CUDA is a computing platform and API that helps allow GPUs be used for general purpose computing & not just graphics)
- CUDA+NVIDIA+PyTorch all works together to make everything hunky.
- Q. how to get GPUs?
	- Google Colab
	- Purchase own GPU. See [Tim Dettmers has an excellent guide](https://timdettmers.com/2020/09/07/which-gpu-for-deep-learning/)
	- Cloud computing: GCP, AWS, Azure
- For the later two, need to set up following [PyTorch installation guidelines](https://pytorch.org/get-started/locally/)
- Check access to a Nvidia GPU: `!nvidia-smi`
- Set device on which codes can run
	```Python
	# Set device type
	import torch
	torch.suda.9s_avaiable()
	# Setup device agnostic code
	device = "cuda" if torch.cuda.is_available() else "cpu"
	device
```
	```Shell
	True
	'cuda'
```
	- For PyTorch since it's capable of running compute on the GPU or CPU, it's best practice to setup [**device agnostic code**](https://pytorch.org/docs/master/notes/cuda.html#device-agnostic-code)
- You can also count the number of GPUs PyTorch has access to: `torch.cuda.device_count()`
