- Cache parameters:
	- 2-way set associative, 6-bit addresses, 1-word blocks, 4-word cache, write-through
	- How many sets?
		- C÷K÷N = 4÷1÷2 = 2 sets
	- TIO Breakdown:
		- O = log<sub>2</sub>(4) = 2, I = log<sub>2</sub>(2) = 1, T = 6 - 1 - 2 = 3
- In Summary:
	- 2-way set associative, 6-bit addresses, 1-word blocks, 4-word cache, write-through
	- Offset - 2 bits, Index - 1 bit, Tag - 3 bits
