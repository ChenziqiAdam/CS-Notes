- Cache parameters:
	- Direct-mapped, address space of 64B, block size of 4B, cache size of 16B, write-through
	- TIO Breakdown:
		- O = log<sub>2</sub>(4) = 2
		- Cache size / block size = 16/4 = 4, so I = log<sub>2</sub>(4) = 2
		- A = log<sub>2</sub>(64) = 6 bits, so T= 6 - 2 - 2 = 2
	- Bits in cache = 2<sup>2</sup> × (8 x 2<sup>2</sup> + 2 + 1) = 140 bits (less bits compared to FA cache)
- In Summary:
	- Direct-mapped, address space of 64B, block size of 4B, cache size of 16B, write-through
	- *Offset* - 2 bits, *Index* - 2 bits, *Tag* - 2 bits
