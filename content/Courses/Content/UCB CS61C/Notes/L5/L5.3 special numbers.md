- Special Numbers
	- Zero
		- 0x00000000 = 1.0 x 2<sup>-127</sup>
		- Representation: *Special Case* Exp and Significand are all zero = 0
	- +/- Infinity
		- Division by zero
			- Infiniti is a number.
			- Okay to do further comparison, e.g. x/0 > y
		- Representation
			- Max Exp = 255 (all 1's)
			- All zero Significand (all 0's)
	- Not-A-Number
		- e.g. 0/0, `sqrt(-1)`, infinity - infinity
		- Representation
			- Max Exp = 255 (all 1's)
			- Non-zero significand
	- Denorm Numbers
		- Short for "denormalized numbers"
		- (−1)<sup>sign</sup> × (***0*** + fraction) × 2<sup>exponent−bias</sup>
			- No leading 1 (for fraction)
			- **Implicit exponent = -126** when Exp = 0x00
			- (intuitive reason: the "binary point" moves one more bit to the left of the leading bit)
		- Gaps
			- Smallest denorm: 0.0...01<sub>two</sub>x2<sup>-126</sup> = 2<sup>-149</sup>
			- Largest denorm: 0.1...1<sup>two</sup>x2<sup>-126</sup> = 2<sup>-126</sup> - 2<sup>-149</sup>
			- Smallest norm: 1.0...0<sup>two</sup>x2<sup>-126</sup> = 2<sup>-126</sup>

| Siginificand | Exponent | Representation |
| ------------ | -------- | -------------- |
| 0            | 0        | 0              |
| 0            | non-zero | Denorm fl. pt. |
| 1-254        | anything | Norm fl. pt.   |
| 255          | 0        | Infinity       |
| 255          | non-zero | NaN            |
