- Direct-Mapped Caches (One-way SA cache): Use "hash function" to determine location for block
	- Each block maps deterministically into a single row; which row == determined by index bit(s)!
	- \# index bits = log_2( cache size / block size )
	![[Pasted image 20250331113157.png]]
- N-way Set Associative Caches: Split slots into sets of size N, map into set, which is a row containing multiple blocks
	- Set (row) chosen by index, block (spot WITHIN row) chosen by replacement policy
	- \# index bits = log_ 2( cache size / (N * block size) )
	![[Pasted image 20250331113338.png]]
- ***TIO*** breakdown of memory address
	- Index field is result of hash function (which *set*, *row*)
		- log_2( cache size / (N * block size) )
	- Tag field is identifier (which block is currently in slot)
		- addr - index - offset
	- Offset field indexes into block
		- log_2( block size )
