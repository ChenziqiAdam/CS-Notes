- By convention, RISC-V instructions are each 1 word = 4 bytes = 32 bits
- Divide the 32 bits of an instruction into "**fields**"
	- regular field sizes -> simpler hardware
	- but need some variation
- Define 6 types of instruction formats:
	- R-Format : instructions using 3 register inputs
		- `add`, `xor`, `mul`
	- I-Format: instructions with immediates, loads
		- `addi`, `lw`, `jalr`, `slli`
	- S-Format: store instructions
		- `sw`, `sb`
	- B-Format: branch instructions
		- `beq`, `bge`
	- U-Format: instructions with upper immediates (20-bits)
		- `lui`, `auipc`
	- J-Format: jump instruction
		- `jal`

```
  1. R-Type (Register) Instruction Format
    +---------+---------+---------+---------+---------+---------+
    | opcode  |  rs1    |  rs2    | funct3  |  rd     | funct7  |
    +---------+---------+---------+---------+---------+---------+
      7 bits    5 bits    5 bits    3 bits    5 bits    7 bits
```
```
  2. I-Type (Immediate) Instruction Format
    +---------+---------+---------+----------+---------+
    | opcode  |  rs1    | funct3  |imm[11:0] |   rd    |
    +---------+---------+---------+----------+---------+
      7 bits    5 bits    3 bits    12 bits    5 bits
```
```
  3. S-Type (Store) Instruction Format
    +---------+---------+---------+---------+---------+----------+
    | opcode  |  rs1    |  rs2    | funct3  |imm[4:0] |imm[11:5] |
    +---------+---------+---------+---------+---------+----------+
      7 bits    5 bits    5 bits    3 bits    5 bits    7 bits
```
```
  4. B-Type (Branch) Instruction Format
    +---------+---------+---------+---------+---------+----------+
    | opcode  |  rs1    |  rs2    | funct3  |imm[11]  |imm[10:5] |
    +---------+---------+---------+---------+---------+----------+
      7 bits    5 bits    5 bits    3 bits    1 bit     6 bits  
	imm[4:1] are concatenated in the instruction
```
```
  5. U-Type (Upper Immediate) Instruction Format
    +---------+---------+---------+---------+--------+
    | opcode  |   imm[31:12]                | rd     |
    +---------+-----------------------------+--------+
      7 bits       20 bits                    5 bits
```
```
  6. J-Type (Jump) Instruction Format
    +--------+-----------+---------+----------+--------+-------+
    | opcode |imm[19:12] | imm[11] |imm[10:1] |imm[20] | rd    |
    +--------+-----------+---------+----------+--------+-------+
      7 bits   8 bits      1 bit     10 bits    1 bit    5 bits
```
