- Address
	- The size of an address (and thus, the size of a pointer) in bytes depends on architecture.
		- We assume a machine is a 32-bit machine by default).
	- If a machine is **byte-addressed**, then each of its addresses points to a unique **byte**.
		- word-address = address points to a word
	- Endianness: The bytes of an integer in memory are ordered in some specific ways on a byte-addressed machine.
		- Big Endian
			- Descending numerical significance with ascending memory addresses
		- Little Endian
			- Ascending numerical significance with ascending memory addresses
		- Example: if you store the 32-bit integer `0x12345678`,
			- Big Endian: `0x12 0x34 0x56 0x78`
			- Little Endian: `0x78 0x56 0x34 0x12`
			- i.e. each byte is represented as a two-digit hexadecimal number.
	- Note
		- Endianness ONLY APPLIES to values that occupy multiple bytes
		- Endianness refers to STORAGE IN MEMORY NOT number representation
		- Ex: `char c = 97`, `c == 0b01100001` in both big and little endian
		- Arrays and pointers still have the same order
			- `int a[5] = {1, 2, 3, 4, 5}` (assume address `0x40`)
			- `&(a[0]) == 0x40 && a[0] == 1`
