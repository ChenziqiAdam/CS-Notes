- Linked List
	- `struct`
	```c
	struct Node {
		char *value;
		struct Node *nest;
	} node;
```
	- `addNode()`: no dereference, then no worry for `NULL`
	```c
	node *addNode(char *s, node *list) {
		node *new = (node *) malloc(sizeof(NodeStruct));
		new->value = (char *) malloc(strlen(s) + 1); // Do not forget the null terminator!
		strcpy(new->value, s);
		new->next = list;
		return new;
	}
```
	- `deleteNode()`
	```c
	node *deleteNode(node *list) {
		node *temp = list->next;
		// Free in correct order!
		free(list->value);
		free(list);
		return temp;
	}
```
