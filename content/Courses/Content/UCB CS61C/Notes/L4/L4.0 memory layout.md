- C Memory Layout: Program's *address space* contains 4 regions:
	- **Stack**: local variables, grows downward
	- **Heap**: space requested via `malloc ()` and used with pointers; resizes dynamically, grows upward
	- **Static Data**: global and static variables, does not grow or shrink
	- **Code**: loaded when program starts, does not change
```sql
|-------------------------------| <- High Memory Address
|     Stack (grows downward)    |  (Local variables, function calls, return addresses)
|-------------------------------|
|      Heap (grows upward)      |  (Dynamically allocated memory)
|-------------------------------|
|    Uninitialized Data (BSS)   |  (Global/static vars initialized to 0)
|-------------------------------|
|         Static Data           |  (Global/static vars initialized by programmer)
|-------------------------------|
|            Code               |  (Program's code, function definitions)
|-------------------------------| <- Low Memory Address

```
- Q. Where do variables go?
	- Declared outside a function: Static Data
	- Declared inside a function (e.g. `main()`): Stack
	- Dynamically allocated: Heap
	```c
	#include <stdio.h>
	int varGlobal; // Static Data
	
	int main () {
		int varLocal; // Stack
		int *varDyn = malloc (sizeof(int)); // Heap
	}
```
