- Common Memory Problems
	1) Using uninitialized values
	2) Using memory that you don't own
		- Using `NULL` or garbage data as a pointer
		- De-allocated stack or heap variable
		- Out of bounds reference to stack or heap array
	3) Freeing invalid memory
	4) Memory leaks
- Memory Leaks
	- Remember that Java has garbage collection but C doesn't. You need to pick up your own trash.
	- Memory Leak: when you allocate memory but lose the pointer necessary to free it
	- **Rule of Thumb**: More `malloc()`s than `free()`s probably indicates a memory leak
	- Potential memory leak: Changing pointer 
		- Do you still have copy to use with free later?
- Debugging Tools: [Valgrind](http://valgrind.org)
