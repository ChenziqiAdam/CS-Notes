- Allocate Memory
	- `malloc()`
		- Allocates a continuous block of n bytes of uninitialized memory (contains garbage!)
		- Returns a pointer to the beginning of the allocated block; `NULL` indicates failed request.
		- Different blocks are not necessarily adjacent.
		- Almost always used for arrays or structs
			- **Good practice to use `sizeof()` and typecasting**
				- `int *p = (int *) malloc(n*sizeof(int)) ;`
				- `sizeof()` makes code more portable
				- `malloc()` returns `void *` 
				- Typecast will help you catch coding errors when pointer types don't match
			- Can use array or pointer syntax to access
	- `free(p)`: Release memory on the Heap using `free()` as emory is limited, release when done.
		- Pass it pointer `p` to beginning of allocated block; releases the whole block
		- `p` must be the address originally returned by `malloc()`/`realloc()`/`calloc()`, otherwise throws system exception (double free error)
		- Don't call `free()` on a block that has already been released or on `NULL`
		- Make sure you don't lose the original address
			- `p++` is bad and nor recommended
	- `void *calloc(size_t nmemb, size_t size)`
		- Like `malloc()`, except it initializes the memory to 0
		- `nmemb` is the number of members
		- `size` is the size of each member
		- e.g.  for allocating space for 5 integers: `int *p = (int *) calloc(5, sizeof(int));`
	- `void *realloc(void *ptr, size_t size)`
		- Takes in a pointer that has been the return of `malloc`/`calloc`/`realloc` and a new size
		- Returns a pointer with now size space (or `NULL`) and copies any contents from pointer
		- `realloc` can move or keep the address the same
			- **Do not rely on the old pointer value!**
	- Example
	```c
	#include <stdlib.h>
	typedef struct {
		int x;
		int y;
	} point;
	point *rect; /* opposite corners = rectangle */
	...
	if( !(rect=(point *) malloc(2*sizeof(point))) ) // Check for returned NULL
	{
		printf("\nOut of memory! \n");
		exit (1);
	}
	... // Do NOT change rect during this time!!!
	free(rect);
```
