- Control bits/signals: All unsigned numbers
	- `PCSel`: determines the address of next instruction
		- By default, `PC` = `PC` + `4`
	- `ImmSel`: reflects correct immediate instructions
	- `RegWEn`: determines whether the instruction will write to a register or not
	- `BrUn`: controls the way to compare two register value, i.e. signed or unsigned
	- `BSel`: determines whether the instruction operates on registers or immediates
	- `ASel`: determines whether the instruction operates on register value or PC
	- `ALUSel`: determines which operation will be performed based on the operands
	- `MemRW`: determines whether the instruction can write to the memory
	- `WBSel`: determines whether the instruction needs to write to the return register
