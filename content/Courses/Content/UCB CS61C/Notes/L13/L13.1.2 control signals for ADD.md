- Control Signals for `ADD`
	- `PCSel`: Should we execute the next instruction (0), or jump control flow to the address given by our ALU output (1)?
		- Not a branch or jump
		- `PCSel` = 0
	- `ImmSel`: How do we want to assemble our immediate?
		- No immediate, i.e. we DON'T CARE about this signal 
		- `ImmSel` = *
	- `RegWEn`: Do we want to write (1) to our destination register rd, or not (0)?
		- Add should write! 
		- `RegWEn` = 1
	- `BrUn`: When we compare `R[rs1]` and `R[rs2]`, should the comparison be signed (0), or unsigned (1)?
		- Not a branch, i.e. this value doesn't matter
		- `BrUn` = *
	-  `ASel` & `BSel`: Which operands do we want to operate on?
		- `ADD` requires `rs1` and `rs2`
		- `ASel` = 0 (`rs1`)
		- `BSel` = 0 (`rs2`)
	- `ALUSel`: What operation do we want to perform?
		- `ADD` = add?
		- But it is an English value! In CPU, it actually is a binary value.
		- The mapping between english words and binary values depends on how you build your ALU!
	- `MemRW` & `WBSel`: Are we reading (0) or writing (1) memory?
		- Wait, we're not doing anything with memory. Can this be a "don't care" value?
		- NO NO NO NO NO ! :(
		- We never want to "accidentally" write memory! This has to be a "passive read". 
		- `MemRW` = 0
	- `WBSel`: What value do we want to write back to `rd`?
		- ALU Out!
		- `WBSel` = 2
