- Arrays
	- Modern machines are "byte-addressable".
	- A C pointer is just abstracted memory address.
	- Type declaration tells compiler how many bytes to fetch on each access through pointer.
	- Q. Integer sizes are machine dependent, how do we tell?
		- `sizeof()`
		- Return size <u>in bytes</u> of variables or data type name.
			- Arrays: returns size of whole array
			- Structs: returns size of one instance of `struct` (sum of sizes of all struct variables + padding)
	- Struct Alignment （dependent on machine architecture)
		![[Pasted image 20250108110529.png]]
	- **Arrays in C does not know its own length, and its bounds are not checked!**
	```c
	const int ARRAY_SIZE = 10;
	int ar[ARRAY_SIZE]; // Single source of truth
	for (int i = 0; i < ARRAY_SIZE; i++) {}
```
	- Arrays v.s. Pointers
		- Arrays are almost identical to pointers.
		- **Key Concept**: An array variable looks like a pointer to the first element (0<sup>th</sup>).
			- `ar[0]` is equivalent to `*ar`, `ar[2]` is equivalent to `*(ar+2)`.
			- The compiler knows it is an integer array and will automatically grab 4 bytes as a group.
		- An array variable is read-only (no assignment).
			```c
			// Three ways to zero an array
			1) for (i=0; i<SIZE; it+) {ar[i] = 0;}
			2) for (i=0; i<SIZE; itt) {*(arti) = 0;}
			3) for(p=ar; p<ar+SIZE; p++) {*p = 0;}
```
			![[Pasted image 20250108113139.png]]
			```bash
			// Output
			*p:1, p:40, &p:20
			*a:2, a:24, &a:24
	```
			- The address of an array is meaningless.
			- It is a variable, so it equals to the address of the first element in the array.
		- An array is passed to a function as a pointer. Thus you must explicitly pass the size.
			- Note. For local arrays inside function that is unnecessary.
