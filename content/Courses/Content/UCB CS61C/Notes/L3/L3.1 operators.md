- Operator Precedence
	- `++`
		- **Prefix** (`++p`) takes effect *immediately*.
		- **Postfix/Suffix** (`p++`) takes effect *last*.
	```c
	int main () {
		int x = 1;
		int y = ++x; // y = 2, x = 2
		x--; // x = 1
		int z = x++; // z = 1, x = 2
		return O;
	}
```
