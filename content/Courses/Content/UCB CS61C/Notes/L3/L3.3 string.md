- Strings
	- A String in C is just an array of characters
	```c
	char letters []] = "abc";
	const char letters[] = f{'a', 'b', 'c', '\0'};
	```
	- Q. How do we know when the string ends? "Null terminator" `\0` is the last character.
		- This means you need an extra space when allocating memory, i.e. the string length plus one.
		```c
		int strlen (char s[]) {
			int n = 0;
			while (s[n] != 0) {n++;}
			return n;
		}
```
	- Standard Functions
		- `int strlen(char *string)`
		- `int strcmp(char *str1, char *str2)`
			- `str1 == str2` just compares the location of the two strings instead of the content!
		- `char *strcpy(char *dst, char *src)`
			- Note. Only *shallow copy* not *deep copy*, i.e. share the same memory.
	- Example
	```c
	#include <stdio.h›
	#include ‹string.h›
	int main () {
		char s1[10], s2[10], s3[]="hello", *s4="hola";
		strcpy (s1, "hi");
		strcpy (s2, "hi");
	}
```
	```bash
	sizeof(s1) // 10
	strlen(s1) // 2
	s1 == s2 // 0 // Point to different locations
	strcmp(s1, s2) // 0
	strcmp(s1, s3) // 4
	strcmp(s1, s4) // -6
```
