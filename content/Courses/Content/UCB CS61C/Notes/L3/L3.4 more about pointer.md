- Pointer Arithmetic
	- A pointer is just a memory address.
	- `p+1` increments `p` by `sizeof(*p)`, i.e. moves pointer to the next array element.
	- Example: assume `a` at address 100
		```c
		char *p; 
		char a;
		p = &a;
		printf("%u %u\n", p, p+1);
		
		int *p; 
		int a;
		p = &a;
		printf("%u %u\n", p, p+1);
	```
		```bash
		100 101
		100 104
	```
	- Valid pointer arithmetic?
		- Add an integer to a pointer
		- Subtract 2 pointers (in the same array)
		- Compare pointers
		- Compare pointer to NULL (indicates that the pointer points to nothing)
	- Increment and Dereference
		- When multiple prefixal operators are present, they are applied from right to left
			- `*--p` decrements p, returns value at that address
				- `--` binds to `p` before `*` and takes effect first
			- `++*p` increments `*p` and returns that value
				- `*` binds first (get value), then increment immediately
		- *Postfixal* in/decrement operators have precedence over prefixal operators (e.g. `*`)
			- BUT the in/decrementation takes effect last because it is a postfix. The "front" of expression is returned.
			- `*p++` returns `*p`, then increments `p`
				- `++` binds to `p` before `*`, but takes effect last
		- Example 1
			```c
			char *p = "hi"; // assume p has value 40
			char c = *p++; // c = 'h', p = 41
			c = *p; // c = 'i'
```
			- `char c = *p++;`
			1. Evaluate `*p = 'h'`
			2. Assignment `c = 'h'`
			3. `p++`; `p = 41`
		- Example 2
			```c
			char arr[] = "bye";
			char *p = arr; // assume p has value 40
			char c = (*p)++; // c = 'b', p = 40, *p = c
			c = *p; // c = 'c'
```
			- `char c = (*p)++;`
			1. Evaluate `*p = 'b'`
			2. Assign `c = 'b'`
			3. `(*p)++`; `*p = c`
	- Pointers and Allocation
		- When you declare a pointer, it does not actually point to anything yet.
		- Option 1: Point to something that already exists
		- Option2: Allocate room in memory for new thing to point to
	- Pointers and Structures
		- `struct` cannot contain an instance of itself, but can point to one.
		- With this we can achieve something similar to *class*.
		- Access elements in a structure
			1. `pt.x`
			2. `ptaddr->x`
			3. `(*ptaddr).x`
		- `pt1 = pt2` copies the content.
