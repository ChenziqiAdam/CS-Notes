- Immediate Instruction
	- ***Immediate***: numerical constants
	- Instruction syntax for immediates:
		`opi dst, src, imm`
		- Operation names end with `i`, replace 2<sup>nd</sup> source register with an immediate
		- Immediates can be up to 12-bits in size
		- Interpreted as sign-extended two's complement
	- Example: Suppose `a` -> `s0`, `b` -> `s1`. Convert the following C statement to RISCV:
		`a = (5+b)-3;`
	```RISCV
		addi t1, s1, 5
		addi so, t1, -3
	```
