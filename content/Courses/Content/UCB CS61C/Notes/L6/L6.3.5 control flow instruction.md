- In C, we had **control flow**. In RISCV, we can't define blocks of code; all we have are **labels**:
	- Defined by text followed by a colon (e.g. `main:`) and refers to the instruction that follows
	- Generate control flow by jumping to labels
	- C has labels too, but they are considered bad style. **Don't use goto!**
- Decision Making Instructions
	- Branch If Equal (`beg`)
		- `beg regl, reg2, label`
		- If value in `reg1` = value in `reg2`, go to `label`
		- **Otherwise go to the next instruction**
	- Branch If Not Equal (`bne`)
		- `bne regl, reg2, label`
		- If value in `reg1` != value in `reg2`, go to `label`
	- Jump (`j`)
		- `j label`
		- Unconditional jump to `label`
	- Example:
		```C
		if (i=j) {
		a = b /* then */
		} else {
		a =-b /* else */
		}
		```
		```
		# i-s0, j+s1
		# a+s2, b+s3
		
		beg s0, s1, then # bne s0, s1, else
		else: # This label unnecessary
		sub s2, x0, s3
		j end
		then:
		add s2, s3, x0
		end:
		```
- More Branching Conditions
	- Branch Less Than (`blt`)
		- `blt regl, reg2, label`
		- If value in `reg1` < value in `reg2`, go to `label`
	- Branch Greater Than or Equal (`bge`)
		- `bge regl, reg2, label`
		- If value in `reg1` >= value in `reg2`, go to `label`
- Loops in RICSV
	- Though there are multiple ways to create a loop (while/for) in RISCV, the key to decision-making is the conditional branch.
- Program Counter
	- Branches and Jumps change the flow of execution by modifying the Program Counter (PC)
	- The PC is a special register that contains the current address of the code that is being executed
		- Not accessible as part of the normal 32 registers
	- Recall: Instructions are stored as data in memory and have addresses, i.e. Code section.
