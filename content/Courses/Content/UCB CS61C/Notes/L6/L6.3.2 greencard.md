- Greencard:
	- A quick reference that summarizes the RISC-V Instruction Set Architecture (ISA)

| **Instruction** | **Mnemonic**     | **Operands** | **FMT (Format)** | **Name**         | **Description**                                          |
| --------------- | ---------------- | ------------ | ---------------- | ---------------- | -------------------------------------------------------- |
| `lw`            | `lw t0, x`       | `t0, x`      | I-type           | Load Word        | Load a 32-bit word from memory at `x` into register `t0` |
| `add`           | `add t2, t0, t1` | `t2, t0, t1` | R-type           | Add              | Add values in `t0` and `t1`, store the result in `t2`    |
| `li`            | `li a0, 0`       | `a0, 0`      | Pseudo-op        | Load Immediate   | Load immediate `0` into register `a0` (exit code)        |
| `ecall`         | `ecall`          | None         | I-type           | Environment Call | Make a system call (exit the program)                    |

- Instruction: The actual opcode used in RISC-V assembly.
- Mnemonic: The exact instruction used in the example.
- Operands: The registers and memory locations involved in the operation.
- FMT (Format): The instruction encoding format (R-type, I-type, etc.).
- Name: The official name of the instruction.
- Description: What the instruction does.
