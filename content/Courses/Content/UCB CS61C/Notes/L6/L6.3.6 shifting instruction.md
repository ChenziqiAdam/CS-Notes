### Definition
- Shifting
	- In binary, shifting an unsigned number left is the same as multiplying by the corresponding power of 2
		- Shifting operations are faster
		- Does not work with shifting right/division
	- *Logical shift*: **Add zeros** as you shift
	- *Arithmetic shift*: **Sign-extend** as you shift
		- Only applies when you shift right (preserves sign)
	- Shifting can specify by an immediate or a variable.

### Example 1: Extracting a byte from a word using `lbu` (load byte unsigned)
```
# lbu using lw: lbu s1,1(s0)
lw  	s1,0(s0)       # get word
li  	tO,0x0000FF00  # load bitmask
and	    s1,s1,t0	   # get 2nd byte
srli	s1,s1,8	       # shift into lowest
```
- Step-by-Step Breakdown:
	1. **`lw s1, 0(s0)`**  
	    - This loads a 32-bit word from memory into register `s1`. The word is located at the memory address contained in register `s0`.  
	    - So, the value from memory at the address `s0` (32-bits or 4 bytes) is stored in `s1`.
	2. **`li t0, 0x0000FF00`**  
	    - This loads the constant value `0x0000FF00` into register `t0`.  
	    - This bitmask value is `00000000 00000000 11111111 00000000` in binary. It will help isolate the second byte (the 2nd 8-bit section) of the word.
	3. **`and s1, s1, t0`**  
	    - This performs a bitwise AND between the value in `s1` and the mask in `t0`.  
	    - This operation will zero out all the bits except for the second byte. For example, if `s1` contained the value `0x12345678`, after this operation, `s1` will become `0x00005600` (only the second byte is kept, others are zeroed out).
	4. **`srli s1, s1, 8`**  
	    - This is a "Shift Right Logical Immediate" instruction. It shifts the bits in `s1` to the right by 8 positions.  
	    - After the previous `and` operation, `s1` might have been `0x00005600`. This shift would result in `s1 = 0x00000056`, which brings the second byte to the least significant byte of the word. Now, you can access the byte directly.

### Example 2: Storing a byte into a word using `sb` (store byte)
```
# sb using sw: sb s1; 3(s0)
lw    t0,0(s0)        # get current word
li    t1, OxOOFFFFFF  # load bitmask
and   t0,t0,t1        # zero top byte
slli  t1,s1,24        # shift into highest
or    t0,t0,t1        # combine
sw    t0,0(s0)        # store back
```
- Step-by-Step Breakdown:
	1. **`lw t0, 0(s0)`**  
	    - This loads the current 32-bit word from the memory address contained in `s0` into register `t0`. This word contains the value in which you want to store a byte.
	2. **`li t1, 0x00FFFFFF`**  
	    - This loads the bitmask `0x00FFFFFF` into register `t1`. The mask is `11111111 11111111 11111111 00000000` in binary. This will help zero out the top (most significant) byte in the word.
	3. **`and t0, t0, t1`**  
	    - This AND operation between `t0` and `t1` will clear the top byte of `t0`. After the operation, the value in `t0` will have zeroed out the most significant byte. If `t0` was `0x12345678`, this step would result in `0x00345678`.
	4. **`slli t1, s1, 24`**  
	    - This shifts the byte in `s1` (the byte you want to store) left by 24 bits (3 bytes). It moves the byte into the most significant byte of `t1`.  
	    - For example, if `s1` contains `0x56`, after this shift, `t1` would become `0x56000000`.
	5. **`or t0, t0, t1`**  
	    - This OR operation combines the modified `t0` (with the cleared top byte) and `t1` (which contains the byte you want to insert in the highest byte).  
	    - If `t0` was `0x00345678` and `t1` was `0x56000000`, after this step, `t0` will become `0x56345678`, with the byte from `s1` inserted in the most significant byte.
	6. **`sw t0, 0(s0)`**  
	    - Finally, the modified word in `t0` is stored back into memory at the address in `s0`, effectively updating the original word with the new byte inserted in the highest byte.
