- Address Translation: the process of converting a virtual address to a physical address.
	- Virtual addresses can be broken into two parts (much like we broke them down for T/l/O): we'll call the two parts the page number and the offset
	![[Pasted image 20250404114317.png]]
	- We can calculate the size of these fields like we did with caches:
		- sizeof(Address) = log_2(Virtual Memory Size)
		- sizeof(offset) = log_2(page size)
		- sizeof(VPN) = log_2(# of virtual pages)
			- = address size - offset size
	- Because we've also divided physical memory into pages, the same process applies here! Given a physical address:
		- Break the address into page number (PPN) and offset
		- Locate the page
		- Locate the byte within the page
- Q. We still haven't solved our original problem: 
	- given a virtual address I can find a virtual byte
	- given a physical address I can find a physical byte, 
	- but: How do I go from virtual address to physical address?
- Paged VM: each process has a table mapping its physical/virtual pages
	![[Pasted image 20250404115436.png]]
- Page Table Entry Format
	- Contains either PPN or indication not in main memory
	- Dirty = Page has been modified recently
	- Valid = Valid page table entry
		- 1 -> virtual page is in physical memory
		- 0 -> OS needs to fetch page from disk Page Fault!
	- Access Rights checked on every access to see if allowed (provides protection)
		- Read, Write, Executable: Can fetch instructions from page
		- Protection Fault!
	![[Pasted image 20250404115622.png]]
	- For the Page Number, look up the page table; for the Offset, it does not require any change
		![[Pasted image 20250404115715.png]]
- Protection Between Processes
	- With a bare system, addresses issued with loads/stores are real physical addresses
	- This means any program can issue any address, therefore can access any part of memory, even areas which it doesn't own
		- Example: the OS data structures
	- Q. How does having a page table isolate and protect processes?
		- In order to create a physical address from a virtual one, we have to convert our page number (VPN -> PPN)
			- To do this, we look up a mapping for the VPN in our page table!
		- We can only "find" mappings for pages we own!
			- All other mappings are invalid or blank!
		- Therefore, we cannot construct physical addresses we do not have access to :)
	![[Pasted image 20250404120013.png]]
	- Physical pages do not need to be continuous.
