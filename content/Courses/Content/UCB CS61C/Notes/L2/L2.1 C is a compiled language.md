- C is a compiled language. C *compilers* map C programs into architecture-specific machine code (different from Java or Python).
	- Pros
		- Excellent run-time performance
		- Fair compilation time (Compilation procedure with `MakeFiles`)
	- Cons
		- Architecture-specific (depends on the systems or architectures)
		- Iteration cycle can be slow
