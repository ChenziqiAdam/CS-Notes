- Typed Variables
	- Integer sizes are machine dependent (4 bytes or 8 bytes).
	- For characters, encode characters are the same as numbers.
		- e.g. `char c = 'a';` is equivalent to `chat c = 97;`
	- A `char` takes up 1 byte of space.
- C is a "weakly" typed language, i.e. you can **typecast** from any type to another.
	- This is possible as everything is stored in bits.
- Typed Functions
	- Functions are also typed in C, i.e. the type of the return variable.
	- Declaring the "prototype" of a function allows you to use it anywhere. In reality always store in `hello.h`.
- Structs
	```c
	typedef struct ｛
		int lengthInSeconds；
		int yearRecorded；
	} Song；
	
	Song song1;
	song1.lengthInSeconds = 42;
	song1.yearRecorded = 1984;
	```
	- C does not have *classes*.
	- Equivalent to `struct` as below.
-  Structs Alignment and Padding
	```c
	struct foo｛
		int a;
		char b;
		struct foo *c;
	};
	```
	- They provide enough space and aligns the data with padding.
	- The actual layout on a 32 bit architecture would be：
		- 4-bytes for a
		- 1 byte for b
		- 3 unused bytes
		- 4 bytes for C (pointer)
	- sizeof（struct foo) == 12
- Unions
	```c
	union foo {
		int a;
		char b;
		union foo *c;
	}
	```
	- Provides enough space for the largest element.
