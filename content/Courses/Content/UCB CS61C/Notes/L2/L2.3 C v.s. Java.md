- Comparison:

|                   | C                              | Java                                 |
| ----------------- | ------------------------------ | ------------------------------------ |
| Type of Language  | Function Orented               | Object Oriented                      |
| Programming Unit  | Function                       | Class (ADT)                          |
| Compilation       | Creates machine-dependent code | Creates machine-independent bytecode |
| Execution         | *Loads* and *executes* program | JVM *interprets* bytecode            |
| Memory management | Manuak                         | Automatic (garbage collection)       |

- C and Java operators are almost the same.
- C Syntax
	- `int main(int argc, char *argv[])`
		- argc (argument count) contains the number of strings on the command line (the executable path counts as one, plus one for each argument).
		- argv (argument value) is an array containing pointers to the arguments as strings
	- C does not have explicit Boolean type!
		- FALSE in C is equivalent to `0` or `NULL`.
		- Anything that is not false is true.
	- C does not have else-if statement.
	- `switch` requires proper `break` to work properly.
