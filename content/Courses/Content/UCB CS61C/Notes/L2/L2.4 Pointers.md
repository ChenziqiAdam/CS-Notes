- **Pointers**
	- `int *x`: Declare variable x as the address of an int
	- `X=&Y`: Assigns address of y to x
		- `&` is called the "**address operator**"
	- `Z=*x`: Assigns the value at address in x to z
		- `*` is called the "**dereference operator**"
	- Points are used to point to one kind of data, including pointers.
		- Exception is `void *`, which can point to anything (generic pointer).
	- Functions can return pointers.
	- `int* x` is equivalent to `int *x`, but `int* x, y` is not equivalent to `int *x, *y`.
		- Avoid to declare multiple variables in the same line.
