- Q. 2 and 6: How do we Transfer Control?
	- Jump (`j`)
		- `j label`
	- Jump and Link (`jal`)
		- `jal dst label`
	- Jump and Link Register (`jalr`)
		- `jalr dst src imm`
		- "and Link": Saves the location of instruction in a register before jumping
	- Jump Register (`jr`): used to return from a function (`src` = `ra`)
		- `jr src`
	- `ra`: *return address register*, used to save where a function is called from so that we can get back
	- Example: `jal` and `ra` are a womb combination
	```
	1000  addi a0,s0,0      # x = a
	1004  addi a1,s1,0      # y = b
	1008  jal ra sum        # ra=1012, goto sum
	1012
	...
	2000  sum: add v0,a0,a1 
	2004  jr ra              # return
	```
- Q. How is `j` implemented?
	- `jal x0 label`
	- `x0` always contains 0, so attempts to write to it do nothing.
	- So `jal x0 label` is just jumping without linking.
- Q. `ret` is a pseudocode instruction that can be used to return from a function. Which real instruction(s) would you use to create `ret`?
	- `jalr x0,ra,0` or `jr ra`
