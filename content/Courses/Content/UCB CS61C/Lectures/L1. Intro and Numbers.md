- Number Representation
	- Number Base: 42 = 4x10<sup>1</sup> + 2x10<sup>0</sup>
	- Commonly Used Number Bases
		- **Decimal** (base 10)
		- **Binary** (base 2)
			- e.g. 101011<sub>two</sub> = 0b101011
			- One digit is called ***bit***.
		- **Hexadecimal** (base 16): 0-9 + A-F
			- e.g. 3A5D<sub>hex</sub> = 0x3A5D
- Bits can represent ANYTHING.
	- *n* digits (base B) -> <= *B<sup>n</sup>* things
- Represent Integers
	- **Unsigned Notation**
		- e.g. 000<sub>two</sub> = 0<sub>ten</sub>
		- cons: cannot represent negative integers
	- **Signed Notation**
		- e.g. 000<sub>two</sub> = -0<sub>ten</sub>, 100<sub>two</sub> = +0<sub>ten</sub>
		- cons: two zeros and complicated addition
	- **Biased Notation**
		- e.g. 000<sub>two</sub> = -3<sub>ten</sub>, 011<sub>two</sub> = 0<sub>ten</sub>, 111<sub>two</sub> = +4<sub>ten</sub>
		- cons: zero is not all 0s
	- **One's Complement** (a.k.a. "**inverse form**")
		- e.g. 001<sub>two</sub> = +1<sub>ten</sub>, 110<sub>two</sub> = -1<sub>ten</sub>
		- cons: two zeros and complicated addition
	- **Two's Complement**
		- e.g. 001<sub>two</sub> = +1<sub>ten</sub>, 111<sub>two</sub> = -1<sub>ten</sub>
		- To convert one integer, flip and then add 1.
- Numbers: hardware can only store a finite number of digits
	- Usually ignore *leading zeros*
	- Leftmost is *MSB* (most significant bit)
	- Rightmost is *LSB* (least significant bit)
- ***Overflow***: the result of an arithmetic operation cannot be represented by finite hardware bits.
- *Sign Extension*
	- To represent the same number using more bits, copy the sign bit and add more sign bits at the beginning.
- More Tips:
	1. Hexadecimal <-> Binary <-> Decimal
	2. 2<sup>5</sup> = 32, 2<sup>10</sup> = 1024
	3. KB: 2<sup>10</sup>, MB: 2<sup>20</sup>, GB: 2<sup>30</sup>, TB: 2<sup>40</sup>
