- Summary for memory
	- **Heap**: dynamic memory allocation region used for allocating and deallocating memory at runtime, e.g. `malloc()`.
	- **Pile**: informal term occasionally used to refer to the heap.
	- **Stack**: static memory allocation region used for storing function call-related data.
	- **Bin**: informal term sometimes used to refer to a container or storage location, not commonly used in technical discussions.
