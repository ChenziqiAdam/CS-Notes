- `cd`: <u>change the Current Working Directory to the specified directory</u>
- `cp`: <u>create a copy of one file or one directory</u>
- `ls`: <u>list all the contents in the folder</u>
- `mkdir`: <u>create a directory</u>
- `rmdir`: <u>remove a directory</u>
- `rm`: <u>remove a file</u>
- `mv`: <u>move a file or directory from one directory to another, or rename a file or directory</u>
