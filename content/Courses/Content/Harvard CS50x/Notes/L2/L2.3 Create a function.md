- Example
	```C
	int plusOne (int n) {
	n += 1;
	return n;
	}
```
	- `int plusOne`: return-value type and function name
		if no return: replace `int` with `void`
	- `(int n)`: argument type
		if no argument: just `()`
	- **Always remember to copy and paste the first line of these functions before the main function if they are used in main**
- Variables only exists inside the most recent curly braces, i.e. ***scope***
