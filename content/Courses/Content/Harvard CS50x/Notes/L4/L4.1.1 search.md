- Q. how to search for a number x?
	```C
	int main(void) {
		int numbers[] = {1, 2, 3, 4, 5};
		int l = sizeof(numbers) / sizeof(numbers[0]);
		for (int i = 0; i < l; i++) {
			if (numbers[i] == 6) {
				printf("Found!");
				return 0; // Similar to break
			}
		}
		printf("Not Found!");
		return 1;
	}
```
- **For `str` (string), "\==" does not work.**
	- Use the function `strcmp()` in `<string.h>`, i.e. `strcmp(strings[i], s) == 0`
	-  `return 0`: the return value can indicate the status of execution, i.e. `0` means success, while `1` means failure. 
	- Common return values: `404`.
		- <u>check the return value</u>: `echo $`
