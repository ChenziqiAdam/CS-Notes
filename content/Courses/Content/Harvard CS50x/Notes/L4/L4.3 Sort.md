1. ***Selection Sort (选择排序)***: *Θ*(n<sup>2</sup>) 
	- every time pick the smallest item in the rest unsorted, and put it to the end of the sorted
	- does not depend on the initial order
2. ***Bubble Sort (冒泡排序)***: *O*(n<sup>2</sup>)
	- swap the nearby two items if out of order
3. ***Merge Sort (归并排序)***: *Θ*(n\*log(n))
	- ==**Divide-and-Conquer**==
	- Example: 4 2 5 7 6 1 0 3
		1. <u>4 2</u> <u>5 7</u> <u>6 1</u> <u>0 3</u>
		2. <u>2 4</u> <u>5 7</u> <u>6 1</u> <u>0 3</u>
		3. <u>2 4 5 7</u> <u>0 1 3 6</u>
		4. <u>0 1 2 3 4 5 6 7 </u>
	- Example code with **Recursion**(递归): 
		==**Always remember the base case in recursion!**==
	```C
		#include <stdio.h>
		
		void merge(int arr[], int l, int m, int r) {
		    int n1 = m - l + 1;
		    int n2 = r - m;
		
		    int L[n1], R[n2];
		
		    // Copy data to temporary arrays L[] and R[]
		    for (int i = 0; i < n1; i++)
		        L[i] = arr[l + i];
		    for (int j = 0; j < n2; j++)
		        R[j] = arr[m + 1 + j];
		
		    // Merge the temporary arrays back into arr[l..r]
		    int i = 0, j = 0, k = l;
		    while (i < n1 && j < n2) {
		        if (L[i] <= R[j]) {
		            arr[k] = L[i];
		            i++;
		        } else {
		            arr[k] = R[j];
		            j++;
		        }
		        k++;
		    }
		
		    // Copy the remaining elements of L[], if any
		    while (i < n1) {
		        arr[k] = L[i];
		        i++;
		        k++;
		    }
		
		    // Copy the remaining elements of R[], if any
		    while (j < n2) {
		        arr[k] = R[j];
		        j++;
		        k++;
		    }
		}
		
		// Function to perform merge sort
		void mergeSort(int arr[], int l, int r) {
		    if (l < r) { // Base case here!
		        // Find the middle point
		        int m = l + (r - l) / 2;
		
		        // Sort first and second halves
		        mergeSort(arr, l, m);
		        mergeSort(arr, m + 1, r); // Recursion here!
		
		        // Merge the sorted halves
		        merge(arr, l, m, r);
		    }
		}
```
