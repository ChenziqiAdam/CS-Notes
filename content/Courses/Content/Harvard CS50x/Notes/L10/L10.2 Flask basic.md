- ***Flask***
	- a framework or a metaframework
	- enable programmers to implement web applications in Python
- <u>Start a web server</u>: `flask run`
- **Flask convention layout**:
```arduino
	my_flask_app/
	├── app.py  
		// Python code
	|-- requirements.txt  
		// text file, with tird-party libraries one per line
	|-- static/  
		// images or .js file
	└── templates/  
		// actual HTML, maybe CSS and JavaScript
```
