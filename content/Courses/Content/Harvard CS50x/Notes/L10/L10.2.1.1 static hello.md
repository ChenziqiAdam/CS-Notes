- Example: static hello
	```HTML
	<!-- index.html -->
	<!DOCTYPE html>

	<html lang="en">
	    <head>
	        <meta name="viewport" content="initial-scale=1, width=device-width">
	        <title>hello</title>
	    </head>
	    <body>
	        hello, world!
	    </body>
	</html>
```
	```Python
	# app.py
	from flask import Flask, render_template, request

	# create a Flask application insrance
	app = Flask(__name__)
	
	@app.route("/")
	def index():
	    return render_template("index.html")
```
	- `Flask`: <u>main class for creating a Flask web application</u>
	- `render_template`:  <u>function used to render an HTML template file</u>
	- `request`: <u>object used to handle HTTP requests in Flask</u>
	- `__name__`: <u>refer to the name of the file</u>
	- `@app.route("/")`: **decorator** associates the URL `/` (the root URL) with the `index` function. 
		- This means when someone accesses the root URL of the web server, the `index` function will be called.
	- `return render_template("index.html")`: tells Flask to render the `index.html` template when the `index` function is called. 
		- `render_template` looks for the `index.html` file in the `templates` folder by default.
