- Duplicate code is always not something good.
	- Example: `layout.html` ***templating***(模版)
		```HTML
		<!-- layout.html -->
		<!DOCTYPE html>
		
		<html lang="en">
		    <head>
		        <meta name="viewport" content="initial-scale=1, width=device-width">
		        <title>hello</title>
		    </head>
		    <body>
		        {% block body %}{% endblock %}
		    </body>
		</html>
	```
		- `{% block body %}{% endblock %}`: 
			- *Jinja* syntax
			- placeholder for a block of code
		```HTML
			<!-- greet.html -->
			{% extends "layout.html" %}
			
			{% block body %}
			
				hello, {{ name }}!
				
			{% endblock %}
```
		```HTML
			<!-- index.html -->
			{% extends "layout.html" %}
			
			{% block body %}
			
				<form action="/greet" method="get">
			        <input autocomplete="off" autofocus name="name" placeholder="Name" type="text">
			        <button tyoe="submit">Greet</button>
			    </form>
				
			{% endblock %}
```
