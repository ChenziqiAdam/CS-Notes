- ***Cookie***
	- a small piece of data that a server sends to a user's web browser
	- The browser stores this data and sends it back to the server with future requests to the same server.
- Q. what happens when the user logs in a website?
	- browser to server (first time)
		```HTTP
	HTTP/2 200
	Content-Type: text/html
	Set-Cookie: session=value
	...
```
	- server to brower (next time the user logs in)
		```HTTP
	GET / HTTP/2
	Host: accounts.google.com
	Cookie: session=value
```
	- When a user visits a website, the server can send a cookie to the user's browser. The browser stores the cookie and sends it back to the server with each subsequent request to the same server. This allows the server to recognize the user and maintain stateful information across different pages and sessions.
