- **brute-force attacks (暴力破解)**:
	```Python
	# crack.py
	from string import digits, ascii_letters, punctuation
	from itertools import product
	
	for passcode in product(digits + ascii_letters + punctuation, repeat=8):
	    print(passcode)
```
	- Solution: 
		- Account Lockout: Temporarily lock accounts after several failed login attempts
		- Rate Limiting: Limit the number of login attempts from a single IP address.
- ***Password Manager***
	- have a prime password that controls all the passwords inside
- ***TFA*: Two-Factor Authentication (双因素认证)**
	- require a second fundamentally different factor for verification, e.g. one-time pass code sent to one's phone
- ***Password Stuffing***:
	- due to the habbit that many users use the same password for different websites, the hackers can try on other websites once they hack in one account
- ***Hashing***:
	- hash function: one way, i.e. the reverse is impossible
	- the server hash the users' passwords and store it in its database s.t. avoid password stuffing
	- That is why when the user forget his password the web manager won't send him an email with his password but a one-time pass code.
- ***Rainbow Table***
	- list all possible hash value and corresponding real password in a dictionary
- Q. what if two users' passwords are the same
	- **Salting**: add some additional value when hashing
