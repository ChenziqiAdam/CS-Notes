- ***Symmetric Cryptography*** (对称加密)
	- plaintext + key --cipher-> ciphertext
		- rotational cipher
		- substitution cipher
	- reversible
	- a.k.a. secret-key cryptography
- ***Asymmetric Cryptography*** (非对称加密)
	- a.k.a. public-key cryptography
	- a key pair: a public key plus a private key
	plaintext + public key -> ciphertext
	ciphertext + private key -> plaintext
	- HTTPS underneath cryptography
- ***Passkeys***
	- a new feature of operating systems, a.k.a. passwordless login
	- the device will generate a pair of keys automatically, i.e. send the public key to the website and keep the private key to solve digital signature
- ***End-To-End Encryption***
	- ensure the information is secure on the internet
	- But there are disadvantages. e.g. Zoom will not support cloud recording, but local recording is ok.
- Deletion
	- when the user deletes a file, it is not actually deleted underneath. It is still stored in the RAM waiting for being overwrittened.
	- Solutions:
		- **Secure Deletion**: replace the whole certain memory with `0`
		- **Full-Disk Encryption (全盘加密)**: randomize everything in the disk or hard drive
- ***Ransomware***(勒索软件)
	Hackers encrypt the disk and limit the access.
