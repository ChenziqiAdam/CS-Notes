- HTML
	- a mark-up language
	- about the components of the websites, i.e. about aesthetics(美学)
	- all about presenting information
- Concepts:
	1. **tags**
	2. **attributes(属性)**
	- Example
		```HTML
		<!DOCTYPE html>
		<!-- document type declaration -->

		<html lang="en">
			<!-- children or elements -->
			<head>
				<title>
					hello, title <!-- row text -->
				</title>
			</head>
			<body>
				hello, body <!-- row text -->
			</body>
		</html>
```
		1. `<!DOCTYPE html>`: <u>document type declaration</u>
			indicates version 5 of HTML
		2. `<html lang="en">`: <u>start tag or open tag</u>
			1. `html`: tag
			2. `lang="en"`: attribute and value, i.e. what is after the tag
				key and value
		3. `</html>`: <u>close tag or end tag</u>
		Structure:
		```mathematica
		html
		└── head
		    └── title
		        └── Text: "hello, title"
		└── body
		    └── Text: "hello, body"
```
