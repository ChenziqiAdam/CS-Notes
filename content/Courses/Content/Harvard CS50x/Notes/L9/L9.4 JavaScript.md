- ***JavaScript***

- Variance of *HTML* combined with *JavaScript*
	1. Example: hello
		```HTML
		<!DOCTYPE html>
				
		<html lang="en">
			<head>
				<script>
				<!-- similar to Python -->
					function greet()
					{
						alert('hello, ' + document.querySelector('#name').value);
					}
				
				</script>
				<title>hello</title>
			</head>
			<body>
				<form onsubmit="greet()； return false;">
					<input autocomplete="off" autofocus id="name" placeholder="Name" type="text">
				</form>
		    </body>
	    </html>
	```
	2. Example: another hello
	```HTML
		<!DOCTYPE html>
				
		<html lang="en">
			<head>
				<title>hello</title>
			</head>
			<body>
				<form>
					<input autocomplete="off" autofocus id="name" placeholder="Name" type="text">
					<input type="submit">
				</form>
				<script>

					document.quertSelector('form').addEventListener('submit', function(event) {
					<!-- anonymous function -->
						alert('hello, ' + document.querySelector('#name').value);
						event.preventDefault();
					});
				
				</script>
		    </body>
	    </html>
	```
