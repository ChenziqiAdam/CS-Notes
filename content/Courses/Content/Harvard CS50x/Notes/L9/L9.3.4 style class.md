Example: style classes
```HTML
	<!DOCTYPE html>
			
	<html lang="en">
		<head>
			<style>
			
				.centered
				/* create a style class called centered */
				{
					text-align: center;
				}
				
				.large
				{
					font-size: large;
				}
				
				.medium
				{
					font-size: medium;
				}
				
				.small
				{
					font-size: small;
				}
				
			</style>
			<title>homepage</title>
		</head>
		<body class="centered">
			<header class="large">
	        John Harvard
		    </header>
		    <main class="medium">
		        Welcome to my home page!
		    </main>
	        <footer class="small">
		        Copyright &#169; John Harvard
		    </footer>
		   </body>
	</html>
```
