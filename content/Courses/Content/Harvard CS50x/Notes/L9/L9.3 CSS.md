- **CSS: Cascading Style Sheets**
	- a stylesheet language used to describe the presentation of a document written in HTML
	- properties: **keys** and **values**
	- selectors: 
		enable to specify the font size, the color, the margins, and other aesthetics
		- type selector
		- class selector
		- ID selector
		- attribute selector
- Expression
	```HTML
	<head>
		<style>
		/* aesthetic settings here */
		</style>
		<title>
			hello, title
		</title>
	</head>

	<!-- The same effect as below -->
	<head>
		<style>
			<link herf="styles.css" real="stylesheet">
		</style>
		<title>
			hello, title
		</title>
	</head>
```
