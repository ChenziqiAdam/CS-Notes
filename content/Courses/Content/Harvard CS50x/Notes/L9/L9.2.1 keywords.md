- **Keywords**
	- `<p>` & `</p>`: <u>define a paragraph of text in a web document</u>
		- White space and indentation does not matter in HTML, except enhancing readability
		- Example
			```HTML
			<!DOCTYPE html>
			
			<html lang="en">
				<head>
					<title>paragraph</title>
				</head>
				<body>
					<p>
			            Hello, world!
			        </p>
			        <p>
			            How are you?
			        </p>
			        <p>
			            Well, I'm glad to hear it.
			        </p>
			        <p>
			            That's great.
			        </p>
			    </body>
		    </html>
```
	- `<h1>` & `</h1>`: <u>define a heading of text in a web document</u>
		- `<h2>`, `<h3>` ... `<h6>` : the number indicates the size of the text, the smaller the number is, the larger the text is
	- `<ul>` & `</ul>`: <u>define an unordered list of text in a web document</u>
		- unordered list: `·`, i.e. bulled list
	- `<ol>` & `</ol>`: <u>define an ordered list of text in a web document</u>
		- ordered list: `1.`
	- <u>Comment</u>: `<!-- -->`
	- <u>Table</u>: `<table>` &`</table>`
		- `<tr>` & `</tr>`: table row
		- `<td>` & `</td>`: table data
		- Example:
			```HTML
			<!DOCTYPE html>
			
			<html lang="en">
				<head>
					<title>table</title>
				</head>
				<body>
					<table>
			            <tr>
				            <td>1</td>
				            <td>2</td>
				        <tr>
				            <td>3</td>
				            <td>4</td> 
			        </table>
			    </body>
		    </html>
```
	- <u>Image</u>: 
		- Example:
			```HTML
		    <!DOCTYPE html>
			
			<html lang="en">
				<head>
					<title>image</title>
				</head>
				<body>
					<img alt="photo of a bridge" src="bridge.png">
					<!-- .png in the same folder -->
			    </body>
		    </html>
```
	- <u>Video</u>:
		- Example:
			```HTML
		    <!DOCTYPE html>
			
			<html lang="en">
				<head>
					<title>video</title>
				</head>
				<body>
					<video controls muted>
						<source src="video.mp4" type="video/mp4">
					</video>
			    </body>
		    </html>
```
