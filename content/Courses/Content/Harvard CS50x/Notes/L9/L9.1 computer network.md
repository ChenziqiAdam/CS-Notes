- [[L9.1.1 TCP and IP]]
- ***DNS***: domain name system server
	translate domain names into IP addresses
	- The inside is essentially a dictionary, i.e. domain name <-> IP
- ***DHCP Sever***: dynamic host configuration protocol server
	automate the process of configuring devices on IP networks, allowing them to use network services such as DNS
- ***HTTP**: Hypertext Transfer Protocol
- ***HTTPS***: secure version of HTTP
	designed for communication between web browsers and web servers
- `https://www.example.com/`
	- `/`: the default page for the website i.e. the root
		- `/path`
		- `/file.html`
		- `/folder/`
	- `www.example.com`: the whole **domain name**
		- `example.com`: **domain name**
		- `www`: name of a specific server in that domain
		- `.com`: top level domain
			- `.com`: commercial
			- `.edu`: educational
			- `.gov`: government
			- `.tv`, `.ai`
- Interaction with servers
	- `GET`: <u>get information</u>, i.e. click
	- `POST`: <u>send information</u>
	- Example: `https://www.harvard.edu/`
		1. browser to server
		```HTTP
		GET / HTTP/2
		Host: www.harvard.edu
		...
```
		2. server to brower
		```HTTP
		HTTP/2 200
		Content-Tyoe: text/html
		...
```
		- `HTTP/2 200`: ok
		- [[L9.1.2 common status number]]
	- VS Code: `curl -I https://www.harvard.edu`
- **DevTools: developer tools**
	1. Chrome: `ctrl` + `shift` + `I`
	2. switch to Network
