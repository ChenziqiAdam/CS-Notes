- Q. how to copy a string?
	Example mistake:
	`char *s = "Hi!"`
	`char *t = s`
	- **Not copy! Both `s` and `t` are pointers to the same string i.e. the beginning of "Hi!".**
- `malloc()`: <u>memory allocation</u>
	- used to allocate a block of memory of a specified size on the heap(dynamic memory)
	- return a pointer to the beginning of the allocated memory bloack
- `free()`: <u>deallocate memory</u>
	- return the memory block to the system, making it avaiable for future allocations
- ==**Variable claimed only exist between the most recent curly braces. But for memory allocated by `malloc()`, it exists until `free()`.**==
- Example: copy a string
	```C
	#include <string.h>
	#include <stdlib.h>

	int main(void) {
		char *s = "Hi!";
		int n = strlen(s) + 1;
		char *t = malloc(n);

		for (int i = 0; i < n; i++) {
			t[i] = s[i];
		}

		free(t);
		return 0;
	}
```
	- The loop has the same effect as `strcpy(t, s)`.
	- **`int n = strlen(s) + 1`: s.t. can copy the end of `s` i.e. `\0`.**
		- Otherwise `t` will not end with `\0`.
		- If `prinf("%s", t)`, then it will print until it meets `\0` somehow. 
- int: 
	```C
	int *x;
	x = malloc(sizeof(int));
	...
	free(x);
```
	- `sizeof`: the number of bytes of the variable type
	- **Q. how to swap two integers?**
		```C
		void swap(int *a, int *b) {
			int temp = *a;
			*a = *b;
			*b = temp;
		}
```
		- if remove `*`, parameters passed to functions are just **copies of original variables**.
		- `*` enables functions to gain access to change the content stored in the memory location.
- `\0`: `null`
- Q. how to debug related to memory, i.e. forget to `free()`?
	- `valgrind ./hello`: analyze the memory usage of your program and report issues if any
- garbage value: 
	- if do not initialize variables, there may be something weird stored in the memory allocated to these variables.
