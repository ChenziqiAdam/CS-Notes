- StdIn:
	```C
	int x;
	scanf("%i", &x); // Reads an integer from std input, i.e. the keyboard, and store it in the vatiable x
```
- StdOut:
	```C
	FILE *file = fopen("hello.c", "a");
	fprintf(file, "Hello, world!\n");
	...
	fclose(file);
```
	- `fopen("hello.c", "a")`: <u>open a file named "hello.c" in append mode ("a")</u>, which means that data will be written to the end of the file if it already exists, or a new file will be created if it doesn't exist.
	- `fclose(file)`:  <u>close the file</u> associated with the `FILE` pointer `file`, and release system resources and ensure that any buffered data is flushed to the file.
- All functions in `<stdio.h>`.
