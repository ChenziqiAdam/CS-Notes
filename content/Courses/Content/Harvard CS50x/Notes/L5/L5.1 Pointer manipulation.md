- **`&`**: ***address-of operator***
	- return the memory address of its operand(操作对象).
- **`*`**: ***dereference operator***
	- used to access the value stored at a memory address pointed to by a pointer
- Example:
	```C
	#include <stdio.h>

	int main() {
		int x  = 10;
		int *ptr = &x; // ptr holds the memory address of x

		printf("%i\n", x);
		printf("%p\n", ptr);
		printf("%i\n", *ptr)
	}	
```
	```YAML
	10
	0x7ffeb074da58
	10
```
