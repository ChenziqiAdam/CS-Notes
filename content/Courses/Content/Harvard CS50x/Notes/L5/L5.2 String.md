- **`string` underneath is `char*`**
	- `typedef char* string`
- Example: 
	- `string s = "Hi!"`
		`char* s = "Hi!"`
	- array of chars: \[ H ]\[ i ]\[ ! ]\[ `\0` ]
	- *RAM* {[[L5.4 RAM]]}: \[ 0x123 ]\[ 0x124 ]\[ 0x125 ]\[ 0x126 ]
	- point `s` -> \[ 0x123 ]
	```C
	printf("%p\n", s);
	printf("%p\n", &s[0]);

	printf("%s\n", s);
	printf("%c%c%c\n", *s, *(s + 1), *(s + 2));
	printf("%s\n", s + 1); // Print from the s+1 position to the position of \0
```
	```YAML
	0x123
	0x123
	Hi!
	Hi!
	i!
```
- **This is why "\==" does not work for strings.
	- If using "\==", it actually compares the beginning position of the two strings, which is always not equal.
	- use `strcmp() == 0` in `<string.h>`
		- underneath: compare each char starting from the begining position.
			`if (*s == *t)`
			`if (*(s + 1) == *(t + 1))`
			`...`
- **String always ends with `\0`.**
