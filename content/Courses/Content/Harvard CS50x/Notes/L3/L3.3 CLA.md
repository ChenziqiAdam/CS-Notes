- CLA: parameters passed to a program when it is run from the command line.
	- provide a way to customize the behavior of the program without modifying its source code.
	- e.g. `./hello David`
- `int main(int argc, string argv[])`
	- `int argc`: the number of CLA plus one
	- `string argv[]`: the content of CLA, separated by the whitespace
		- start from `argv[1]`
		- `argv\[0] = "./hello"`
- Terminal supports `tab` to auto-complete, or up and down arrows to go back to your history.
