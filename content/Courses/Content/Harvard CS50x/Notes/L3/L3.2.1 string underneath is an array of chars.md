- **String underneath is an array of chars**
	- Example: string
		```C
		string s = "Hi!";
		// below is the same output "Hi!"
		printf("%s", s);
		printf("%c%%c%c", s[0], s[1], s[2]);
```
		- if RAM is  \[ 72 ]\[ 73 ]\[ 74 ]\[ `\0` ], `printf("%i%i%i%i", s[0], s[1], s[2], s[3])` output is `72 73 74 0`
		- `\0` literally is "0"
		- **The \[n] position is actually accessible and the content is always `\0`**
	- Example: array of strings
		```C
		string words[2];
		words[0] = "Hi!";
		words[1] = "Bye!";
```
		- `words` is essentially a 2-dimension array
		- `words[0][0]` = `H`
	- Q. how to compute the length of a string?
		```C
		int strlen(string name) {
			int n = 0;
			while (name[n] != '/0') {
			n++;
			}
		return n;
```
		- This is the underneath implementation of function `strlen` in `<string.h>` library.
		- `int n = strlen(name)`
	- Q. how to uppercase a string?
		```C
		string uppercase(string name) {
			int n = strlen(name);
			for (int i = 0; i < n; i++) {
				name[i] = toupper(name[i]);
			}
			return name;
		}

		// Convert a lowercase character to its uppercase 
		char toupper(char c) {
			if (islower(c)) {
				c += 32;
			}
			return c;
		}
		
		// Another way to implement toupper
		char toupper(char c) {
			if (islower(c)) {
				c = c - 'a' + "A";
			}
			return c;
		}
```
		- `toupper()` is actually a standard library function in `<ctype.h>` header file.  Above is its underneath implementation.
		- `islower()` is also a function in `<ctype.h>` heaer file.
