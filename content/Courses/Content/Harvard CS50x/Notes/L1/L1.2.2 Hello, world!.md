- Example: hello world
	```C
	#include <stdio.h>
	
	int main(void) {
	string name = "David";
	printf("Hello, world!\n");
	printf("Hello, %s\n!", name);

	return 0; // Indicates successful execution
	}
```
	- `#include <stdio.h>`: import a built-in library, i.e. include a ***header file***
		- what if an external library: `g++ -o hello.exe hello.c -lcs50` i.e. link the code to the cs50 library
	- `void`: function without input
	- `%s`: ***place holder*** for string (`%i` is place holder for integer). 
		- For multiple place holders, the variables plug in in order.
		- **Corner Case:**
			- what if users want print `%s`?
				replace `%` with `%%`
	- `\n`: ***newline character****
		- **Corner Case**
			- what if users want to print `\n`?
				replace `\n` with `\\n`
	- **`string` is not a built-in variable type in C**
