- Representation
	- ***ASCII***: American Standard Code for Information Interchange
		a character encoding standard that assigns numerical values to characters, including letters, digits, punctuation marks, and control characters
	- ***Unicode***
		a character encoding standard that aims to represent text from all writing systems in the world
	- ***RGB***: red, green and blue
		a color model that represents colors by specifying the intensity of these three primary colors
		- red: (255, 0, 0)
		- green: (0, 255, 0)
		- blue: (0, 0, 255)
		- black: (0, 0, 0)
		- white: (255, 255, 255)
