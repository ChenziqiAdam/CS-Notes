- `int`
	- For integer division in Python, it will avoid truncation and return a float, but there is still floating-point imprecision.
	- Integer overflow is not a problem in Python, i.e. the integer can be as large as the user want.
	- Example:
	```Python
		x = int(input("x: "))
		y = int(input("y: "))
		z = x / y
		print(z)
		print(f"{z:.50f}")
```
	```MakeFile
		x: 10
		y: 3
		3.3333333333333335
		3.33333333333333348136306995002087205648422241210938 # Floating-point imprecision
	```
	- Q. how to swap the value of two integers?
		`x, y = y, x`
