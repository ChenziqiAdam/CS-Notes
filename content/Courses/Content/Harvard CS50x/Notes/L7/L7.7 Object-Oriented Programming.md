- **Object-Oriented Programming (OOP)**
	- compared to **Procedural Programming**, the objects, i.e. the data types, have properties and functionalities.
	- Four main principles of OOP:
		1. **Encapsulation(封装)**
		2. **Inheritance(继承)**
		3. **Polymorphism(多态性)**
		4. **Abstraction(抽象)**
	- Example:
		`if s in ["Y", "y", "Yes", "yes"]:`
		`if s.lower() in ["y", "yes"]:`
		`if s.lower().startwith("y"):`
