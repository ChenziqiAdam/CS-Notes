- Array must be contiguous(相邻的，接壤的) i.e. the memory used to store the content of the array is contiguous.
- Q. how to create an array?
	```C
	int *list = malloc(n * sizeof(int)); // n is the size of the array.
	if (list == NULL) {
		free(list);
		return 1;
	}
```
	- `if (array == NULL)`: necessary in case that if the system is out of memory, `list` will be `NULL`.
	- ***Memory Leak****: references to allocated memory are lost without deallocating.
- Q. how to expand an array?
	```C
	int *temp = realloc(list, (n + 1) * sizeof(int));
	if (temp == NULL) {
		free(list);
		return 1;
	}
	list = temp;
	list[n + 1] = ...;
```
	- `realloc()`: <u>reallocate memory</u>
		- create an new array `temp`, whose size is n+1, and copy each number in `list` to `temp`
		- **plus it will free the memory of the original one**
- Q. it is really tedious to repeat the steps above every time users want to add a new element to the array, how to avoid this?
	- List: \[ `list`, 0x123 ] -> \[ 1, 0x456 ] -> \[ 2, 0x789 ] -> \[3, `NULL`]
	- RAM: \[ ... ] -> \[ 0x123 ] -> \[ 0x456 ] -> \[ 0 x789 ]
		- the cell of the data structure stores two things: number plus the memory position of next cell
		- Q. how to implement this?
			- `typedef`
- Example code:
	```C
	typedef struct {
		int number;
		struct node *next;
	} node;

	int min (int argc, char *argv[]) {
		node *list = NULL;
		for (int i = 1; i < argc; i++) {
			int number = atoi(argv[i]);
			node *n = malloc(sizeof(node));
			if (n == NULL) {
				return 1;
			}
			n -> number = number;
			n -> next = NULL;
			list = n;
		}
		node *ptr = list;
		while (ptr != NULL) {
			printf("%i\n", ptr -> number);
			ptr = ptr -> next;
		}

		ptr = list;
		while (ptr != NULL) {
			node *next = ptr -> next;
			free(ptr);
			ptr = next;
		}
	}
```
	- `for (int i = 1; i < argc; i++)`: `argv[0]` is the file name
	- `atoi()`: turn `string` into `int` in `<stdlib.h>`
	- `n -> number`: similar to `n.number`
