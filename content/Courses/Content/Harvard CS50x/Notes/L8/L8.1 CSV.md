- **Flat-File Database**: 
	a type of database that stores data in a simple, plain-text file without any structured format such as tables
	each line of the file typically represents a single record, with fields separated by delimiters such as commas
- CSV: comma-separated values
- Example:
	```Python
	import csv

	with open("favorites.csv", "r") as file: # close the file automatically
		reader = csv.reader(file)
		next(reader)
		for row in reader:
			favorite = row[1]
			print(favorite)
```
	```csv
	// favorites.csv
	name,language // Called metadata
	Adam,C
	Smith,Python
	Chris,C++
	Sam,Java
	Tom,Python
	Tim,C++
	Archer,C
	David,C
	```
	- More robost, use `csv.DictReader`
		automatically analyse the first line metadata as the dictionary, s.t. avoid some colum change
	```Python
	reader = csv.DictReader(file)
	for row in reader:
		print(row["language"])
```

	```Python
		reader = csv.DicReader(file)
		counts = {}

		for row in reader:

```
	- Q. what if the output want to be in aphabetical order?
		`for favorite in sorted(counts)`
	- Q. what if in increasing order?
		`for favorite in sorted(counts, key=counts.get)`
	- Q. what if in decreasing order?
		`for favorite in sorted(counts, key=counts.get, reverse=True)`
- Python is equipped with a huge amount of packages
	```Python
	import csv
	from collections import Counter
	
	with open("favorites.csv", "r") as file:
		reader = csv.DictReader(file)
		counts = Counter()

	for favorite in count in counts.most_common():

```
	- `counts.most_common()`: built-in function in `Counter`
