- There are many stars in different seasons of a show.
	- e.g.
		```SQL
		SELECT name FROM people WHERE id IN (
		SELECT person_id FROM stars WHERE show_id = (
		SELECT id FROM shows WHERE title = 'Game of Thrones' AND year = 2005));
			
		SELECT title FROM shows WHERE id IN (
		SELECT show_id FROM stars WHERE person_id = (
		SELECT id FROM people WHERE name = 'Billie Eillish'));
	```
- `JOIN` supports joining three tables
	- e.g. 
		```SQL
		SELECT title FROM shows 
		JOIN stars ON shows.id = stars.show_id 
		JOIN people ON stars.person_id = people.id 
		WHERE name = 'Billie Eillish';
			
		SELECT title FROM shows, stars, people 
		WHERE shows.id = stars.show_id 
		AND people.id = stars.person_id 
		AND name = 'Billie Eillish';`
```
