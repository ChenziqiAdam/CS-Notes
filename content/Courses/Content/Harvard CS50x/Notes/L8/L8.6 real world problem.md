- With large systems with thousands of servers, there will be **race conditions(竞态条件）**.
- **Keywords**:
	`BEGIN TRANSACTION`
	`COMMIT`
	`ROLLBACK`
	- make code atonic(原子性的), all happen or none happen
	- Example: 
		```Python
		import sqlite3
		
		# Connect to the SQLite database
		conn = sqlite3.connect('favorites.db')
		cursor = conn.cursor()
		
		try:
		    # Begin a transaction
		    conn.execute("BEGIN TRANSACTION;")
		    
		    # Perform some operations
		    cursor.execute("INSERT INTO favorites (name, language) VALUES ('Alice', 'Ruby');")
		    cursor.execute("UPDATE favorites SET language = 'Python' WHERE name = 'Bob';")
		    cursor.execute("DELETE FROM favorites WHERE name = 'Chris';")
		    
		    # Commit the transaction
		    conn.commit()
		    print("Transaction committed successfully.")
		
		except Exception as e:
		    # Roll back the transaction in case of error
		    conn.rollback()
		    print("Transaction rolled back due to an error:", e)
		
		finally:
		    # Close the connection
		    conn.close()
	```
- SQL Injection Attack
	User may input like `--` to make programmer's code become comments.
	- Use Place Holder `?`
