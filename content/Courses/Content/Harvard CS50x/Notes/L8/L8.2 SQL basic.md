- Programmers should write fewer codes but utilize more tools to help them solve problems.
- Relational Database: database that organizes data into tables with rows and columns
- SQL: Structured Query Language
	database specific language
	- declarative language whereby there is not much conditional expression, loop or keyword but describe the problem.
	- ***CRUD***:
		- **Create (Insert)**
		- **Read**
		- **Update**
		- **Delete (Drop)**
- <u>Run SQLite3</u>: `sqlite3 FILE`
	e.g. `sqlite3 favorites.db` 
- <u>Switch mode</u>: `.mode csv`
	as well as `.mode column` and `.mode table` which is more readable
- <u>Import data</u>: `.import FILE TABLE`
	e.g. `import favorites.csv favorites`
- <u>Open database</u>: `sqlite3 FILE`
- <u>Show the schema(框架) of the database</u>: `.schema`
	this command will automatically create a table if there is no table in the database
	- `.schema table`: show the schema of a particular table
- <u>Create table</u>: `CREATE TABLE table (column type, ...);` 
	**Semicolon!**
- <u>Access data in the table</u>: `SELECT * FROM table;`
	e.g. `SELECT name FROM favorites LIMIT 5;`
- **Keywords**:
	`AVG`
	`COUNT`
	`DISTINCT`
	`UPPER`
	`LOWER`
	`MAX`
	`MIN`
	- e.g.
		- `SELECT COUNT(*) FROM favorites;`
		- `SELECT DISTINCT(language) FROM favorites;`
- **More keywords**:
	`WHERE`
	`LIKE`
	`ORDER BY`
	`LIMIT`
	`GROUP BY`
	- e.g.
		- `SELECT COUNT(*) FROM favorites WHERE language = 'C';`
		- `SELECT COUNT(*) FROM favorites WHERE language = 'C' AND name = 'Adam';`
		- `SELECT language, COUNT(*) FROM favorites GROUP BY language;`
		- `SELECT language, COUNT(*) FROM favorites GROUP BY language ORDER BY COUNT(*);`
			- by default is by ascending order: `... BY COUNT(*) ASC`
			- if want to by descending order: `... BY COUNT(*) DESC`
		- `SELECT language, COUNT(*) AS n FROM favorites GROUP BY language ORDER BY n DESC;`
			name `COUNT(*)` as `n`
- <u>Add a new row</u>: `INSERT INTO table (column, ...) VALUES(value, ...);`
	e.g. `ISERT INTO favorites (name, language) VALUES('Noah', 'SQL');`
	- User can add a new row even if user do not know some value, e.g. the favorite language. And SQL will automatically fill it with `NULL`.
- <u>Delete a row</u>: `DELETE FROM table WHERE condition;`
	e.g. `DELETE FROM favorites WHERE language IS NULL;`
		`DELETE FROM favorites;`: **NEVER DO THIS!**
- <u>Modify data</u>: `UPDATE table SET column = value WHERE condition;`
