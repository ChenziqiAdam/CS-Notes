## CRH

- **Collision Resistant Hash Function** (**CRH**): 
	- A function $H$: $M → T$ is collision resistant if it is "hard" to find even a single collision for $H$
	- We say $H$ is a CRH

## Merkle Tree

![[Pasted image 20251117200649.png]]
- Goal
	- Commit to list $S$ of size $n$
	- Later prove $S[i] = m_i$
- To prove $S[4] = m_4$
	- Proof: $\pi = (m_3, y_1, y_6)$
	- i.e. provide the siblings
	- Length of $\pi$: $\text{log}_2 n$
- Theorem: 
	- If H CRH, then adversary cannot find ($S, i, m, \pi$) s.t. $m \ne S[i]$ and verify($h, i, m, \pi$) = accept where $h$ = commit($S$)
- Super Useful
	- When writing a block of transactions $S$ to the blockchain, suffices to write commit($S$) to chain. Keep chain small.
	- Allows efficient and secure verification of the contents of a large data structure.
