## Overview

- SNARK (Succinct Non-Interactive Argument of Knowledge)
	- Allow for transactions to be verified without revealing the sender, receiver, or amount
	- Can also reduce the data needing to be verified on the main blockchain by creating a small, verifiable proof
- **Rollup coordinator**: compresses a thousand Tx into one on-chain proof (SNARK)
	![[Pasted image 20251118103759.png]]
	- Compared to standard L1 chains: every miner must verify every posted Tx

### Transferring Assets

- Transactions within a Rollup system are easy:
	- Batch settlement on L1 network (e.g., Ethereum)
- Moving funds in to or out of Rollup system (L1 <-> L2) is more expensive:
	- Requires posting more data on L1 network → higher Tx fees.
- Moving funds from one Rollup system to another (L2 <-> L2)
	- Either via L1 network (expensive), or via a direct L2 <-> L2 bridge (cheap)

### zkEVM: from L1 Ethereum to L2 zkRollup

- Solidity compatibility: Coordinator can produce a SNARK proof for the execution of a short Solidity program:
	- Easy to migrate a DAPP from L1 Ethereum to L2 zkRollup.
	- Reduced Tx fees and increased Tx rate compared to L1
