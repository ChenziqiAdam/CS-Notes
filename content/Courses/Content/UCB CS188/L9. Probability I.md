### Probability Fundamentals

* A **random variable** represents an event with an unknown outcome. A **probability distribution** assigns weights to outcomes.
* Probability distributions must satisfy:
    * $0 \le P(\omega) \le 1$
    * $\sum_{\omega} P(\omega) = 1$
* Capital letters denote random variables, lowercase letters denote specific outcomes.
* $P(A, B, C)$ denotes the **joint distribution**, where ordering does not matter (e.g., $P(A,B,C) = P(C,B,A)$).
* **Chain Rule (Product Rule):**
    * $P(A,B) = P(A|B)P(B) = P(B|A)P(A)$
    * $P(A_1, A_2, ..., A_k) = P(A_1)P(A_2|A_1)...P(A_k|A_1...A_{k-1})$
* **Marginal Distribution:** Obtained by "summing out" (marginalizing) variables.
    * $P(A,B) = \sum_c P(A,B,C=c)$
    * $P(A) = \sum_b \sum_c P(A,B=b,C=c)$
* **Normalization:** For distributions that don't sum to 1, divide each entry by the sum of all entries.
* **Conditional Probabilities:** Assign probabilities to events given known facts.
    * $P(A|B=b)$ gives the probability distribution of A given B equals b.
    * Definition: $P(A|B) = \frac{P(A,B)}{P(B)}$
* **Bayes' Rule:** Derived from conditional probability and chain rule.
    * $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
* **Mutual Independence:** A and B are mutually independent ($A \perp \perp B$) if $P(A,B) = P(A)P(B)$.
    * Equivalent to $P(A|B) = P(A)$ and $P(B|A) = P(B)$.
* **Conditional Independence:** A and B are conditionally independent given C ($A \perp \perp B | C$) if $P(A,B|C) = P(A|C)P(B|C)$.
    * This means if C is known, A and B don't affect each other.
    * Equivalent to $P(A|B,C) = P(A|C)$ and $P(B|A,C) = P(B|C)$.

### Probabilistic Inference

* Used in AI to model relationships between nondeterministic events and answer questions involving uncertainty.
* The world is modeled with each possible state having its own probability (a joint distribution).
#### Inference By Enumeration (IBE)

* A procedure to compute any desired probability distribution $P(Q_1...Q_m|e_1...e_n)$ given a joint PDF.
* **Types of Variables:**
    1.  **Query variables ($Q_i$):** Unknown, on the left side of the conditional.
    2.  **Evidence variables ($e_i$):** Observed, known values, on the right side of the conditional.
    3.  **Hidden variables:** Present in the joint distribution but not in the desired distribution.
* **Algorithm:**
    1.  Collect all rows consistent with observed evidence variables.
    2.  Sum out (marginalize) all hidden variables.
    3.  Normalize the table.
* IBE can be used for any number of query variables as long as the joint PDF is available.
