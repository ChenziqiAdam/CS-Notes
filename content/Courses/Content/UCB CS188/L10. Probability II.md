### Bayesian Network Representation

- While IBE (inference by enumeration) can compute probabilities for any query we might desire, representing an entire joint distribution in the memory of a computer is impractical for real problems.
	- If each of n variables we wish to represent can take on $d$ possible values (it has a **domain** of size $d$), then our joint distribution table will have $d^n$ entries.
- **Bayes nets** avoid this issue by taking advantage of the idea of conditional probability. 
	- Rather than storing information in a giant table, probabilities are instead distributed across a number of smaller conditional probability tables along with a **directed acyclic graph** (**DAG**) which captures the relationships between variables. 
	- The local probability tables and the DAG together encode enough information to compute any probability distribution that we could have computed given the entire large joint distribution.
- We formally define a Bayes Net as consisting of:
	- A directed acyclic graph (DAG) of nodes, one per variable $X$.
	- A conditional distribution for each node $P(X|A_1...A_n)$, where $A_i$ is the $i^{th}$ parent of $X$, stored as a **conditional probability table** (**CPT**). 
	- Each CPT (conditional probability table) has $n+2$ columns: one for the values of each of the $n$ parent variables $A_1...A_n$, one for the values of $X$, and one for the conditional probability of $X$ given its parents.
- The structure of the Bayes Net graph encodes conditional independence relations between different nodes. These conditional independences allow us to store multiple small tables instead of one large one.
	- It is important to remember that the edges between Bayes Net nodes do not mean there is specifically a causal relationship between those nodes, or that the variables are necessarily dependent on one another. 
	- It just means that there may be some relationship between the nodes.
#### Example

- Consider a model where we have five binary random variables described below:
	* **B**: Burglary occurs.
	* **E**: Earthquake occurs.
	* **A**: Alarm goes off.
	* **J**: John calls.
	* **M**: Mary calls.
- Assume the alarm can go off if either a burglary or an earthquake occurs, and that Mary and John will call if they hear the alarm. We can represent these dependencies with the following graph structure where arrows point from parent nodes to child nodes:
	* `B` -> `A`
	* `E` -> `A`
	* `A` -> `J`
	* `A` -> `M`
- In this Bayes Net, we would store the following conditional probability tables (CPTs):
	* $P(B)$
	* $P(E)$
	* $P(A|B, E)$
	* $P(J|A)$
	* $P(M|A)$
- Given all of the CPTs for a graph, we can calculate the probability of a given joint assignment using the following rule:
	$P(X_{1},X_{2},...,X_{n})=\prod_{i=1}^{n}P(X_{i}|parents(X_{i}))$
- For the alarm model above, we can calculate the probability of a specific joint probability as follows:
	$P(-b,-e,+a,+j,-m)=P(-b) \cdot P(-e) \cdot P(+a|-b,-e) \cdot P(+j|+a) \cdot P(-m|+a)$
- To prove this relationship, we can compare it to the chain rule of probability. If we expand the joint distribution with a topological ordering (parents before children), we get:
	$P(B,E,A,J,M)=P(B)P(E|B)P(A|B,E)P(J|B,E,A)P(M|B,E,A,J)$
- Based on the conditional independence relations encoded in the graph structure:
	* `E` is independent of `B`, so $P(E|B) = P(E)$.
	* `J` is conditionally independent of `B` and `E` given `A`, so $P(J|B,E,A) = P(J|A)$.
* `M` is conditionally independent of `B`, `E`, and `J` given `A`, so $P(M|B,E,A,J) = P(M|A)$.
- Applying these independencies simplifies the chain rule equation to the Bayes Net formula:
	$P(B,E,A,J,M)=P(B)P(E)P(A|B,E)P(J|A)P(M|A)$

### Structure of Bayes Nets

- In this class, we will refer to two rules for Bayes Net independences that can be inferred by looking at the graphical structure of the Bayes Net:
	1. **Each node is conditionally independent of all its ancestor nodes (non-descendants) in the graph, given all of its parents.**
		![[Pasted image 20250630151657.png|400]]
	2. **Each node is conditionally independent of all other variables given its Markov blanket.** A variable’s Markov blanket consists of parents, children, children’s other parents.
		![[Pasted image 20250630151804.png|400]]
- Using these tools, we can return to the assertion in the previous section: that we can get the joint distribution of all variables by joining the CPTs of the Bayes Net.
	$P(X_1, X_2,...X_n) = \prod_{i=1}^{n}P(X_i|parents(X_i))$
	- This relation between the joint distribution and the CPTs of the Bayes net works because of the conditional independence relationships given by the graph.
#### Example

- We can prove this using the previous Burglary-Alarm example. For this Bayes net, we are trying to prove the following relation:
	$P(B,E,A,J,M)=P(B)P(E)P(A|B,E)P(J|A)P(M|A)$ (1)
- We can also expand the joint distribution using the chain rule. If we use a topological ordering (parents before children), we get the following equation:
	$P(B,E,A,J,M)=P(B)P(E|B)P(A|B,E)P(J|B,E,A)P(M|B,E,A,J)$ (2)
- We rely on the first conditional independence relation: 
	- each node is conditionally independent of all its ancestor nodes in the graph, given all of its parents. 
	- Therefore, in a Bayes net, $P(var|Parents(var),Ancestors(var))=P(var|Parents(var))$, which means Equation (1) and Equation (2) are equal. 
	- The conditional independences in a Bayes Net allow for multiple smaller conditional probability tables to represent the entire joint probability distribution.
