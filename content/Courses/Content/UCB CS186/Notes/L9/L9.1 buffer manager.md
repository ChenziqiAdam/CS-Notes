- Buffer manager is to provide the illusion of addressing and modifying disk pages in memory to the higher levels.
	- Almost the same as cache
	![[Pasted image 20250625170930.png|400]]
- Q. How to handle dirty/modified pages?
	1. How the buffer manager find out the dirty pages
		- Dirty bit on page
	2. What to do with the dirty pages
		- Write back via disk manager
	3. How to deal with concurrent operations on a page
		- Solved by Concurrency Control Module
	4. How to handle system crash before write-back
		- Solved by Recovery Module
- Buffer Manager State
	- Buffer pool: Large range of memory, malloced at DBMS server boot time
	- Buffer Manager metadata: Smallish array in memory, malloced at DBMS server boot time
