- Recall
	- B: The number of data blocks
	- R: Number of records per block
	- D: Average time to read/write disk block

| Initial          | Heap File  | Sorted File                 |
| ---------------- | ---------- | --------------------------- |
| Scan all records | B\*D       | B\*D                        |
| Equality Search  | 0.5\*B\*D  | (log<sub>2</sub>B)\*D       |
| Range Search     | B\*D       | (log<sub>2</sub>B+pages)\*D |
| Insert           | 2\*D       | (log<sub>2</sub>B+B)\*D     |
| Delete           | (B/2+1)\*D | (log<sub>2</sub>B+B)\*D     |

- Note:
	- Equality Search: can apply binary search for sorted file
	- Insert: read first to modify the file
	- Delete: require to move the rest files to fill the empty hole for sorted file
- Q. Can we do better?
	- Indexes!
