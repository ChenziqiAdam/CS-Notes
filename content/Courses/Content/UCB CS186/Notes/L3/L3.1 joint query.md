- Expression
	```sql
	SELECT [DISTINCT] <column expression list>
		FROM <tablel [AS t1], ... , tableN [As tn]>
		[WHERE <predicate>]
		[GROUP BY <column list>[HAVING <predicate>] ]
		LORDER BY <column list>];
```
	- The major procedure is the same as single table. But the SELECT is different.
	- SELECT from *Cross(Cartesian) Product*
- ***Cross(Cartesian) Product***: all pairs of tuples concatenated
- Example
	![[Pasted image 20250602165149.png]]
	1. SELECT Sailors who reserved a boat
		```sql
		SELECT Sailors.sid,
				Sailors.sname,
				Reserve.bid
			FROM Sailors, Reserve
			WHERE Sailors.sid = Reserve.sid
```
- Column Names and Table Aliases: two equivalent expressions
	```sql
	SELECT Sailors.sid, sname, bid
	FROM Sailors, Reserves
	WHERE Sailors.sid = Reserves.sid
```
	```sql
	SELECT S.sid, sname, bid
	FROM Sailors AS S, Reserves AS R
	WHERE S.sid = R.sid
```
- More Aliases
	```sql
	SELECT x.sname, x.age,
			y.sname AS sname2,
			y.age AS age2
	FROM Sailors AS x, Sailors AS y
	WHERE x.age > y.age
```
- Note
	- Table aliases in the FROM clause
		- Needed when the same table used multiple times ("self-join")
	- Column aliases in the SELECT clause
