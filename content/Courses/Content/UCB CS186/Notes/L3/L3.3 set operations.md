- Combining Predicates "subtle connections"
	- Boolean logic in WHERE (i.e., AND, OR)
	- Traditional Set operations (i.e. INTERSECT, UNION)
- Example: two equivalent expressions
	- Sid's of sailors who reserved a red **or** green boat
	```sql
	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND 
		(B.color='red' OR B.color='green')
```
	```sql
	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND B.color='red'
	
	UNION ALL
	
	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND B.color='green'
```
	- Sid's of sailors who reserved a red **and** green boat
	```sql
	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND B.color='red'
	
	INTERSECT

	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND B.color='green'
```
	- NOTE: this above is not equivalent to this below, which will return empty (no boat is both 'red' and 'green')
	```sql
	SELECT R.sid
	FROM Boats B, Reserves R
	WHERE R.bid=B.bid AND
		(B.color='red' AND B.color='green')
```
- **Set Semantics**
	- Set: a collection of distinct elements
	- Standard ways of manipulating/combining sets: Union, Intersect, Except
		- Except: in A but not in B (asymmetric)
	- Treat tuples within a relation as elements of a set

	- UNION: sum of cardinalities
	- INTERSECTION: min of cardinalities (= 0 is eliminated)
	- EXCEPT: difference of cardinalities (<= 0 is eliminated)
