- ARGMAX
	- F1
	```sql
	SELECT *
	FROM Sailors S
	WHERE S.rating >= ALL
		(SELECT S2.rating
		FROM Sailors S2)
```
	- F2
	```sql
	SELECT *
	FROM Sailors S
	WHERE S.rating =
		(SELECT MAX(S2.rating)
		FROM Sailors S2)
```
	- F3
	```sql
	SELECT *
	FROM Sailors S
	ORDER BY rating DESC
	LIMIT 1;
```
	- Note: the last one will always return one result, while the previous two may return all sailors who share the same highest rating. 
		- In that case, the result of the last one is not deterministic.
